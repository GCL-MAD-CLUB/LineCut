# 创建第一个项目

使用一段容易辨认内容的视频，完成从素材导入到片段交付的基本流程。视频无需包含字幕。

## 创建并保存项目

1. 在项目首页选择**新建项目**，或选择**文件 → 新建项目**。
2. 按 **Ctrl + S**，为项目命名并选择 `.lcp` 文件的保存位置。
3. 将原始素材放在稳定的文件夹中；项目文件需要与素材一起保管。

## 导入视频

1. 切换到顶部**导入**工作区。
2. 浏览素材所在文件夹，勾选视频。也可选择文件夹，等待扫描结束。
3. 如需集中保管素材，开启**复制媒体**并选择目标位置。
4. 单击**导入**，完成后切换到**编辑**工作区。

更多导入选项见[导入和整理媒体](/media/import-organize)。

## 浏览和寻找镜头

1. 在媒体箱双击视频，并打开**分镜**面板。
2. 在分镜来源菜单中选择视频；尚无分镜时会开始识别。等待结果显示。
3. 切换到图标视图浏览画面，单击缩略图预览完整镜头。
4. 若已安装语义检索组件，将搜索模式设为**语义**，输入画面描述。首次搜索需要等待准备完成。

没有语义检索组件时，仍可浏览分镜、编辑标题、添加关键字并按文字筛选。操作示例见[按画面查找镜头](/workflows/find-visuals)。

## 整理并选择候选镜头

1. 选中所需镜头，设置星级或留用旗标。
2. 为镜头添加容易复用的关键字，例如“人物 > 嘉宾”或“地点 > 室外”。
3. 按住 **Ctrl** 选择多个镜头；按住 **Shift** 选择连续范围。
4. 按 **Ctrl + S** 保存整理结果。

## 导出片段

1. 保持镜头选中，选择**文件 → 导出…**。
2. 在导出列表中核对勾选项，逐段预览；需要时拖动蓝色括号微调入点和出点。
3. 选择输出文件夹、格式和命名规则。
4. 要生成一个文件，开启**合并为一个文件**；要逐镜头交付，关闭此选项。
5. 单击**导出**，完成后在输出文件夹检查结果。

下一步可阅读[使用分镜](/storyboard/storyboards)或[导出媒体](/export/exporting)。有对白检索需求时，再参阅[使用字幕](/subtitles/subtitles)。
