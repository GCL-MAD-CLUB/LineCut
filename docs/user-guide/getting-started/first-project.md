# 创建第一个项目

本教程使用一个带台词的视频演示完整路径。你也可以先导入视频，再单独导入外部字幕。

## 1. 新建项目

1. 选择 **文件 → 新建项目**，或按 <kbd>Ctrl</kbd> + <kbd>N</kbd>。
2. 如果当前项目有未保存更改，先选择**存储**、**不保存**或**取消**。
3. 新项目会以未命名状态打开；在首次保存前，它仍可正常导入和编辑素材。

## 2. 导入视频和字幕

1. 在媒体箱中点击导入按钮，或选择 **文件 → 导入**，也可按 <kbd>Ctrl</kbd> + <kbd>I</kbd>。
2. 选择一个或多个视频、音频或字幕文件。
3. 导入完成后，在媒体箱中双击视频，或把视频拖到源播放器以激活预览。
4. 若字幕与视频是两个文件，选中字幕和目标视频后执行[绑定音频和字幕到视频](/media/tracks-binding)。

## 3. 搜索并选择台词

1. 打开**字幕**面板。
2. 在搜索框中输入一个词或一句台词。
3. 点击结果可跳转源播放器到相应时间；勾选要保留的字幕。
4. 可用星级、旗标或色标继续筛选，避免把所有搜索结果都导出。

详细规则见[搜索、过滤和排序字幕](/subtitles/subtitles)和[选择字幕并导出](/subtitles/subtitles)。

## 4. 导出

1. 切换到顶部的**导出**工作区。
2. 在来源列表勾选要输出的片段。
3. 选择输出位置和输出模式；第一次导出时先保留默认视频、音频设置。
4. 点击**导出**。任务会进入队列；完成后按你的设置写入目标目录。

## 5. 保存项目

按 <kbd>Ctrl</kbd> + <kbd>S</kbd> 保存。第一次保存会打开文件选择框，请使用 `.lcp` 扩展名。项目记录素材引用和整理状态，不会把视频嵌入项目文件；移动素材后需要重新链接。

下一步可按目标继续：

- 想更细致地检索，阅读[通过字幕找到片段](/workflows/find-dialogue)。
- 想按画面内容整理，阅读[整理分镜并建立关键字](/workflows/organize-storyboard)。
- 想理解项目安全保存，阅读[新建、打开、保存和关闭项目](/projects/projects)。
