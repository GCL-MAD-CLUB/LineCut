# 系统要求

Locution Pro 在本机完成媒体处理。素材长度、分辨率、编码和电脑性能会影响预览与处理速度。

## 安装和使用条件

| 项目     | 要求或建议                                                        |
| -------- | ----------------------------------------------------------------- |
| 操作系统 | Windows 10 或 Windows 11，64 位                                   |
| 显示器   | 可用窗口至少 1080 × 700，建议 1920 × 1080 或更高                  |
| 媒体工具 | 使用安装程序提供的内置 FFmpeg，或在首选项中指定 FFmpeg 与 ffprobe |
| 存储     | 为素材、媒体缓存、可选组件、代理和输出文件保留空间                |
| 网络     | 下载、更新和在线帮助需要网络；日常本地素材处理无需联网            |

## 安排存储位置

将原始素材放在稳定、可访问的磁盘上。使用外接存储时，在导入、检测、检索准备、代理生成和导出完成前保持连接。

项目文件不包含原始媒体。请分别安排项目、原始素材、自动保存、媒体缓存、代理和导出的位置，避免将唯一副本放在会被自动清理的目录中。

在[首选项](/projects/preferences)中检查缓存与自动保存位置。更改位置后，旧文件不会自动移动。

## 处理大型素材

高分辨率、长时长或高码率视频可能需要较长的准备时间。先用少量代表素材确认预览和处理表现，再进行大批量工作。

预览不流畅时可[创建代理](/workflows/create-proxy)。镜头检测和首次画面检索准备仍需要原始视频在线。语义检索组件需要额外存储空间，未安装时不会出现语义搜索选项。

继续阅读[安装与首次启动](/getting-started/install)。
