# 系统要求

> 适用版本：LineCut 0.3.3。本文以 `release/0.3.3` 分支实现为准。

LineCut 是 Windows 桌面应用。媒体分析、缩略图、代理和导出都在本机完成，因此视频长度、分辨率和编码格式会直接影响所需时间、内存和磁盘空间。

## 基本条件

| 项目     | 要求或建议                                                               |
| -------- | ------------------------------------------------------------------------ |
| 操作系统 | Windows 10 或 Windows 11，64 位                                          |
| 屏幕     | 可用窗口最小为 1080 × 700；建议 1920 × 1080 或更高                       |
| 磁盘     | 为缓存、缩略图、代理和导出文件保留充足空间                               |
| 媒体工具 | 安装程序可安装内置 FFmpeg；也可在首选项中指定已有的 FFmpeg 与 ffprobe    |
| 网络     | 日常导入、分析和导出不依赖网络；只有打开在线帮助或 GitHub 页面时需要网络 |

## 开始前的存储规划

LineCut 的 `.lcp` 项目只记录素材路径、项目内容和工作状态，不会复制原始视频。请把原始素材放在稳定的本地磁盘或可靠的外接存储中，并为以下位置分别预留空间：

- 原始媒体所在目录；
- 首选项中的缓存路径；
- 代理输出位置；
- 导出目标目录。

如果素材位于可移动磁盘、网络盘或稍后会改名的目录，先阅读[项目文件与素材位置](/projects/projects)和[脱机、替换和重新链接](/media/offline-proxies)。

## 性能预期

- 高分辨率、高码率或很长的视频可能需要较长时间生成缩略图、检测镜头切点或创建代理。
- 可用的 DirectML 环境会用于分镜检测的 GPU 加速；不能使用时会回退到 CPU。
- 预览不流畅时，优先使用[代理](/media/offline-proxies)，而不是移动或重新编码原始素材。
- 缓存存储在空间不足的系统盘时，生成缩略图、代理或导出可能失败；可在[首选项](/projects/preferences)中更改缓存路径。

## 0.3.3 检测任务的资源预期

分镜检测最多三项并行，受 CPU 物理核数和后台提取预算进一步限制。解码与推理重叠运行，有界队列控制待处理帧积压；模型会话在最后一项检测结束后短暂保留约 30 秒，便于接续任务，因此任务完成后内存不一定立即降回起始值。

Windows 提取请求 D3D11VA；推理尝试 DirectML，二者分别依赖媒体工具、源编码和显卡环境。无法提供固定处理速度或统一的 GPU 显存门槛，正式批处理前应以实际素材和电脑测量。代理可改善预览，但检测仍要求原始媒体在线。
