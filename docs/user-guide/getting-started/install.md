# 安装与首次启动

> 适用版本：Locution Pro 0.3.3。

## 安装 Locution Pro

1. 打开 Locution Pro 的 GitHub Releases 页面，下载与 Windows 对应的安装程序。
2. 运行安装程序并按屏幕提示完成安装。
3. 安装程序询问 FFmpeg 方案时，首次使用建议选择**内置 FFmpeg**。它用于探测媒体、导入字幕、生成代理和导出。
4. 在 FFmpeg 之后的**语义检索**页选择是否附带组件，首次安装默认勾选。未勾选时，程序的搜索模式中不会出现“语义”选项。
5. 从开始菜单或桌面快捷方式启动 Locution Pro。

语义检索模型在本机运行，附带组件会占用额外磁盘空间。覆盖安装时可以修改选择；自动更新会保留此前的选择。

Locution Pro 是 LineCut 的独立续作，两款软件可以共存。Locution Pro 使用自己的安装位置、卸载记录、快捷方式和数据目录，不会卸载 LineCut，也不能安装到 LineCut 的目录内。两者继续支持 `.lcp` 项目；项目内容版本的兼容性规则保持不变。

只有当前用户首次安装、存在 LineCut 数据，且没有 Locution Pro 安装记录、数据目录或浏览器配置时，安装器才执行复制迁移。检测在安装器写入新文件前完成；任意 Locution Pro 既有数据都会使后续覆盖安装、更新和重新安装跳过迁移，不合并或同步 LineCut 后续产生的数据。卸载时保留的数据也会阻止再次迁移；完全清理 Locution Pro 安装记录与数据后重新安装，才可再次满足首次迁移条件。为所有用户安装时不迁移用户数据。软件正常运行不会扫描 LineCut 目录，也不会执行数据复制迁移。

满足条件时，文件安装完成后会在同一个窗口中自动进入“迁移旧数据”页，复制设置、用户文件、默认或自定义缓存、自动保存和浏览器配置。复制后，缓存与自动保存路径均指向 Locution Pro 自身目录；除用户主动打开的 `.lcp` 项目与引用的原始素材外，不共享 LineCut 的可写数据。LineCut 的安装文件、模型组件和安装选项不会导入。请预留副本所需的磁盘空间，迁移前关闭 LineCut 以避免源数据持续变化。

页面显示复制与校验阶段、文件数量、数据大小和当前文件。每个复制文件都会在写入后重新读取，以 SHA-256 校验，校验通过后才提交。全部完成后自动进入安装完成页。取消或失败会保留原数据并停留在迁移页，可以在本次安装中点击“重试”；关闭安装器后留下的 Locution Pro 数据将阻止下一次安装重新导入。旧 `.lcp` 项目可直接打开；新版本重新保存的项目可能无法由旧版本打开，降级前请保留原文件副本。

如果已安装并维护了自己的 FFmpeg，也可以不安装内置版本，随后在 **编辑 → 首选项** 中填写 `FFmpeg` 与 `ffprobe` 的可执行文件路径。具体排查方式见[FFmpeg、ffprobe 与工具路径](/troubleshooting/troubleshooting)。

## 首次启动后应看到什么

应用会显示菜单栏、工作区切换器和四个默认面板：**源播放器**、**媒体箱**、**字幕**、**分镜**。没有项目时，播放器和内容面板会显示空状态；这是正常现象。

默认工作区包含“导入、编辑、导出”三个入口。它们不创建不同的项目，而是切换你在当前项目中完成任务的工作界面。

## 首次检查清单

- 在 **编辑 → 首选项** 中确认缓存路径有足够空间。
- 若未安装内置 FFmpeg，确认 `FFmpeg`、`ffprobe` 路径可用。
- 在 **文件 → 新建项目** 创建项目，或在 **文件 → 打开项目** 打开已有 `.lcp` 项目。
- 导入一段带字幕的视频，或分别导入视频和字幕文件。

> [!TIP]
> 浏览器预览只能展示界面，不能选择本地文件、保存首选项、导入本地媒体或生成代理。上述操作必须在安装后的 Tauri 桌面应用中完成。

继续阅读[创建第一个项目](/getting-started/first-project)。

## 从 0.3.2 升级

升级前保存重要项目并备份 `.lcp` 与源素材。安装 0.3.3 对应构建后，先核对媒体工具与缓存路径，再打开原项目检查字幕标注、分镜、绑定和代理。已有分镜不会仅因升级自动覆盖；缺失封面或内嵌文本字幕数据可能在后台重新分析。

当前指南对应 `release/0.3.3`，不代表安装包已经公开发布。请在下载页面核对构建版本；完整升级注意事项见[0.3.3 新增功能](/release-notes/v0.3.3)。
