# 认识工作界面

## 顶部菜单

| 菜单 | 作用                                                       |
| ---- | ---------------------------------------------------------- |
| 文件 | 新建、打开、保存、导入、链接、替换、脱机和导出项目内容     |
| 编辑 | 撤销、重做、复制、粘贴、清除、重复、全选、取消选择和首选项 |
| 剪辑 | 当前为后续版本预留的菜单入口                               |
| 窗口 | 打开或显示源播放器、项目媒体箱、字幕、分镜和历史记录面板   |
| 帮助 | 当前为后续版本预留；应用内尚未提供打开在线帮助的命令       |

## 工作区切换器

| 工作区 | 适合做什么                                       |
| ------ | ------------------------------------------------ |
| 导入   | 选择多个视频、音频和字幕，并查看待导入项目       |
| 编辑   | 在可停靠面板中预览、检索字幕、整理媒体和分镜     |
| 导出   | 选择片段、设置编码、命名与目标位置，然后提交导出 |

工作区不会删除任何内容，也不会改变项目文件；它只让当前任务的界面更集中。

## 默认面板

| 面板     | 主要用途                                           |
| -------- | -------------------------------------------------- |
| 源播放器 | 预览活动视频，播放、逐帧、调整时间线和切换预览方式 |
| 媒体箱   | 管理视频、音频、字幕、媒体箱文件夹、代理和链接状态 |
| 字幕     | 搜索、筛选、排序、选择和标注字幕条目               |
| 分镜     | 检测镜头、浏览画面、标记、堆叠并给镜头添加关键字   |
| 历史记录 | 回到任意项目操作状态，管理后续分支                 |
