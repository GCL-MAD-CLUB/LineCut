# 认识工作界面

Locution Pro 将常用操作安排在**导入、编辑、导出**三个工作区中。它们使用同一个项目，可按工作需要随时切换。

## 选择工作区

| 工作区 | 适合完成的任务                                     |
| ------ | -------------------------------------------------- |
| 导入   | 浏览本地文件，选择素材，设置复制与媒体箱组织       |
| 编辑   | 预览画面、检测与整理镜头、添加关键字、筛选候选素材 |
| 导出   | 核对片段范围，配置文件格式、画面、音频和输出位置   |

右上角主页按钮打开项目首页，用于新建、打开和查找最近项目。首页关闭后可继续当前工作。

## 使用编辑面板

| 面板       | 用途                                             |
| ---------- | ------------------------------------------------ |
| 项目媒体箱 | 管理视频、音频、图像和字幕，建立文件夹与媒体关系 |
| 源监视器   | 播放媒体，逐帧检查，调整分镜切点，导出当前帧     |
| 分镜       | 按镜头浏览与检索画面，设置标题、关键字和标记     |
| 字幕       | 已有字幕时，查找、标注并选择对白片段             |
| 历史记录   | 查看项目操作，撤销、重做或返回先前状态           |

从**窗口**菜单可打开面板。拖动面板标签可调整停靠位置，拖动分隔线可改变大小；详见[工作区、面板与任务](/workspace/workspace)。

## 确认当前操作对象

执行全选、删除、标注或导出前，先单击目标面板。命令通常作用于当前聚焦面板中的选择；焦点在文字输入框时，快捷键用于文字编辑。

分镜和字幕面板各自提供来源菜单，可同时查看多个视频。单击条目会在源监视器中打开对应媒体。需要固定面板内容时，使用来源菜单旁的**锁定作用域**。

## 查看进度和提示

顶部进度区显示处理任务与等待状态。灰色命令通常表示当前选择、媒体连接或工作区不符合条件。遇到问题时，先查看屏幕提示，再参阅[故障排查](/troubleshooting/troubleshooting)。
