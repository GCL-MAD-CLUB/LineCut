# 堆叠、展开和拆分分镜

堆叠将两个或更多分镜作为一个可折叠集合显示，适合把连续反应镜头、一个完整动作或同一段落的多个切点组织在一起。堆叠不会合并或重编码视频文件。

## 创建堆叠

1. 按时间顺序选择至少两个分镜。
2. 右键打开 **堆叠** 子菜单，选择创建堆叠。
3. 堆叠在列表/图标中以一个入口表示，显示包含的分镜数量。

如果只选择一个分镜，不能创建堆叠。

## 展开与折叠

单击堆叠的展开/折叠控件，可在整体视图和内部各分镜之间切换。展开状态只影响浏览，不改变堆叠成员、关键字或标记。

## 从堆叠中移除或拆分

- 从堆叠中移除一个分镜：该镜头恢复为独立分镜，其余成员仍可保持堆叠。
- 拆分堆叠：把堆叠成员完全恢复为独立镜头。
- 取消堆叠：针对当前堆叠执行解除操作，效果是撤销其整体分组。

## 删除与波纹删除

右键菜单还提供**删除**和**波纹删除**。它们修改项目中的分镜划分：

- 删除移除所选分镜而保留后续镜头的时间位置；
- 波纹删除会让后续分镜向前闭合时间空缺。

删除分镜会同时清理与其关联的分镜标记；在处理堆叠前先保存项目副本，并使用历史记录核对结果。
