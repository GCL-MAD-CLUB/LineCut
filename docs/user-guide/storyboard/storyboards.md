# 使用分镜

分镜将视频呈现为可预览、检索和标注的镜头条目。即使视频没有字幕，也可以完成本页全部操作。整理结果保存后可继续用于筛选和导出。

## 生成分镜

1. 在媒体箱选择原始文件在线、已启用的视频。
2. 打开**分镜**面板，在来源菜单选择视频。新增来源尚无分镜时，会自动开始识别。
3. 需要主动识别时，单击标题行最右侧的剪刀按钮**切分**或**重新切分**。
4. 等待顶部进度结束，在列表或图标视图中查看结果。

也可以在媒体箱多选视频，右键选择**分镜识别**。识别需要原始视频在线；仅有代理可预览时，请先重新连接原始媒体。

自动识别后请检查明显的误切和漏切，尤其是淡入淡出、叠化和快速运动画面。需要修正时，在[源监视器](/source/source-monitor#调整分镜切点)中添加、移动或清除切点。

### 重新识别已有分镜

| 选项 | 对已有工作的影响                                               |
| ---- | -------------------------------------------------------------- |
| 合并 | 保留现有划分与整理，补充识别出的新切点；检查新镜头的边界和标记 |
| 覆盖 | 重建分镜，清除旧删除记录、堆叠和镜头标注                       |
| 取消 | 保留现有分镜，不执行本次识别                                   |

准备覆盖前请保存项目副本。如果识别期间继续修改了相关镜头，完成时可能再次要求选择处理方式。

## 浏览和选择镜头

使用面板底部控件切换**列表**或**图标**视图，并调整缩略图大小。列表适合比较标题、时间、时长、关键字与星级；图标视图适合快速审看画面。单击表头或使用排序菜单改变顺序。

- 单击行或卡片可选择镜头并定位到开始位置。
- 单击缩略图画面或双击条目，可播放该镜头范围。
- **Ctrl + 单击**增减不连续选择，**Shift + 单击**选择连续范围。
- 在空白区域拖动可框选；方向键可移动选择。
- **编辑 → 全选**选择当前筛选后可见的镜头。
- **仅展示选中分镜**可集中核对候选集合。

图标信息区域的右键菜单可选择显示标题、编号、时间、星级或标签。面板底部**更多选项**用于显示或隐藏常用工具。

### 同时查看多个视频

在来源菜单勾选多个视频，可集中检索和标注。列表会出现**来源**列：按来源正序或倒序排列时，先分组，再按其他列排序；将来源排序设为**无**可跨视频统一排序。

取消最后一个来源后，面板显示**未选择**。重新选择来源即可继续查看。使用标题行的**锁定作用域**固定来源，详见[来源工作区与导航历史](/workspace/workspace#来源工作区与导航历史)。

## 用描述查找画面

安装语义检索组件后，可使用**语义**搜索。它按画面内容查找镜头，无需先填写标题或关键字。

1. 选择需要搜索的视频来源。
2. 将搜索模式设为**语义**，输入具体画面描述，例如“室外行走的人群”。
3. 首次使用时，等待语义检索初始化和分镜索引构建完成。
4. 查看匹配度靠前的结果，并在源监视器中核对。
5. 调整阈值缩小或扩大结果集合。

阈值默认是 0，越高越严格。分镜匹配度显示五位小数，阈值可调整到三位小数。匹配度用于比较相关性，不代表识别正确的概率。结果过少时，降低阈值或使用更简洁的描述。

图标视图会显示镜头中最符合查询的画面，并以竖线提示其时间位置。列表缩略图区域会并列显示原画面与命中画面；命中画面用于查看，原缩略图保留预览操作。清空搜索或切换模式后，恢复普通缩略图。

准备过程可取消，之后可重新尝试。视频较长或素材较多时需要等待。相关示例见[按画面查找镜头](/workflows/find-visuals)。

## 按文字和标记筛选

### 文字搜索

从搜索范围选择**任何可搜索的字段**、**标题**或**关键字**。关键字范围支持完整路径和同义词。

| 模式或规则          | 用途                                               |
| ------------------- | -------------------------------------------------- |
| 过滤                | 只保留匹配项                                       |
| 高亮                | 保留上下文，用上一个、下一个按钮或匹配序号浏览结果 |
| 包含                | 查找包含任一输入词的条目                           |
| 包含所有 / 包含单词 | 要求所有输入词满足对应匹配条件                     |
| 不含                | 排除包含输入词的条目                               |
| 开头为 / 结尾为     | 按输入的完整文字匹配字段首尾                       |
| 为空 / 不为空       | 查找未填写或已填写的字段                           |

高亮模式不会隐藏非匹配项；此时全选可能包含这些镜头。只需匹配结果时，请切换到过滤模式后选择。

搜索框获得焦点时会显示最近搜索，可用上下方向键选择并按 Enter 使用。结果随输入更新；离开搜索框后保存最终的非空查询。最近搜索保存在当前电脑，字幕和分镜分别记录。

### 标记过滤

组合旗标、星级、色标和已编辑状态，逐步缩小范围。已编辑包括自定义标题、关键字和其他标记。

在关键字树中启用节点右侧的快捷过滤，可按分类筛选；同时启用多个节点时，结果须全部满足。详见[使用关键字](/storyboard/use-keywords)。

## 标记与批量审核

| 标记             | 用法                             |
| ---------------- | -------------------------------- |
| 标题             | 简短描述镜头，便于搜索与导出命名 |
| 星级             | 用 0–5 星记录质量或优先级        |
| 旗标             | 留用、排除或无旗标               |
| 色标与自定义标签 | 按工作约定分类；两者互斥         |
| 关键字           | 按人物、地点、动作等建立层级分类 |

单击已选镜头的文字单元格并稍候，或双击相应文字，编辑标题、关键字和标签。按 **Enter** 或移开焦点保存，按 **Esc** 取消。标题编辑只针对当前镜头。

选中多个镜头后，使用底部工具或右键菜单批量标注。对折叠堆叠操作时，应展开检查其成员是否都符合本次标记要求。

### 喷涂标记

1. 单击底部喷瓶，选择**关键字、标签、旗标**或**星级**。
2. 设置要应用的值，在镜头缩略图上单击或拖动。
3. 关键字、标签和旗标模式按住 **Alt** 可擦除；星级设为 0 可清除。
4. 关键字模式按住 **Shift** 可选择最近使用的关键字。
5. 单击完成或空喷瓶退出。

一次连续拖动可以整体撤销。退出喷涂后再进行普通选择。

## 组合和拆开镜头

### 合并镜头与堆叠

合并会移除镜头之间的切点，将范围作为一个镜头处理。堆叠则保留各镜头，以可折叠集合显示，适合将同一段落的画面集中浏览。

选择至少两个可组合镜头，使用右键菜单中的相应命令。跨多个视频选择时，合并与堆叠分别在各视频内进行；需要跨视频拼接时，使用合并导出。

### 使用堆叠菜单

| 命令                | 结果                         |
| ------------------- | ---------------------------- |
| 组成堆叠            | 将选择组成可折叠集合         |
| 展开 / 折叠堆叠     | 查看内部镜头或收起为代表项   |
| 展开全部 / 折叠全部 | 统一调整当前来源中的堆叠显示 |
| 从堆叠中移去        | 让所选成员恢复为独立镜头     |
| 拆分堆叠            | 以所选成员为界拆开分组       |
| 取消堆叠            | 解除整个分组                 |

## 删除与恢复

**删除**移除所选分镜并保留原时间位置。源监视器以斜线显示该区间，连续播放时会跳过；仍可手动定位，并从切点菜单恢复。

**波纹删除**让后续镜头起点前移，覆盖被删除区间，不提供相同的独立恢复入口。它不会删除源视频中的画面，也不会改写媒体文件。需要回退时使用撤销。

如果只是暂不采用某个镜头，设置排除旗标即可。恢复步骤见[恢复普通删除的分镜](/source/source-monitor#恢复普通删除的分镜)。

## 查看帧数据

右侧**帧数据**提供直方图和帧迹图。直方图用于查看当前画面的颜色分布；帧迹图可选择**动势、四色、清晰度**。暂停时将指针移到图表上可预览对应帧，单击可定位。

单击分组标题可收起图表，腾出整理空间。帧数据用于辅助审看，最终选择仍应结合实际画面。

整理完成后，参阅[导出媒体](/export/exporting)。
