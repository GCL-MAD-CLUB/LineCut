# 使用分镜

> 适用版本：LineCut 0.3.3。本文以 `release/0.3.3` 分支实现为准。

分镜把连续视频拆成可浏览和可整理的镜头条目。检测结果是编辑起点，不是不可修改的最终答案：你可以重新切分、调整选择、添加标记、建立堆叠，并把需要的镜头送入导出。

本页覆盖从生成分镜到完成镜头整理的完整流程。描述画面内容的层级关键字较为复杂，单独集中在“使用关键字”主题页中。

## 检测镜头切点

分镜检测把当前活动视频按检测到的镜头切点拆成连续分镜，帮助你按画面而不是台词整理素材。检测结果保存到项目中。

### 开始检测

1. 在媒体箱中选择在线、启用且具有视频流的视频；打开**分镜**面板并确认来源。
2. 在来源菜单勾选视频。新增来源若还没有分镜，会自动提交检测；已有分镜则直接显示，不会因勾选而覆盖。
3. 需要主动检测已选来源时，点击面板标题行最右侧的剪刀按钮“切分”或“重新切分”。该按钮处理当前勾选的全部合格视频。
4. 也可以在媒体箱中多选视频，右键选择**分镜识别**，批量为这些视频提交检测。
5. 顶部进度区显示运行与排队状态；完成后，结果写入对应视频的项目分镜，列表/图标区域即可浏览。

### 重新切分：合并、覆盖或取消

已有分镜（包括普通删除后保留的分镜）时，主动重新识别会先显示选择对话框：

| 按钮 | 结果                                                                       | 使用前应确认                     |
| ---- | -------------------------------------------------------------------------- | -------------------------------- |
| 合并 | 保留现有切分，把新识别到且不存在的切点加入现有有效镜头                     | 希望补充漏切点并保留已有人工整理 |
| 覆盖 | 用本次检测结果重建镜头，清空旧删除记录、堆叠和镜头标注，创建默认标题和标记 | 确实要放弃旧划分，已保存项目副本 |
| 取消 | 不执行这次请求，保留当前项目结果                                           | 尚未决定如何处理已有内容         |

合并通过分割已有镜头加入切点，新镜头沿用分割规则继承标注；已有切点不重复添加，删除区间不会被当作正常镜头重新生成。合并也会改变镜头数量和编号，完成后仍须检查标题、关键字、堆叠和边界。

批量请求中只要合格视频已有分镜，就会先询问处理方式。任务运行期间如果你又改动了相关镜头、删除记录、堆叠或标注，检测完成后会再次询问，避免旧请求的选择直接覆盖新编辑。取消该确认会丢弃本次检测结果，保留当前编辑。

### 检测条件与性能

- 检测必须在桌面应用中执行，来源须启用且原始文件在线。原始媒体脱机时，即使代理还能预览，也不能检测。
- 无合格来源或所有目标已在排队/运行时，按钮不可用；同一项目内同一视频的同一素材版本不会重复提交。
- 最多同时运行三项分镜检测；其余按队列等待。导入、分析、代理、导出等其他任务保留独占执行顺序，不能把“三个进度槽”理解成所有任务都可以并行。
- 检测使用本机 TransNetV2 模型。DirectML 推理可用时优先用 GPU，否则回退 CPU。Windows 帧提取另行请求 D3D11VA 硬件解码，两者是不同阶段，取决于驱动、FFmpeg 构建和源编码。
- 解码和推理以有界队列重叠运行。长视频、高分辨率、复杂编码和慢磁盘仍会增加耗时；文档不承诺固定倍数的速度提升。
- 取消或失败不会把半完成结果作为新分镜写入项目。一项失败不会自动取消其他视频；切换项目或替换素材后，不再适用的结果也不会写入新目标。

### 检测后应做什么

1. 在图标视图快速浏览，检查误切或漏切是否影响后续整理。
2. 用星级、旗标和关键字标记可用镜头。
3. 将需要作为一个整体使用的连续镜头堆叠。
4. 选择最终镜头并导出。

### 将检测结果视为起点

检测产生的是按时间连续的镜头基础划分，并不判断镜头是否“可用”、是否属于同一叙事段落，也不替你命名。检测完成后先在图标视图快速扫一遍，再对明显的误切、漏切或需要作为一个整体的连续画面作人工整理。

如果准备重新切分，先判断你的目的：只是整理镜头组时应使用堆叠；只有基础切点本身不可靠时才重新切分。重新切分的影响范围更大，完成后还要重新检查标题、关键字、筛选和待导出选择。

继续阅读[列表、图标与选择分镜](/storyboard/storyboards)和[堆叠、展开和拆分分镜](/storyboard/storyboards)。

## 浏览、搜索和选择分镜

### 列表和图标视图

分镜面板底部可以切换两种浏览方式：

- **列表视图**：显示标题、媒体开始/结束、持续时间、关键字、星级、留用和标签等列。单击表头可排序，拖动列分隔可调整宽度，双击分隔线恢复默认宽度。
- **图标视图**：以缩略图卡片快速浏览画面。可从排序菜单选择标题、时间、时长、关键字、星级、留用或标签作为排序依据。

在视频选择菜单中勾选多个视频后，两个视图会合并显示这些视频的分镜；列表视图会在**标题**左侧增加**来源**列。来源作为第一排序键，原有排序规则只用于每个来源内部。来源列可像其他列一样拖动列宽，双击分隔线恢复默认宽度；名称过长时自动换行，最多显示四行后才省略。搜索、过滤、选择、批量标记、删除、合并、堆叠和导出会统一作用于所有已选来源；单击某一行或卡片会把源监视器切换到对应的视频。

再次单击已勾选的视频可取消该来源，包括最后一个来源。全部取消后，面板显示**未选择**，列表和图标视图清空；重新勾选视频后仍可查看其分镜和标注。

两种视图可分别调整缩略图/图标大小，切换不会删除标记、关键字或分镜。

在图标卡片下方的信息区域右键，可选择显示**无**、**星级和标签**、**索引编号**、**标题**、**媒体开始**、**媒体结束**、**媒体时长**、**星级**或**标签**。该设置只改变图标视图的辅助信息，不会清除对应项目数据。

### 搜索范围和规则

分镜搜索不只限于文字标题。可先选择范围，再选择规则：

| 范围             | 搜索对象                 |
| ---------------- | ------------------------ |
| 任何可搜索的字段 | 标题和关键字等可搜索文本 |
| 标题             | 仅分镜标题               |
| 关键字           | 关键字路径和同义词       |

| 规则            | 行为                     |
| --------------- | ------------------------ |
| 包含            | 文本中含有输入内容       |
| 包含所有        | 同时包含输入中的各个条件 |
| 包含单词        | 以词为单位匹配           |
| 不含            | 排除含有输入内容的分镜   |
| 开头为 / 结尾为 | 匹配开头或结尾           |
| 为空 / 不为空   | 查找未填写或已填写的字段 |

“包含”会匹配任一输入词，“包含所有”和“包含单词”要求每个词都满足；“不含”要求所有输入词都不存在。“开头为/结尾为”按完整输入检查某一个可搜索字段。搜索会忽略大小写；关键字范围还会考虑有效父级路径和同义词。

### 过滤器和快捷关键字过滤

与字幕面板相同，分镜可组合按旗标、已编辑/未编辑、星级比较和色标过滤。“已编辑”表示分镜具有非零星级、旗标、自定义标题、关键字、色标或自定义标签中的至少一项。底部“仅展示选中分镜”可以临时只查看当前选择。

关键字树节点上的快捷过滤按钮会过滤拥有该关键字或其父级语义的分镜。多次启用快捷过滤时，结果需要满足所有启用的关键字条件。

### 选择方式

- 单击选择一个分镜，同时在源播放器跳转到该镜头。
- <kbd>Ctrl</kbd> + 单击添加或移除不连续选择。
- <kbd>Shift</kbd> + 单击选择从锚点到当前项的连续范围。
- 在空白区域拖拽框选可批量选择卡片或列表行；配合修饰键可以与原选择组合。
- 在面板获得焦点后，方向键移动当前选择；按住 <kbd>Shift</kbd> 扩展连续范围，<kbd>Ctrl</kbd>/Command + <kbd>Shift</kbd> 将范围加入原选择。图标视图的上/下方向键会按当前列数跨行移动。
- **编辑 → 全选**只选择当前筛选后可见的分镜；**编辑 → 取消选择**清空当前选择。

单击普通行或卡片会跳到镜头开始位置；单击缩略图画面或双击分镜会按完整镜头范围定位并开始范围预览。底部**更多选项**可分别显示或隐藏视图模式、选中、喷涂工具、排序、旗标、星级、色标和缩略图大小区域；隐藏控件不删除数据。

<GuideImage src="/images/storyboard/views-selection.png" alt="分镜列表的搜索、过滤与多选" />

选好分镜后，可以[标记分镜](/storyboard/storyboards)、[建立关键字](/storyboard/use-keywords)或进入导出工作区。

## 标记分镜

分镜标记保存到项目，帮助你表达镜头的用途和内容质量。它们不修改视频文件。

### 可用标记

| 标记       | 说明                                             |
| ---------- | ------------------------------------------------ |
| 标题       | 为镜头写简短描述，便于搜索、排序和导出命名       |
| 星级       | 0–5 星，适合表示质量或优先级                     |
| 旗标       | 留用、排除、无旗标，适合做候选/淘汰决策          |
| 色标       | 红、黄、绿、蓝、紫，可按团队约定分类             |
| 自定义标签 | 用于没有固定颜色含义的自由分类                   |
| 关键字     | 描述画面内容，支持父子关系和同义词，详见后续页面 |

色标和自定义标签互斥；设置其中之一时，另一个会被清除。

### 编辑标题和普通标记

1. 选择分镜。单击已选中的**标题**、**关键字**或**标签**单元格并稍候，或双击相应文字，进入编辑。
2. 标题输入非空文字；关键字按 `父>子`、`子<父`、`父|子` 和逗号规则输入；标签可输入预设颜色名称或任意自定义文字。
3. 按 <kbd>Enter</kbd> 或移开焦点保存；按 <kbd>Esc</kbd> 取消。关键字路径无效时会保留编辑状态并显示错误。
4. 星级、旗标和色标可用底部控件、缩略图控件或右键菜单设置；若点击的镜头属于当前多选，操作会应用到整个选择。
5. 在搜索和过滤器中验证标记结果。

标题只修改当前单个分镜。关键字和标签在折叠堆叠的代表项上操作时，会作用于该代表项包含的镜头集合；需要逐镜头不同值时，先展开堆叠。

快捷键与字幕标记一致：<kbd>P</kbd>/<kbd>X</kbd>/<kbd>U</kbd> 控制旗标，<kbd>0</kbd>–<kbd>5</kbd> 设置星级，<kbd>6</kbd>–<kbd>9</kbd> 设置红黄绿蓝色标，<kbd>[</kbd>/<kbd>]</kbd> 调整星级。

### 分镜喷涂工具

分镜喷涂支持**关键字、标签、旗标、星级**四种模式：

1. 点击底部喷瓶进入喷涂。
2. 选择模式和值，然后拖过连续镜头。
3. 关键字、标签和旗标模式按住 <kbd>Alt</kbd> 可擦除；星级模式直接选择 0 星来清除。
4. 关键字模式按住 <kbd>Shift</kbd> 会打开“最近使用过的关键字”九宫格；单击格子装入/移除喷瓶关键字，也可**全选**或**清除**。
5. 在镜头上按住并拖动完成一笔连续喷涂。
6. 点击“完成”或空喷瓶退出。

一次拖动会归为同一历史操作，方便整体撤销。

## 堆叠、展开和拆分分镜

堆叠将两个或更多分镜作为一个可折叠集合显示，适合把连续反应镜头、一个完整动作或同一段落的多个切点组织在一起。堆叠不会合并或重编码视频文件。

### 创建堆叠

1. 按时间顺序选择至少两个分镜。
2. 右键打开 **堆叠** 子菜单，选择**组成堆叠(G)**。
3. 堆叠在列表/图标中以一个入口表示，显示包含的分镜数量。

如果只选择一个分镜，不能创建堆叠。

### 展开与折叠

单击堆叠的展开/折叠控件，或使用右键子菜单中的**展开堆叠 / 折叠堆叠**，可在整体视图和内部各分镜之间切换。**展开全部堆叠(E)** 和**折叠全部堆叠(C)** 一次处理当前已选来源中的全部堆叠。展开状态只影响浏览，不改变堆叠成员、关键字或标记。

### 从堆叠中移除或拆分

- **从堆叠中移去(R)**：把所选成员恢复为独立分镜，其余成员仍可保持堆叠。
- **拆分堆叠(S)**：以所选堆叠成员为边界拆分现有堆叠，而不是简单删除所有分组。
- **取消堆叠(U)**：解除所选堆叠代表项对应的整个分组。

命令会根据当前选择自动禁用：不能把少于两个可组合镜头组成堆叠，未选择堆叠成员时不能移去或拆分，没有堆叠时也不能展开、折叠或取消。

### 删除与波纹删除

右键菜单还提供**删除**和**波纹删除**。它们修改项目中的分镜划分：

- **删除**移除所选分镜而保留后续镜头的时间位置。删除区间会保存在项目中，在源监视器时间线上以斜线显示，并在连续播放时自动跳过；
- **波纹删除**会让紧随删除区间的分镜起点前移以闭合空缺，并清理被删除镜头的标记。

普通删除保留被删分镜及其标记，以便从源监视器切点菜单恢复；保存并重新打开项目后恢复信息仍然存在。波纹删除不提供同样的切点恢复入口。在处理堆叠前先保存项目副本，并使用历史记录核对结果。

<kbd>Delete</kbd> 或 <kbd>Backspace</kbd> 执行普通删除，<kbd>Shift</kbd> + <kbd>Delete</kbd> 执行波纹删除。若只是暂时不导出镜头，请取消选择或设置排除旗标，不要删除。

具体恢复步骤见[恢复普通删除的分镜](/source/source-monitor#恢复普通删除的分镜)。

### 导出所选分镜

右键选择 **导出 → 导出(E)…** 可进入导出工作区；已有上次成功记录的设置时，可选择**使用上次设置导出(W)**直接加入导出队列。右键未选择的镜头时，该镜头会成为操作目标；右键当前多选中的镜头时，导出整个选择。

<GuideImage src="/images/storyboard/stacks.png" alt="展开和折叠的分镜堆叠" />

堆叠中的单个镜头仍可拥有独立[标题、标记和关键字](/storyboard/storyboards)。

## 多来源分镜与合并操作

在来源菜单沿项目媒体箱层级展开并勾选视频；文件夹上的圆点表示其后代存在已选来源，不表示点击文件夹会全选它。隐藏不等于禁用；是否能作为来源还取决于启用状态、视频流和原始媒体/代理的可用性。

多来源的**来源**列是第一排序键。单击来源表头可切换来源升序或降序。来源名称相同仍按独立来源处理；时间、时长、星级等只在每个来源内部排序。点击任一行或图标会切换到对应视频，不会把各视频拼接成一个可编辑时间线。

### 合并分镜与组成堆叠

在同一个视频选择至少两个镜头，右键执行**合并(M)**，会将选中镜头涉及的区间归并为镜头，保留左侧标题并按合并规则汇总标注。它改变项目划分，使用前应核对时间范围。**组成堆叠(G)**则组织可展开的镜头集合，保留成员的独立身份，不重编码源媒体。

多来源选择会按视频分别执行合并与堆叠：某个视频只有一个选中镜头时，该组不参与需要两个镜头的操作。只有每个视频都各选一条时，不能组成跨视频堆叠或跨视频合并镜头；至少一个来源有合格镜头组时，命令才可能可用。想将不同视频拼接为成片，应在导出中使用**合并为一个文件**。

### 搜索高亮和来源历史

分镜使用与字幕相同的**过滤 / 高亮**模式、八种搜索规则、匹配数量与序号输入，以及循环前后导航。分镜另外提供**任何可搜索的字段 / 标题 / 关键字**范围；关键字路径和同义词也参与匹配，因此某条结果匹配成功时，当前显示文本未必包含完全相同的词。

在匹配序号输入框填写目标序号后，按 Enter 或移开焦点提交，按 Esc 取消草稿；越界数值限制到 1 至匹配总数，没有匹配时不提供序号跳转。高亮不提供“不含”“为空”“不为空”，从这些规则切换高亮会恢复包含规则。

高亮模式只取消文本搜索对列表的隐藏作用；旗标、星级、颜色、编辑状态、快捷关键字过滤和仅展示选中分镜仍然生效。左右方向键在有效高亮导航状态下优先切换匹配项，图标/列表的一般选择操作见[键盘快捷键](/workspace/shortcuts)。

来源菜单旁的前后按钮切换来源选择历史；面板菜单可返回保存的来源工作区。这两套历史都不等于分镜编辑撤销，详见[来源工作区与导航历史](/workspace/workspace#来源工作区与导航历史)。

### 高亮导航会改变当前选择

切换为高亮或修改查询、规则（分镜还包括范围）后，有匹配时会自动定位首条匹配项，并把当前临时选择替换为该条。使用匹配前后导航或序号跳转，同样会替换为目标单条选择。先前手工选择的整批条目不会因导航而一直保留；准备导出时须重新核对并建立最终选择集合。

高亮且查询非空时，面板会优先处理规定焦点区域内无修饰键的左右方向键。没有匹配时按钮禁用、按键不能跳到结果；要恢复普通左右选择，切到过滤模式或清空查询。标题、标签等其他文字输入控件继续自行处理方向键。
