# 创建和管理关键字树

## 输入关键字和路径

在选定一个或多个分镜后，点击“单击此处添加关键字”输入框。可以一次输入多个关键字，使用英文逗号或中文逗号分隔。

| 写法                     | 含义                                              |
| ------------------------ | ------------------------------------------------- |
| `人物`                   | 添加一个顶级关键字                                |
| `人物>主讲人`            | 按“父 > 子”建立路径，并把最末级“主讲人”应用到分镜 |
| `主讲人<人物`            | 按“子 < 父”写同一条路径                           |
| `人物                    | 主讲人`                                           | 也可用竖线书写从父到子的路径 |
| `人物>主讲人, 地点>教室` | 一次添加两条路径                                  |

同一个值内不能混用 `>`、`<`、`|`。逗号、路径分隔符和星号不能成为关键字名称的一部分；出现空节点或混用分隔符时，输入框会显示错误，必须修正后才能提交。

## “键入关键字”与“关键字与父关键字”

关键字标记区右侧的编辑方式菜单提供两种显示：

- **键入关键字**：显示可编辑文本，可直接修改当前选中分镜的关键字集合。
- **关键字与父关键字**：以展开的层级文本显示，便于核对父级语义；此模式用于查看关系，新增仍可通过下方输入框完成。

多选分镜时，星号 `*` 表示某个标记只应用于其中一部分选择。编辑前先确认你是在替换共同集合，还是只添加新关键字。

## 用关键字树管理节点

1. 在“关键字列表”点击加号，或右键空白区域选择**创建关键字标记…**。
2. 填写关键字名称；同义词可用逗号或换行分隔。
3. 若从某节点的右键菜单创建，可勾选“置入‘该节点’中”成为子关键字。
4. 若已有分镜选择，可勾选“添加到选定的分镜”。
5. 右键节点可编辑名称和同义词、创建子节点、把节点加入/移出选定分镜，或删除节点。

树内可以拖动关键字节点改变层级位置；在筛选关键字时，树会自动展示匹配路径以便查找。

## 删除的影响

删除关键字节点会影响使用该节点及其子节点的分镜。删除前检查树中是否有子关键字、分镜是否仍需保留相关描述，并建议先保存项目副本。

## 快捷过滤和快捷关键字

树节点右侧的快捷过滤箭头可立即把该节点加入当前分镜过滤。右键节点的“设为快捷关键字”可把它带入关键字喷涂输入，方便连续标注。
