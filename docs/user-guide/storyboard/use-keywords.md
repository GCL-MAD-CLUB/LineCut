# 使用关键字

关键字用于描述镜头中“有什么”或“发生了什么”。它与表示质量的星级、表示取舍的旗标和表示流程状态的色标相互独立，并以项目级层级树保存在 `.lcp` 项目中。

一个分镜可以直接拥有多个关键字。关键字还可以包含父级、子级和同义词，因此你既能以“人物”查找一整类镜头，也能以“主讲人”查找更精确的子类。本页覆盖关键字的查看、创建、赋值、编辑、批量喷涂、筛选和删除。

## 打开和调整关键字面板

1. 在分镜面板右侧边缘单击展开按钮，显示关键字面板；再次单击可关闭。
2. 拖动分镜表格与关键字面板之间的竖向分隔线，调整两边宽度。窄屏时可先缩小分镜列宽，再给关键字树留出空间。
3. 单击面板顶部的**关键字**标题，可折叠或展开上方的关键字标记、建议和关键字集区域；下方关键字列表仍可独立使用。
4. **关键字标记**、**建议关键字**、**关键字集**和**关键字列表**各有自己的展开/折叠按钮。折叠只减少界面占用，不删除输入、节点或分镜赋值。

关闭整个关键字面板不会清除快捷过滤。若重新打开后发现分镜数量仍少于预期，检查树节点右侧是否仍有高亮的快捷过滤箭头。

## 开始前

使用关键字前需要满足以下条件：

1. 项目中至少有一个视频，并且已经完成分镜检测；
2. 顶部处于**编辑**工作区，分镜面板可见；
3. 分镜面板右侧的关键字面板已经展开；
4. 项目和媒体箱不是只读状态；
5. 至少选择一个分镜，才能把关键字赋给镜头。

没有选择分镜时仍可创建和整理关键字树，但“添加到选定的分镜”、关键字输入框和树节点勾选不可用。

## 理解关键字层级

### 父级、子级和直接关键字

下面的树包含两个顶级关键字和两个子关键字：

```text
人物
└─ 主讲人
地点
└─ 教室
```

把“主讲人”添加到分镜时，分镜直接保存“主讲人”，同时在搜索和筛选语义上属于父级“人物”。这种父级匹配由树关系推导，不需要再把“人物”重复添加到同一镜头。

界面以“子级在前”的形式显示完整路径，例如 `主讲人 < 人物`。输入路径时则可以使用更适合键入的父子顺序，详见后文。

### 同义词

同义词属于某一个关键字节点，用来吸收不同的检索说法。例如“主讲人”可以包含“讲师”和“老师”。搜索关键字时，LineCut 会同时考虑镜头的直接关键字、父级节点和这些节点的同义词。

同义词不会作为独立节点出现在关键字树中，也不会单独显示为镜头的直接关键字。需要独立统计、单独筛选或继续建立子级的概念，应创建为关键字节点，而不是同义词。

### 使用数量

关键字树右侧的数字表示该关键字在当前视频分镜中的有效使用数量。子关键字会让父关键字在语义上生效，因此父级的数量可能包含只直接赋予了子级的镜头。

## 查看分镜上的关键字

### 查看一个分镜

1. 在分镜列表或图标视图中单击一个镜头；
2. 展开关键字面板的**关键字标记**区域；
3. 在编辑方式菜单中选择：
   - **键入关键字**：显示并允许编辑镜头直接拥有的关键字；
   - **关键字与父关键字**：展开显示完整层级关系，仅用于核对语义。
4. 在关键字树中查看勾选状态和使用数量。

### 查看多个分镜

选择多个分镜后，关键字文本中的星号 `*` 表示该关键字只应用于部分选中镜头。例如 `主讲人<人物*` 表示当前选择中并非每个镜头都属于“主讲人”。

树节点可能出现三种状态：

| 状态 | 含义                                                 |
| ---- | ---------------------------------------------------- |
| 勾选 | 该节点直接应用于所有选中分镜                         |
| 减号 | 只应用于部分分镜，或通过子级让该父节点对部分镜头生效 |
| 空白 | 没有选中分镜直接使用该节点，也没有通过子级继承其语义 |

在多选状态直接编辑关键字文本前，先确认是否需要保留带星号的部分关键字。删除带星号条目会从原本拥有它的镜头中移除；去掉星号但保留名称，会把它补充到全部选中镜头。

## 将关键字添加到分镜

### 在输入框中添加

1. 选择一个或多个分镜；
2. 单击**单击此处添加关键字**；
3. 输入一个名称、一条层级路径，或用中英文逗号分隔的多个值；
4. 按 <kbd>Enter</kbd> 提交；
5. 检查关键字文本、树节点状态和使用数量是否更新。

输入不存在的路径时，LineCut 会创建缺失节点，并把路径最后一级添加到选中分镜。

| 输入                     | 结果                                               |
| ------------------------ | -------------------------------------------------- |
| `人物`                   | 创建或复用顶级“人物”，并添加到分镜                 |
| `人物>主讲人`            | 按“父 > 子”建立路径，并添加“主讲人”                |
| `主讲人<人物`            | 用“子 < 父”的写法表达同一条路径                    |
| `人物\|主讲人`           | 用竖线按“父到子”建立同一条路径                     |
| `人物>主讲人, 地点>教室` | 一次创建或复用两条路径，并把两个末级节点添加到分镜 |

同一个值中不能混用 `>`、`<` 和 `|`。逗号、路径分隔符和星号不能成为关键字名称的一部分；连续分隔符会产生空节点。输入无效时，控件会显示错误，修正后才能提交。

### 从建议关键字添加

**建议关键字**根据项目中的真实使用次数和近期使用情况排列，并排除当前选择已经有效拥有的关键字。

1. 选择目标分镜；
2. 展开**建议关键字**；
3. 单击一个建议项，将其添加到全部选中分镜；
4. 再次检查树状态或用搜索验证结果。

建议只帮助重复已有分类，不会自动分析画面内容，也不会凭空创建新的关键字。

### 从最近使用的关键字添加

**关键字集 → 最近使用过的关键字**显示最近直接使用的有效节点。单击某一格可在“添加到全部”和“从全部移除”之间切换。

关键字面板处于活动状态、最近使用区域已展开且没有菜单或对话框遮挡时，可以按住 <kbd>Alt</kbd> 显示九宫格提示，再按数字快速添加：

```text
7 8 9
4 5 6
1 2 3
```

焦点位于文本输入框、同时按下 Ctrl/Command，或当前没有选择分镜时，数字快捷操作不会触发。

### 从关键字树添加

可以使用以下任一方法：

- 单击节点左侧复选框；
- 右键节点并选择**将此关键字添加到选定分镜**；
- 从分镜缩略图上的关键字标记开始拖动，把一个或多个已选分镜拖到关键字树中的目标节点；拖到树的空白区域则不赋值。

向堆叠代表镜头喷涂或赋值时，操作可能作用于该选择所代表的镜头集合。完成后展开堆叠核对每个成员，而不要只看堆叠封面。

## 直接编辑当前关键字集合

“键入关键字”模式允许一次替换当前选择的直接关键字集合：

1. 单击关键字文本区域进入编辑；
2. 用逗号分隔需要保留或新增的路径；
3. 多选时，保留原有 `*` 可让部分关键字保持原分布；
4. 按 <kbd>Enter</kbd> 或移开焦点提交；
5. 按 <kbd>Esc</kbd> 取消本次文本修改并恢复原值。

这与下方“添加关键字”输入框不同：添加输入框只追加；直接编辑会协调整个集合，删除的条目会从相应镜头移除。

## 创建关键字标记

<GuideImage src="/images/storyboard/keyword-management.png" alt="创建关键字标记对话框与树右键菜单" />

### 创建顶级关键字

1. 在**关键字列表**标题栏单击加号，或右键树节点并选择**创建关键字标记…**；
2. 输入非空名称；
3. 可选：用逗号、中文逗号或换行分隔同义词；
4. 不勾选“置入某关键字中”，使其成为顶级节点；
5. 若已有分镜选择，可勾选**添加到选定的分镜**；
6. 单击**创建**。

同一父级下不能存在两个同名节点。不同父级下可以使用相同名称，因为它们的完整路径不同。名称重复时，LineCut 会保留对话框内容并要求换名。

### 创建子关键字

以下方式都可以指定父级：

- 右键父节点，选择**在“父节点”中创建关键字标记…**；
- 选中父节点后打开创建对话框，并勾选**置入“父节点”中**；
- 右键父节点启用**将新关键字置入到该关键字中**。节点旁出现圆点后，后续普通创建会默认置入该节点，直到再次取消。

提交前检查对话框显示的父级名称。过滤树、切换选择或连续创建时，不要仅凭视觉缩进推断父级。

## 编辑和查找关键字节点

### 重命名或修改同义词

1. 右键节点，选择**编辑关键字标记…**；
2. 修改名称或同义词；
3. 按 <kbd>Enter</kbd> 或单击**存储**；
4. 若同一父级已有同名节点，换用其他名称后重试；
5. 用分镜搜索验证新名称和同义词。

重命名会更新引用该节点的镜头显示，不需要重新赋值。编辑同义词不会生成新的树节点。

### 当前不能移动节点

当前版本没有用于修改现有关键字父级的拖拽或“移动到”命令。分镜可拖到关键字节点进行赋值，但拖动关键字树节点本身不会改变层级。若创建时放错父级，应在正确位置新建节点、把它添加到需要的分镜、移除旧关系，再删除错误节点；执行批量替换前先保存项目副本。

### 选择多个树节点

- 单击：只选择当前节点；
- <kbd>Ctrl</kbd>/Command + 单击：添加或移除不连续节点；
- <kbd>Shift</kbd> + 单击：按当前可见顺序选择连续范围。

树被过滤或部分节点折叠时，Shift 范围只基于当前可见节点。多选后可以批量删除或一起拖动。

### 过滤关键字树

在**过滤关键字**中输入文字，可按节点名称和完整路径缩小树。匹配结果的祖先会自动显示，便于看清层级。

过滤树只改变关键字列表的可见节点，不会过滤分镜。要过滤镜头，使用树右侧快捷过滤箭头或分镜搜索框。

### 展开和折叠树节点

单击节点名称左侧的小箭头可展开或折叠子级；叶节点没有可展开内容。输入“过滤关键字”时，匹配节点的祖先会临时展开以显示路径；清空过滤后恢复手动折叠状态。折叠节点不会停用其子级关键字、改变使用数量或影响搜索语义。

## 从分镜移除关键字

以下操作只解除镜头与节点的关系，不删除树节点：

- 在“键入关键字”模式中删除对应条目并提交；
- 取消树节点左侧复选框；
- 右键节点选择**从选定的分镜中移去此关键字**；
- 在关键字喷涂模式按住 <kbd>Alt</kbd> 擦除。

从镜头移除子关键字后，由它产生的父级语义也会消失；如果镜头还直接拥有父节点或另一个同父级子节点，父级仍可能有效。

## 删除关键字节点

删除节点会从关键字树中移除该节点及其后代，并从使用它们的分镜解除相应关系：

1. 在树中选择一个或多个节点；
2. 单击标题栏减号，或右键选择**删除…**；
3. 阅读确认框中的使用数量与子级警告；
4. 确认确实要删除分类本身，而不只是从当前分镜移除；
5. 单击**删除**。

没有被使用的单个节点会直接删除；正在使用的节点和批量选择会要求确认。误删后应立即使用撤销，并检查历史记录；在大范围调整树之前，优先保存项目副本。

## 使用快捷关键字和喷涂工具

### 设置快捷关键字

右键一个树节点，选择**设为快捷关键字**。节点旁会显示加号，分镜底部关键字喷涂输入会同步采用它的完整路径。再次选择同一命令可取消。

### 装入多个喷涂关键字

1. 在分镜底部启用喷瓶；
2. 将“喷涂”模式设为**关键字**；
3. 在输入框键入一条或多条有效路径；
4. 或按住 <kbd>Shift</kbd> 打开最近使用关键字九宫格；
5. 在九宫格中逐项切换，也可使用**全选**或**清除**；
6. 松开 Shift，确认喷瓶中显示的是本轮需要的关键字集合。

### 批量添加或擦除

1. 先在一个测试镜头的缩略图上单击，确认赋值正确；
2. 按住鼠标左键拖过连续镜头缩略图；
3. 同一笔划经过的每个镜头只处理一次；
4. 按住 <kbd>Alt</kbd> 再单击或拖动，可从镜头移除喷瓶中的关键字；
5. 点击空喷瓶图标退出喷涂。

一次连续笔划归入同一历史操作，适合整体撤销。喷涂期间普通单击选择会被抑制，应先退出喷涂再改变选择或打开右键菜单。

## 使用关键字搜索和筛选分镜

### 按文字搜索

1. 在分镜搜索框将范围设为**关键字**，或使用**任何可搜索的字段**；
2. 选择“包含”“包含所有”“不含”“开头为”“结尾为”“为空”或“不为空”等规则；
3. 输入节点名称、完整路径或同义词；
4. 检查结果数量，再组合旗标、星级、色标或编辑状态过滤器。

“包含所有”要求输入条件全部匹配；“为空”适合找出尚未标注关键字的镜头。

### 使用树节点快捷过滤

单击树节点最右侧的箭头可启用快捷过滤。筛选会匹配直接拥有该节点或通过子级继承其语义的分镜。

同时启用多个节点时采用“并且”关系。例如同时启用“人物”和“教室”，只显示既属于人物、又属于教室的镜头。再次单击箭头取消该条件。

## 推荐的分类方法

为避免树在项目后期失控，可以从少量稳定顶级分类开始：

```text
人物 > 主讲人 / 嘉宾 / 观众
地点 > 教室 / 室外 / 演播室
景别 > 特写 / 中景 / 全景
动作 > 讲话 / 行走 / 演示
```

- 用父级表达长期稳定的维度，用子级表达具体值；
- 同一个概念只保留一个正式节点，口语差异放入同义词；
- 不要把“好镜头”“待审核”建成关键字，优先使用星级、旗标或色标；
- 先在少量镜头试用分类，再批量喷涂；
- 定期过滤未使用或低使用节点，确认后再删除。

## 常见问题

### 输入后没有添加

- 确认已选择分镜且项目可编辑；
- 检查是否混用了多个路径分隔符；
- 检查路径中是否存在空名称；
- 按 Enter 提交，而不是只把文字留在输入框中。

### 搜索父关键字却找不到镜头

- 确认子节点仍位于预期父级下；
- 确认使用的是分镜搜索而不是“过滤关键字”树输入框；
- 清除其他快捷关键字、旗标、星级或色标过滤条件；
- 用“关键字与父关键字”模式核对层级。

### 多选后误改了部分关键字

星号表示只应用于部分选择。立即撤销，然后重新选择镜头；若只想追加关键字，使用下方添加输入框或树节点，不要直接改写整个关键字文本。

### 删除节点的影响超出预期

删除父节点会连同后代一起删除。立即撤销并检查历史记录；恢复后先把需要保留的子节点移动到其他父级，再删除空节点。
