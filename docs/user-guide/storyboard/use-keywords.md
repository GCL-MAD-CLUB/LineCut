# 使用关键字

关键字描述画面中的人物、地点、景别和动作，便于反复查找素材。它与星级、留用旗标配合使用：关键字描述内容，标记帮助决定是否采用。

关键字由你创建和分配，不会因语义搜索自动生成。项目中的同一分类可用于多个视频。

## 规划分类

从少量稳定的分类开始，例如：

| 分类 | 示例               |
| ---- | ------------------ |
| 人物 | 主讲人、嘉宾、观众 |
| 地点 | 教室、室外、演播室 |
| 景别 | 特写、中景、全景   |
| 动作 | 讲话、行走、演示   |

同一个概念只保留一个常用名称，其他叫法放入同义词。先在少量镜头上试用，再批量应用。

## 为分镜添加关键字

1. 在分镜面板选择一个或多个镜头。
2. 在右侧关键字区域单击**单击此处添加关键字**。
3. 输入名称或路径，如“人物 > 嘉宾”；多个路径用逗号分隔。
4. 按 **Enter** 提交，查看镜头关键字和树中的勾选状态。

输入不存在的路径时，会创建相应分类。支持“父 > 子”“子 < 父”或竖线分隔的父子路径；同一条路径不要混用分隔符。名称不得为空，也不能包含路径分隔符、逗号或星号。

也可勾选关键字树节点，或右键选择**将此关键字添加到选定分镜**。拖动分镜的关键字标记到树节点，也可赋予该分类。

## 读取关键字状态

- 子关键字也属于它的父级分类；为镜头添加“人物 > 嘉宾”后，可通过“人物”找到它。
- 多选镜头时，星号表示该关键字只出现在部分选择中。
- 在不同显示方式中可查看直接关键字或包含父级的完整分类。

直接编辑当前关键字文本会替换相应集合，移除的文字可能同时移除已有赋值。只想追加时，请使用下方添加框或树节点。多选编辑时，保留星号可保留部分赋值的原分布。

## 创建和编辑分类

### 创建分类

1. 单击**关键字列表**标题栏加号，或右键选择**创建关键字标记…**。
2. 输入名称，可按需填写同义词。
3. 需要子分类时，确认**置入某关键字中**及父级名称。
4. 可勾选**添加到选定的分镜**，再单击**创建**。

同一父级下不能使用重复名称。右键父节点可直接在其中创建；启用**将新关键字置入到该关键字中**后，后续创建默认采用该父级，使用完毕后可取消。

### 修改名称与同义词

右键节点，选择**编辑关键字标记…**。修改后单击**存储**。同义词可用逗号或换行分隔，方便按不同叫法搜索。

重命名影响项目中使用该分类的所有视频。批量调整前请保存副本。

### 更正父级

不提供直接移动已有节点的命令。创建时父级选错，应在正确位置新建分类，添加到所需镜头，再移除旧赋值，最后删除错误分类。

## 重复使用常用关键字

**建议关键字**和**最近使用过的关键字**方便重复添加已有分类。选择镜头后单击建议或最近项，完成后核对赋值。

右键树节点可**设为快捷关键字**。批量标注时：

1. 开启底部喷瓶，将模式设为**关键字**。
2. 输入路径，或按住 **Shift** 从最近关键字中选择。
3. 在镜头缩略图上单击或连续拖动。
4. 按住 **Alt** 单击或拖动可擦除。
5. 单击空喷瓶退出。

一次连续拖动可整体撤销。对折叠堆叠赋值后，应展开确认成员是否符合本次分类。

## 搜索与过滤

**过滤关键字**仅缩小树中的节点显示，不改变分镜结果。展开或折叠节点也不改变已有赋值。

要筛选镜头，请使用以下方式：

- 在分镜搜索中选择**关键字**范围，输入名称、完整路径或同义词。
- 单击节点右侧快捷过滤箭头，筛选属于该分类的镜头。
- 同时启用多个节点时，结果须满足全部分类。
- 再组合星级、旗标或色标，找到符合用途的候选镜头。

父级分类也可找到具有相应子关键字的镜头。高亮模式下，同义词命中不一定在可见文字中显示相同字符，应结合匹配计数核对。

## 移除赋值与删除分类

从镜头移除关键字：取消节点勾选，或右键选择**从选定的分镜中移去此关键字**。分类仍保留，可供其他镜头使用。

删除分类：选择树节点，单击减号或右键选择**删除…**。删除父节点会连同其子分类和相关赋值一起移除；先阅读使用数量与确认提示。

误操作后立即撤销。不需要改变其他镜头时，应移除当前赋值，而不是删除整个分类。
