# 关键字系统概览

关键字用于描述“画面是什么”，与表达质量的星级、表达去留的旗标相互独立。LineCut 的关键字是项目级层级树：一个关键字可以有父级、子级和同义词；一个分镜可以拥有多个关键字。

## 父级与子级

例如建立如下树：

```text
人物
└─ 主讲人
地点
└─ 教室
```

把“主讲人”加到镜头后，该镜头在关键字过滤和搜索语义上也属于“人物”。这让你既能搜精确子类，也能用父类获得更宽的结果。

## 分镜上显示的关键字

分镜直接保存的是你指定的关键字节点。界面会把它显示为层级路径，例如 `主讲人 < 人物`。父级由路径关系推导出来，不需要每次重复添加。

## 添加关键字的三种途径

1. 在“关键字标记”输入框键入名称或路径；必要节点会自动创建。
2. 在关键字树中勾选/右键，把现有关键字添加到选定分镜。
3. 使用建议关键字、最近使用关键字，或关键字喷涂应用到多个镜头。

## 同义词

同义词属于一个关键字节点，用来吸收不同的检索说法，而不是创建重复分类。例如“主讲人”的同义词可包含“讲师”“老师”。对关键字搜索而言，分镜会匹配该节点及其父级节点的同义词。

## 建议、最近使用和快捷过滤

- **建议关键字**综合近期使用和实际分镜使用情况，帮助你快速重复标注。
- **最近使用过的关键字**显示近期直接使用的项目关键字。
- 每个树节点的快捷过滤按钮可将其加入分镜过滤条件；多个快捷条件同时开启时，结果必须满足全部条件。
