# 使用字幕

> 适用版本：LineCut 0.3.3。本文以 `release/0.3.3` 分支实现为准。

字幕不仅用于观看台词，也是 LineCut 定位内容和收集片段的主要入口。一个完整的字幕工作流通常包含：选择正确的字幕轨，缩小结果范围，标注候选台词，选择片段，然后交给导出工作区。

本页按这个顺序集中说明所有字幕操作。外部字幕尚未绑定、字幕轨为空或时间范围异常时，请先处理轨道与媒体关系，再进行搜索和导出。

## 字幕轨与字幕显示

字幕面板显示已选视频可见的字幕轨。字幕来源可以是视频内嵌流，也可以是单独导入并绑定到该视频的外部字幕文件。

### 选择字幕轨和来源

1. 在媒体箱激活目标视频。
2. 打开**字幕**面板。
3. 打开来源选择菜单，单击有右侧箭头的视频展开字幕轨，再勾选轨道；视频和文件夹用圆点表示其下有已选来源。无字幕轨的视频没有展开箭头，可直接勾选视频项。轨道会显示可用的语言、标题、来源或流信息。
4. 需要跨媒体检索时，在同一菜单中勾选其他视频的字幕轨。再次单击已勾选的轨道或无字幕轨的视频可取消选择，包括最后一个来源；全部取消后，面板显示**未选择**。
5. 检查列表中的文字和时间范围是否与画面匹配。

同一视频在该面板中一次只能选择一条字幕轨；勾选它的另一条轨道会替换旧轨道，不会同时显示该视频的两条轨道。单选时列表只显示该轨道。勾选多个来源后，标题左侧会出现**来源**列，来源排序默认为正序，此时来源作为第一排序键，原有列排序只在每个来源内部生效；将来源排序设为“无”后，其他列会跨来源统一排序。搜索、过滤、筛选、批量标记、删除和导出会统一作用于所有已选来源；单击任一行仍会把源监视器切换到该行的媒体与轨道。来源列只在多选时出现，单选后的操作方式与以前相同。来源列可像其他列一样拖动列宽，双击分隔线恢复默认宽度；名称过长时自动换行，最多显示四行后才省略。

不同来源的字幕条目即使编号相同也保持独立。临时搜索、过滤和选择在同一面板会话中按来源工作区及来源组合缓存，返回同一组合时可恢复；新建工作区不保证沿用另一工作区的临时视图。长期标注则按各媒体与字幕轨写入项目。

### 内嵌字幕与外部字幕

| 字幕来源   | 如何出现                                                  | 适用情况                       |
| ---------- | --------------------------------------------------------- | ------------------------------ |
| 内嵌字幕流 | 选中视频后，直接选择可读字幕轨；也可在媒体箱分解流        | 视频文件本身含多语字幕或字幕流 |
| 外部字幕   | 导入 `SRT`、`ASS`、`SSA`、`VTT` 或 `WebVTT`，再绑定到视频 | 字幕文件与视频分开保存         |

外部字幕未绑定到当前视频时，可能不会在其字幕面板出现。请按[绑定音频和字幕到视频](/media/tracks-binding)处理。

### 字幕条目包含什么

每条字幕有开始和结束时间、原始文本和用于搜索的纯文本；部分轨道还提供说话人、样式或层级信息。列表中可显示缩略图、星级、旗标、色标和自定义标签。

如果字幕轨带有提示或警告，字幕面板会在列表上方显示。常见原因包括解析格式限制、位图字幕不能像文本字幕一样检索，或时间信息存在异常。

## 搜索、过滤和排序字幕

### 文本搜索

字幕面板顶部的统一搜索栏包含输入框、**模式**、匹配导航、**规则**和选择数量摘要。输入立即生效，无须按 Enter。搜索作用于当前已选来源，不会自动检索项目里尚未勾选的视频。

搜索范围包含字幕纯文本、说话人、样式以及当前色标或自定义标签。搜索忽略大小写；多个条件按文字、数字和下划线组成的词拆分。中文连续文字不会自动进行自然语言分词：例如“重新开始”是一个连续条件，需要两个条件时可输入“重新 开始”。搜索不是正则表达式输入框。

| 模式 | 显示与操作结果                                                               |
| ---- | ---------------------------------------------------------------------------- |
| 过滤 | 只显示满足文本搜索和其他过滤器的字幕；全选作用于这些可见结果                 |
| 高亮 | 保留满足其他过滤器的全部字幕，对匹配文字高亮；非匹配字幕仍可见，也可能被全选 |

清空输入会取消文本词匹配限制，但不会关闭星级、旗标、颜色、编辑状态或“仅查看已选字幕”等其他条件。规则为“为空/不为空”时，即使没有输入文字也会继续检查字段是否为空。

### 语义搜索

将搜索栏的**模式**设为**语义**，输入要寻找的意思或描述。搜索只处理当前已选来源的字幕纯文本。首次搜索会将缺少索引的字幕登记为后台任务，任务栏实时显示构建进度；期间仍可进行其他操作。索引存放在首选项缓存目录下的 `semantic-search` 文件夹，按字幕文件或字幕轨保存并用内容 hash 校验。例如 A 已有索引，选择 A+B 时只补建 B；修改字幕内容后重建对应文件的索引。

语义模式下，左右导航按钮替换为匹配度阈值滑动条及输入框。阈值范围为 0 到 1，默认 0.50；尚无搜索结果时控件置灰，有结果后可拖动滑块，或输入数字后按 Enter、移开焦点筛选。阈值越高，保留的结果越少。文字匹配规则不参与语义搜索，其他过滤器继续生效。

语义查询非空时，字幕文本右侧立即增加可调整宽度的**匹配度**列。等待索引或结果时显示 `-`，沿用原排序；结果产生后自动按匹配度降序排列，并将来源排序设为“无”，使不同视频的结果按匹配度统一排序。单击其他列可切换普通排序，也可手动恢复来源正序或倒序。清空查询恢复全部字幕，切换回过滤或高亮模式会隐藏匹配度列。

修改查询或切换作用域不会取消正在构建的索引。任务完成后，若当前仍有语义查询，使用此刻的查询搜索；作用域已改变时，为当前作用域创建不重复的任务并复用已有文件索引。若已离开语义模式或查询为空，则不继续检索。主动取消任务时，只有当前作用域与查询均和任务创建时一致才会清空搜索框；否则保留当前状态，按需继续新任务。

推理在本机执行，使用 Jina INT8 模型，不上传字幕。开发环境须先执行 `npm run prepare:transnetv2` 和 `npm run prepare:semantic` 准备运行库与模型；发布包在构建时自动准备资源。

### 搜索规则

| 规则            | 判断方式                              | 高亮模式 |
| --------------- | ------------------------------------- | -------- |
| 包含            | 任一输入词出现在可搜索字段中          | 可用     |
| 包含所有        | 所有输入词均出现，可分布在不同字段中  | 可用     |
| 包含单词        | 所有输入词都按完整词边界出现          | 可用     |
| 不含            | 所有输入词都未出现                    | 不可用   |
| 开头为 / 结尾为 | 某一非空字段以完整输入开始或结束      | 可用     |
| 为空 / 不为空   | 全部可搜索字段为空 / 至少一个字段非空 | 不可用   |

“包含单词”按 Unicode 字母、数字和下划线判断边界，并非任意中文词语分词。“为空”检查的是全部可搜索字段：字幕文字为空但样式或标签非空时，仍不符合为空。高亮模式不提供“不含”“为空”“不为空”；从这些规则切换到高亮时会恢复到可高亮的包含规则。

### 高亮匹配项导航

1. 输入关键词，将**模式**设为**高亮**，必要时选择更严格的规则。
2. 使用搜索栏的**上一个搜索项 / 下一个搜索项**按钮逐条定位。导航按当前显示顺序进行，到末尾后循环到开头，反向亦然。
3. 搜索栏显示当前匹配项序号与总数；单击序号输入目标数字，按 Enter 或移开焦点确认，按 Esc 取消。超出范围的数字会限制在 1 到匹配总数之间。
4. 导航会让对应字幕进入可见区域，并让源监视器定位到该条目的媒体和时间；一个条目包含多个命中文字仍计为一条结果。
5. 在高亮模式且存在有效匹配时，聚焦搜索框、字幕行或面板后，可以用不带修饰键的左/右方向键导航匹配项。其他文本编辑框不会被该导航接管。

没有输入内容、没有匹配结果或处于过滤模式时，导航按钮禁用。仅看见高亮或把结果定位到播放器，并不等于已经勾选完整导出集合；导出前核对选择摘要和来源列表。

### 查看列表列并调整列宽

字幕列表可以显示缩略图、字幕文本、媒体开始、媒体结束、媒体持续时间、星级、留用状态和标签。多选来源时，字幕文本左侧还会显示**来源**列：

- 单击字幕、开始时间、结束时间、持续时间、星级、留用或标签表头可按该列排序；
- 再次单击当前排序列切换升序和降序；
- 多选来源时，单击**来源**表头按**正序 → 倒序 → 无 → 正序**循环；正序或倒序时来源是第一主键，“无”时不参与排序，也不显示箭头；
- 拖动表头分隔线调整列宽；
- 双击分隔线恢复该列默认宽度；
- 横向滚动时，缩略图列保持固定，其他列随列表移动。

单击字幕文本、时间或标签单元格会把它设为活动单元格，但不会修改字幕原文和时间码。双击字幕行的普通区域会让源监视器以该字幕的完整起止范围定位预览。

### 仅查看已选字幕

开启“仅查看已选字幕”后，列表只显示当前勾选的字幕。这是检查准备导出范围的快捷方式，不会删除未选条目，也不会改变项目中的星级、旗标或色标。

### 过滤器

过滤器可以组合使用；满足所有已启用条件的字幕才会显示。

| 类别 | 可用条件                                       |
| ---- | ---------------------------------------------- |
| 旗标 | 留用、无旗标、排除                             |
| 编辑 | 已编辑、未编辑                                 |
| 星级 | 选择星级，并用“大于等于 / 小于等于 / 等于”比较 |
| 颜色 | 红、黄、绿、蓝、紫、自定义、无                 |

“已编辑”指该字幕已经拥有项目标注，例如星级、旗标、色标或自定义标签；它不表示修改了字幕原文。

### 排序

可从底部“排序依据”菜单改变列表顺序，并通过方向按钮切换升序/降序。列表表头中的可排序列也能快速切换相应排序方式。排序只改变浏览顺序，不改写字幕时间码或导出媒体内容。

### 缩略图大小与显示区域

底部控件可以调整字幕缩略图大小。更多选项菜单还可控制选择、喷涂工具、排序、旗标、星级、色标和缩略图大小这些底部区域是否显示；隐藏控件不会移除相应功能。

## 星级、旗标和色标

字幕标注会保存到项目中，可在以后重新打开项目后继续过滤和导出。它们不会改写原始字幕文件。

### 标记类型

| 标记       | 可选值                 | 建议用途                               |
| ---------- | ---------------------- | -------------------------------------- |
| 星级       | 0–5 星                 | 表达内容质量、优先级或适用程度         |
| 旗标       | 留用、排除、无旗标     | 表达是否应该进入候选输出               |
| 色标       | 红、黄、绿、蓝、紫、无 | 按团队约定进行分类                     |
| 自定义标签 | 任意简短文字           | 记录项目特有的分类，例如“开场”“需复核” |

色标和自定义标签是互斥的视觉标签：给条目写入自定义标签会清除它的色标，选择色标也会清除自定义标签。

### 给一条或多条字幕标记

1. 在列表或缩略图中选择字幕。可用 <kbd>Ctrl</kbd> 添加不连续选择，或用 <kbd>Shift</kbd> 选择范围。
2. 使用底部旗标、星级、色标控件，或右键菜单设置标记。
3. 用过滤器检查同一类标记是否一致。

快捷键也可用于当前焦点条目：<kbd>P</kbd> 留用、<kbd>X</kbd> 排除、<kbd>U</kbd> 清旗标；<kbd>0</kbd>–<kbd>5</kbd> 设星级；<kbd>6</kbd>–<kbd>9</kbd> 设红黄绿蓝色标。

按住 <kbd>Shift</kbd> 或开启 <kbd>Caps Lock</kbd> 再使用标注快捷键，会在写入标记后自动前进到下一项，适合逐条审核。鼠标按钮和右键菜单不会触发这种自动前进。

列表行上的星级、旗标和标签按钮直接操作该行；如果该行已经属于多选，则操作应用到整个选择。右键菜单提供同样的旗标、0–5 星、提升/降低星级和色标选项。

### 编辑自定义标签

1. 先选择一条字幕；
2. 单击标签单元格并稍候，或双击当前标签文字；
3. 输入简短标签；
4. 按 <kbd>Enter</kbd> 或移开焦点保存，按 <kbd>Esc</kbd> 取消；
5. 输入恰好与预设颜色名称一致的文字时，会转换为对应色标；其他文字保存为自定义标签。

空标签会清除自定义标签。色标和自定义标签共用同一视觉位置，因此设置其中一种会替换另一种。

### 与“选择”区分

- **选择（勾选）**：用于当前批次的查看或导出，属于临时操作状态。
- **星级 / 旗标 / 色标 / 自定义标签**：用于长期整理，写入项目文件并可作为过滤条件。

不要仅因要导出一次就把所有字幕都设为留用旗标；如果它们不代表长期“可用”判断，单纯选择即可。

## 使用喷涂工具批量标注

喷涂工具用于连续浏览字幕时快速给多条字幕添加同一种标记。它适合审片式整理，不适合需要逐条确认不同值的复杂标注。

### 启用并选择喷涂属性

1. 在字幕面板底部点击喷瓶图标，进入喷涂状态。
2. 使用“喷涂”下拉控件选择**色标/自定义标签**、**旗标**或**星级**。
3. 按模式设置具体值：
   - 色标：选择颜色，或输入自定义喷涂标签；
   - 旗标：选择留用或排除；
   - 星级：选择 0–5 星。
4. 在字幕行上按住鼠标左键并拖过目标条目。
5. 点击空喷瓶图标或**完成**退出喷涂。

### Alt 擦除

色标/自定义标签和旗标喷涂支持按住 <kbd>Alt</kbd> 擦除：

- 色标或自定义标签会被清除；
- 旗标会恢复为“无旗标”。

星级模式不使用 Alt 擦除；请直接喷涂 0 星或改用普通星级控件。

### 注意事项

- 一次连续拖动会被视为同一组项目历史，方便一次撤销。
- 每条经过的字幕在一次笔划中只会处理一次，即使鼠标来回经过。
- 喷涂状态下正常的单击选择会被抑制，先退出喷涂再做范围选择或打开右键菜单。

### 使用前、使用中、使用后

**使用前**，先用搜索或过滤缩小到确实需要审核的字幕，并明确本轮是在做“留用/排除”、质量评分还是内容分类。色标和自定义标签互斥；选择其中一个会清除另一个，所以不要把两种语义混在同一次喷涂中。

**使用中**，先在一条测试字幕上单击确认颜色、旗标或星级值，再拖过连续条目。拖动结束后不要立即开始第二个语义不同的笔划；先核对可见行的标记结果。

**使用后**，可按旗标、色标、星级或自定义标签过滤结果。发现整笔错误时优先使用一次撤销；逐条反向喷涂只适合少量修正。

## 选择字幕并导出

### 选择字幕

在字幕列表或缩略图中单击可选择条目；使用 <kbd>Ctrl</kbd> 选择多个不连续条目，使用 <kbd>Shift</kbd> 选择连续范围。底部会显示“已选择 / 可见总数”摘要。

可使用 **编辑 → 全选**、<kbd>Ctrl</kbd> + <kbd>A</kbd> 选择当前可见结果，使用 **编辑 → 取消选择** 或 <kbd>Ctrl</kbd> + <kbd>Shift</kbd> + <kbd>A</kbd> 清空选择。若先使用搜索或过滤，全选只作用于当前显示的字幕。

还可以从列表空白处拖出选择框：

- 直接框选会用框内字幕替换原选择；
- <kbd>Shift</kbd> + 框选会把框内字幕加入原选择；
- <kbd>Ctrl</kbd>/Command + 框选会切换框内每一项的选中状态；
- 在空白处单击且未按修饰键会清空选择。

面板获得焦点后，四个方向键都可移动到上一条或下一条字幕，并让源监视器定位；按住 <kbd>Shift</kbd> 扩展连续范围，<kbd>Ctrl</kbd>/Command + <kbd>Shift</kbd> 把新范围加入原选择。单独按 <kbd>Ctrl</kbd>/Command + 方向键不会移动选择。

单击缩略图会选择字幕并让源监视器定位到字幕范围；单击普通行主要定位到开始位置，双击普通行明确以完整范围预览。底部“仅展示选中字幕”只改变可见列表，不改变选择本身。

### 从字幕面板导出

1. 确认当前选择只包含要输出的字幕。
2. 右键打开菜单，选择 **导出 → 导出…**；也可按 <kbd>Ctrl</kbd> + <kbd>Shift</kbd> + <kbd>E</kbd>。
3. 在导出工作区复核来源列表、顺序、输出模式和设置。
4. 已有可用导出设置时，可用“使用上次设置导出”或 <kbd>Ctrl</kbd> + <kbd>Alt</kbd> + <kbd>Shift</kbd> + <kbd>E</kbd> 快速提交。

### 删除与波纹删除

字幕右键菜单提供**删除**和**波纹删除**。它们作用于项目中的字幕/片段范围，而不是删除原始媒体文件；使用前务必在历史记录中保留可回退状态。

- 删除：移除所选字幕条目，保留后续时间位置。
- 波纹删除：移除所选内容后，让后续项目范围向前闭合。

<kbd>Delete</kbd> 或 <kbd>Backspace</kbd> 执行普通删除；字幕面板聚焦时，<kbd>Shift</kbd> + <kbd>Delete</kbd> 执行波纹删除。

具体结果取决于当前项目内容和选择范围。若目标只是“不导出”，不要删除，改用取消选择或设置排除旗标。

## 多来源整理的边界

多来源把不同视频的字幕放进同一个操作视图，但不会把轨道数据改造成同一个字幕文件。同名视频或相同字幕编号仍按来源独立标识；搜索、标注和导出会回到各自视频与轨道。重新分析或重新链接素材后，应核对来源是否仍可用、轨道是否被替换。

来源排序为正序或倒序时，列表先按来源分组，再按各组的字幕排序条件排序；设为“无”时，按其他列跨来源排序。排序不会把所有视频时间码放在一条全局可编辑时间线上。删除和波纹删除也只在各自媒体内处理，不能让一个视频的时间变化传播到另一个视频。跨来源导出可以合并为一个文件，最终顺序以导出列表为准。

面板来源选择可用**上一个来源选择 / 下一个来源选择**返回先前组合；面板菜单的**关闭 / 关闭全部**管理来源工作区。它们与项目撤销、文本搜索左右导航是不同操作，见[来源工作区与导航历史](/workspace/workspace#来源工作区与导航历史)。

### 高亮导航会改变当前选择

切换为高亮或修改查询、规则（分镜还包括范围）后，有匹配时会自动定位首条匹配项，并把当前临时选择替换为该条。使用匹配前后导航或序号跳转，同样会替换为目标单条选择。先前手工选择的整批条目不会因导航而一直保留；准备导出时须重新核对并建立最终选择集合。

高亮且查询非空时，面板会优先处理规定焦点区域内无修饰键的左右方向键。没有匹配时按钮禁用、按键不能跳到结果；要恢复普通左右选择，切到过滤模式或清空查询。标题、标签等其他文字输入控件继续自行处理方向键。
