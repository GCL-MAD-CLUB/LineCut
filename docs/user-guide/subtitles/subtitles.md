# 使用字幕

已有字幕时，可以通过对白文字或含义定位片段，再进行标注和导出。没有字幕的视频可以直接使用[分镜与画面检索](/storyboard/storyboards)。

字幕面板用于查找与整理，不提供字幕文字或原始时间的编辑功能。

## 选择字幕来源

1. 打开**字幕**面板和来源菜单。
2. 展开目标视频，选择需要的字幕轨。轨道会显示可用的语言、标题和来源信息。
3. 跨视频查找时，继续勾选其他视频的字幕轨。
4. 单击条目预览，确认对白、画面和时间相符。

同一视频一次显示一条字幕轨；选择另一条会替换当前轨道。多来源时，列表提供**来源**列，可按来源分组或跨来源排序。取消全部来源后显示**未选择**。

外部字幕需要先导入并绑定到视频；内嵌文字字幕可直接选择。具体操作见[管理音频与字幕轨](/media/tracks-binding)。

需要固定当前检索范围时，单击来源菜单旁的**锁定作用域**。字幕与分镜面板可分别锁定，详见[来源工作区与导航历史](/workspace/workspace#来源工作区与导航历史)。

## 阅读与预览

字幕列表显示文字、时间和标记，可调整缩略图大小并按列排序。单击条目可跳转并预览对应片段；列表可随播放位置跟随定位。

同一轨道中，文字完全相同且时间相接或重叠的连续字幕，会自动显示为一个完整片段。不同轨道或中间有时间空隙的字幕保持分开。原始字幕文件不会因此改变；预览、选择和导出使用显示片段的完整范围。

格式样式和换行可能以便于阅读的文字形式显示。位图字幕不能用于文字或语义检索；画面中的烧录字幕也不会自动转为可搜索文字。

## 按文字查找对白

1. 在搜索框输入一句对白或若干关键词。
2. 选择**过滤**，只保留匹配结果；或选择**高亮**，在上下文中浏览匹配项。
3. 选择匹配规则，必要时叠加星级、旗标、色标或编辑状态过滤。
4. 在源监视器中核对结果，再决定是否选用。

| 规则            | 适用任务               |
| --------------- | ---------------------- |
| 包含            | 查找含任一输入词的字幕 |
| 包含所有        | 要求所有输入词都出现   |
| 包含单词        | 按词匹配所有输入条件   |
| 不含            | 排除含输入词的字幕     |
| 开头为 / 结尾为 | 按完整输入匹配首尾     |
| 为空 / 不为空   | 按是否具有文字筛选     |

高亮模式提供上一个、下一个匹配按钮和序号跳转，到两端后循环。计数按匹配条目计算。高亮保留非匹配项，若只想全选匹配字幕，应使用过滤模式。

搜索结果随输入更新。离开搜索框后，最终的非空查询会进入最近搜索；在搜索框内可选择历史查询再次使用。

## 按含义查找对白

安装语义检索组件后，将搜索模式设为**语义**，输入想找的主题或表达，例如“讨论如何控制拍摄预算”。

首次使用需要等待字幕检索准备完成。结果按匹配度查看，可用阈值筛选；默认阈值为 0，提高后结果更严格。含义相近不代表原文完全一致，使用前应试听完整上下文。

语义搜索查找已有字幕的含义，不会听写音频或生成缺失字幕。没有该模式时，请检查安装组件。

## 选择与标注

- 单击选择一项，**Ctrl + 单击**增减不连续项，**Shift + 单击**选择连续范围。
- 可在空白区域拖动框选，或使用**编辑 → 全选**。
- 使用**仅展示选中字幕**核对候选集合。
- 设置 0–5 星、留用或排除旗标、色标或自定义标签。色标与自定义标签互斥。
- 用底部喷涂工具连续应用标记；完成后退出喷涂，再恢复普通选择。

快捷标记：**P / X / U** 设置留用、排除或清除旗标，**0–5** 设置星级，**6–9** 设置红、黄、绿、蓝色标。按住 **Shift** 或开启 **Caps Lock** 标注，可自动前进到下一项。

标注应保存到项目。临时勾选和搜索条件不适合作为长期整理记录。

## 删除字幕条目

删除会改变项目中显示的字幕条目，不会修改原始字幕文件。需要回退时立即撤销；若只是不想使用某段，优先设置排除旗标或取消选择。

普通删除保留其他条目的时间范围；波纹删除还会将下一条的开始位置前移到删除区间。执行前先保存副本并核对影响范围。

## 导出对白片段

选择所需字幕后，选择**文件 → 导出…**。待导出范围按显示的字幕片段生成；需要保留更多开头或结尾时，在导出预览中调整蓝色括号。

导出范围调整不改变原字幕时间。完整设置见[导出媒体](/export/exporting)，任务示例见[通过字幕找到片段](/workflows/find-dialogue)。
