# 星级、旗标和色标

字幕标注会保存到项目中，可在以后重新打开项目后继续过滤和导出。它们不会改写原始字幕文件。

## 标记类型

| 标记       | 可选值                 | 建议用途                               |
| ---------- | ---------------------- | -------------------------------------- |
| 星级       | 0–5 星                 | 表达内容质量、优先级或适用程度         |
| 旗标       | 留用、排除、无旗标     | 表达是否应该进入候选输出               |
| 色标       | 红、黄、绿、蓝、紫、无 | 按团队约定进行分类                     |
| 自定义标签 | 任意简短文字           | 记录项目特有的分类，例如“开场”“需复核” |

色标和自定义标签是互斥的视觉标签：给条目写入自定义标签会清除它的色标，选择色标也会清除自定义标签。

## 给一条或多条字幕标记

1. 在列表或缩略图中选择字幕。可用 <kbd>Ctrl</kbd> 添加不连续选择，或用 <kbd>Shift</kbd> 选择范围。
2. 使用底部旗标、星级、色标控件，或右键菜单设置标记。
3. 用过滤器检查同一类标记是否一致。

快捷键也可用于当前焦点条目：<kbd>P</kbd> 留用、<kbd>X</kbd> 排除、<kbd>U</kbd> 清旗标；<kbd>0</kbd>–<kbd>5</kbd> 设星级；<kbd>6</kbd>–<kbd>9</kbd> 设红黄绿蓝色标。

## 与“选择”区分

- **选择（勾选）**：用于当前批次的查看或导出，属于临时操作状态。
- **星级 / 旗标 / 色标 / 自定义标签**：用于长期整理，写入项目文件并可作为过滤条件。

不要仅因要导出一次就把所有字幕都设为留用旗标；如果它们不代表长期“可用”判断，单纯选择即可。
