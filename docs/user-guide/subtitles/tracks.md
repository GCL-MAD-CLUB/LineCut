# 字幕轨与字幕显示

字幕面板显示当前活动视频可见的字幕轨。字幕来源可以是视频内嵌流，也可以是单独导入并绑定到该视频的外部字幕文件。

## 选择字幕轨

1. 在媒体箱激活目标视频。
2. 打开**字幕**面板。
3. 使用字幕轨选择控件切换轨道；轨道会显示可用的语言、标题、来源或流信息。
4. 检查列表中的文字和时间范围是否与画面匹配。

不同轨道各自拥有独立的搜索、过滤、选择和当前条目状态。切换轨道后，之前的临时勾选与过滤不会被当作另一个轨道的内容。

## 内嵌字幕与外部字幕

| 字幕来源   | 如何出现                                                  | 适用情况                       |
| ---------- | --------------------------------------------------------- | ------------------------------ |
| 内嵌字幕流 | 选中视频后，直接选择可读字幕轨；也可在媒体箱分解流        | 视频文件本身含多语字幕或字幕流 |
| 外部字幕   | 导入 `SRT`、`ASS`、`SSA`、`VTT` 或 `WebVTT`，再绑定到视频 | 字幕文件与视频分开保存         |

外部字幕未绑定到当前视频时，可能不会在其字幕面板出现。请按[绑定音频和字幕到视频](/media/bind)处理。

## 字幕条目包含什么

每条字幕有开始和结束时间、原始文本和用于搜索的纯文本；部分轨道还提供说话人、样式或层级信息。列表中可显示缩略图、星级、旗标、色标和自定义标签。

如果字幕轨带有提示或警告，字幕面板会在列表上方显示。常见原因包括解析格式限制、位图字幕不能像文本字幕一样检索，或时间信息存在异常。
