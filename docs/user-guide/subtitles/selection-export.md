# 选择字幕并导出

## 选择字幕

在字幕列表或缩略图中单击可选择条目；使用 <kbd>Ctrl</kbd> 选择多个不连续条目，使用 <kbd>Shift</kbd> 选择连续范围。底部会显示“已选择 / 可见总数”摘要。

可使用 **编辑 → 全选**、<kbd>Ctrl</kbd> + <kbd>A</kbd> 选择当前可见结果，使用 **编辑 → 取消选择** 或 <kbd>Ctrl</kbd> + <kbd>Shift</kbd> + <kbd>A</kbd> 清空选择。若先使用搜索或过滤，全选只作用于当前显示的字幕。

## 从字幕面板导出

1. 确认当前选择只包含要输出的字幕。
2. 右键打开菜单，选择 **导出 → 导出…**；也可按 <kbd>Ctrl</kbd> + <kbd>Shift</kbd> + <kbd>E</kbd>。
3. 在导出工作区复核来源列表、顺序、输出模式和设置。
4. 已有可用导出设置时，可用“使用上次设置导出”或 <kbd>Ctrl</kbd> + <kbd>Alt</kbd> + <kbd>Shift</kbd> + <kbd>E</kbd> 快速提交。

## 删除与波纹删除

字幕右键菜单提供**删除**和**波纹删除**。它们作用于项目中的字幕/片段范围，而不是删除原始媒体文件；使用前务必在历史记录中保留可回退状态。

- 删除：移除所选字幕条目，保留后续时间位置。
- 波纹删除：移除所选内容后，让后续项目范围向前闭合。

具体结果取决于当前项目内容和选择范围。若目标只是“不导出”，不要删除，改用取消选择或设置排除旗标。
