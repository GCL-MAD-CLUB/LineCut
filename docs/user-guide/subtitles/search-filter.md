# 搜索、过滤和排序字幕

## 文本搜索

在字幕面板顶部的搜索框输入关键词，结果会立即限制为当前字幕轨中匹配的条目。点击结果可让源播放器跳转到该字幕的开始位置。

搜索只作用于当前轨道，不会在其他视频或字幕轨中跨项目查找。搜不到时，优先检查是否选择了正确视频和正确轨道。

## 仅查看已选字幕

开启“仅查看已选字幕”后，列表只显示当前勾选的字幕。这是检查准备导出范围的快捷方式，不会删除未选条目，也不会改变项目中的星级、旗标或色标。

## 过滤器

过滤器可以组合使用；满足所有已启用条件的字幕才会显示。

| 类别 | 可用条件                                       |
| ---- | ---------------------------------------------- |
| 旗标 | 留用、无旗标、排除                             |
| 编辑 | 已编辑、未编辑                                 |
| 星级 | 选择星级，并用“大于等于 / 小于等于 / 等于”比较 |
| 颜色 | 红、黄、绿、蓝、紫、自定义、无                 |

“已编辑”指该字幕已经拥有项目标注，例如星级、旗标、色标或自定义标签；它不表示修改了字幕原文。

## 排序

可从底部“排序依据”菜单改变列表顺序，并通过方向按钮切换升序/降序。列表表头中的可排序列也能快速切换相应排序方式。排序只改变浏览顺序，不改写字幕时间码或导出媒体内容。

## 缩略图大小与显示区域

底部控件可以调整字幕缩略图大小。更多选项菜单还可控制选择、喷涂工具、排序、旗标、星级、色标和缩略图大小这些底部区域是否显示；隐藏控件不会移除相应功能。
