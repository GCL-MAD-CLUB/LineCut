# 喷涂工具批量标注

喷涂工具用于连续浏览字幕时快速给多条字幕添加同一种标记。它适合审片式整理，不适合需要逐条确认不同值的复杂标注。

## 启用并选择喷涂属性

1. 在字幕面板底部点击喷瓶图标，进入喷涂状态。
2. 使用“喷涂”下拉控件选择**色标/自定义标签**、**旗标**或**星级**。
3. 按模式设置具体值：
   - 色标：选择颜色，或输入自定义喷涂标签；
   - 旗标：选择留用或排除；
   - 星级：选择 0–5 星。
4. 在字幕行上按住鼠标左键并拖过目标条目。
5. 点击空喷瓶图标或**完成**退出喷涂。

## Alt 擦除

色标/自定义标签和旗标喷涂支持按住 <kbd>Alt</kbd> 擦除：

- 色标或自定义标签会被清除；
- 旗标会恢复为“无旗标”。

星级模式不使用 Alt 擦除；请直接喷涂 0 星或改用普通星级控件。

## 注意事项

- 一次连续拖动会被视为同一组项目历史，方便一次撤销。
- 每条经过的字幕在一次笔划中只会处理一次，即使鼠标来回经过。
- 喷涂状态下正常的单击选择会被抑制，先退出喷涂再做范围选择或打开右键菜单。

## 使用前、使用中、使用后

**使用前**，先用搜索或过滤缩小到确实需要审核的字幕，并明确本轮是在做“留用/排除”、质量评分还是内容分类。色标和自定义标签互斥；选择其中一个会清除另一个，所以不要把两种语义混在同一次喷涂中。

**使用中**，先在一条测试字幕上单击确认颜色、旗标或星级值，再拖过连续条目。拖动结束后不要立即开始第二个语义不同的笔划；先核对可见行的标记结果。

**使用后**，可按旗标、色标、星级或自定义标签过滤结果。发现整笔错误时优先使用一次撤销；逐条反向喷涂只适合少量修正。
