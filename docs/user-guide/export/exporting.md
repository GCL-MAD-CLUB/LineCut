# 导出媒体

导出会把时间线范围、字幕片段、分镜或媒体条目生成新的媒体文件。它不同于保存项目：导出产生可播放或可交付的成品，保存项目则保留以后继续编辑所需的工作状态。

本页按实际操作顺序集中说明整个导出工作区。第一次导出时，建议从“工作区概览”开始逐节阅读；以后可直接使用右侧页内目录查找某个参数。

## 导出工作区概览

导出工作区用于把时间线、已选字幕、分镜或素材箱中的片段输出为新媒体文件。它并不是项目保存：导出会生成 MP4、MOV、WebM、MP3 或 AAC 等成品，项目本身仍应另存为 `.lcp`。

### 从哪里开始导出

可从下列对象进入导出流程：

- 时间线中的片段范围；
- 字幕列表中选中的一条或多条字幕；
- 分镜中的一个或多个镜头；
- 素材箱中选中的媒体或片段。

进入后，应用会带着当前来源创建导出任务。左侧显示待导出的片段，中间是设置，右侧复用源监视器预览当前聚焦片段，并显示媒体信息。

<GuideImage src="/images/export/overview.png" alt="导出工作区全景" />

### 先确认导出集合

1. 在左侧片段列表勾选要输出的项目；顶部全选框可一次选中或取消全部。
2. 单击某一项使它成为预览项；右侧播放器会定位到该片段的开始位置，并在有结束点时限制预览范围。
3. 检查底部的总时长和输出摘要，再调整格式、命名与画质。
4. 点击底部的导出按钮。若目的地已有同名文件，行为取决于“现有文件”设置。

未勾选任何片段时，不应把导出当作空白序列导出；先回到左侧选择有效片段。

左侧每行有两个不同操作：复选框决定该片段是否参与导出，单击行的其他位置只把它设为右侧预览和“示例”命名的当前片段。顶部**全选**会勾选或取消所有来源；摘要实时显示“已选数量 / 总数”和所选片段总时长。

### 工作区布局

| 区域       | 用途                                       | 常见操作                     |
| ---------- | ------------------------------------------ | ---------------------------- |
| 左侧“导出” | 决定哪些片段参与导出                       | 勾选、全选、聚焦某一片段     |
| 中间“设置” | 控制路径、容器、命名、视频、音频与常规选项 | 展开一个设置组后逐项调整     |
| 右侧预览   | 核对当前片段的画面、入出点与媒体信息       | 在源监视器中播放、定位       |
| 底部操作条 | 提交导出并查看任务状态                     | 开始导出、处理中避免关闭应用 |

两条竖向分隔线可拖动，以便在小屏幕上给片段列表或设置更多宽度。设置面板一次只展开一个分组；这能减少长参数表带来的干扰。

右侧“来源”显示当前预览片段的媒体箱名称、视频编码、尺寸、像素宽高比、帧率、时长、音频编码、采样率和声道；“输出”随设置显示预计的视频/音频参数和估计文件大小。估计大小按经验码率计算，只用于量级判断，不是最终文件大小承诺。

### 合并与逐项输出

在“常规”分组中可切换“合并为一个文件”。

- 开启：所选片段按来源提供的顺序拼接，输出为一个文件；适合将一组连续字幕或多个镜头交付为一个片段。
- 关闭：每个勾选片段各自输出一个文件；适合批量切条、逐镜头交付或保留独立命名。

合并前请在预览中确认片段顺序、画幅、帧率和音频条件。来源差异很大时，最终转码会以所选导出参数统一处理，接缝处的观感仍应先用少量片段试导出验证。

### 导出前的推荐检查

1. 若素材显示离线，先重新链接；不要期待导出自动找到原文件。
2. 确认选中的是需要的字幕/分镜，而不是只聚焦但未勾选的行。
3. 先选择输出目录和重复文件策略，避免成品散落或被覆盖。
4. 第一次使用某种编码组合时，先导出一小段，检查画面、声音、字幕范围与播放兼容性。
5. 导出完成后若勾选“导入项目”，在素材箱中核对新文件确已出现。

下一步请阅读 [输出位置与冲突处理](/export/exporting) 和 [视频设置](/export/exporting)。

## 输出位置、子文件夹与现有文件

输出位置位于导出设置顶部，决定成品写入何处。应用会记住最近一次手动选择的“指定文件夹”，便于下一次继续使用。

<GuideImage src="/images/export/output.png" alt="输出位置设置" />

### 目的地类型

| 选项                             | 行为                                           | 适合场景                 |
| -------------------------------- | ---------------------------------------------- | ------------------------ |
| 指定文件夹                       | 点击“选择”后自行选一个目录；会恢复最近手选目录 | 交付盘、特定项目目录     |
| 原始照片所在的文件夹             | 使用导出来源第一个片段的原始媒体目录           | 希望成品贴近源文件       |
| 桌面 / 文档 / 用户 / 视频 / 图片 | 由系统解析对应的常用目录                       | 临时交付或固定个人工作流 |

选择“指定文件夹”后，点击文件夹行的**选择**打开“选择导出目录”窗口。选择非“指定文件夹”后，该按钮会禁用，因为路径由系统目录或来源路径决定。选择界面中的“原始照片所在的文件夹”时，要确保第一个来源素材在线且其路径仍可访问；这里的“照片”是当前界面名称，对视频来源同样有效。系统目录解析失败时路径会留空，底部导出按钮也会禁用。

### 使用子文件夹

勾选“存储到子文件夹”，输入子目录名。成品会写到所选目的地之下的该子目录。

建议以交付批次或日期命名，例如 `client-review-2026-08-28`。不要使用操作系统不允许的路径字符，也不要把子文件夹名当作完整磁盘路径输入；它应只是当前输出目录下的一层名称。

### 现有文件的处理方式

| 选项                       | 实际动作               | 风险与建议                               |
| -------------------------- | ---------------------- | ---------------------------------------- |
| 询问要执行的操作           | 碰到同名文件时由你决定 | 最安全，适合正式交付                     |
| 为导出的文件选择一个新名称 | 自动为新文件附加序号   | 批量导出方便，但请检查最终命名           |
| 无提示覆盖                 | 直接替换同名文件       | 不可逆风险高，只用于确定可覆盖的缓存产物 |
| 跳过                       | 不生成已存在的同名文件 | 适合可重跑批处理                         |

对于无法重新生成的交付文件，推荐使用“询问”或“新名称”。即使你选择了自动新名称，仍应在导出后检查目录，避免把旧版本误发给他人。

### 导出后导入项目

在“常规”中勾选“导入项目”后，成功导出的成品会自动导入当前项目素材箱。这个选项只影响导出完成后的导入动作，不会替代保存项目；若要长期保留新的项目状态，请再保存 `.lcp`。

相关： [项目、素材与工程文件](/projects/projects)、[命名规则](/export/exporting)、[冲突处理](/export/exporting)。

## 视频导出设置

“视频”分组控制输出画面。它可单独关闭，但视频和音频不能同时关闭；输出为纯音频容器时，视频会自动关闭。

<GuideImage src="/images/export/video.png" alt="视频设置展开状态" />

### 容器与视频编码

可选视频容器包括：

- H.264 / MP4：兼容性优先，适合常规交付；
- HEVC (H.265) / MP4：更高压缩效率，但接收方设备和播放器要支持；
- ProRes / MOV：面向后期交换，文件通常较大；
- VP9 / WebM：适合支持 WebM 的网页或工作流。

容器只是文件封装格式的一部分。最终能否在目标设备播放还取决于设备支持的编码、分辨率和音频组合；交付前请用目标播放器实测。

### 分辨率与帧速率

#### 匹配源

“匹配源”会沿用来源的尺寸或帧速率，是素材无须规格转换时的首选。混合来源合并导出时，应先试导出并确认结果是否符合预期。

#### 自定义分辨率

选择“自定义”后输入宽度和高度。数值最小为 2。建议维持与源一致的宽高比，否则画面可能出现拉伸、黑边或裁切，具体取决于编码处理。

#### 帧速率选项

可选匹配源，或 23.976、24、25、29.97、30、50、59.94、60 fps。通常按交付规格选择；不要仅为了提高数字而把低帧率源强行转成高帧率，这不会凭空创造真实运动细节。

### 质量、速度和性能

| 项目     | 含义               | 取舍                                                                               |
| -------- | ------------------ | ---------------------------------------------------------------------------------- |
| 质量     | 低、中、高、非常高 | 质量越高，通常编码时间和文件体积也越大                                             |
| 编码速度 | 快速、平衡、质量   | 越偏向质量，导出通常越慢                                                           |
| 性能     | 硬件加速、仅限软件 | 硬件加速会尝试可用的 GPU/iGPU 编码器并在不兼容时回退；仅限软件适合排查硬件编码问题 |

第一次给客户、平台或长期归档输出时，建议选择“高”质量，先做 10–30 秒试片，并在目标环境检查清晰度、运动画面、色彩和音画同步。若硬件加速模式失败或结果异常，可用“仅限软件”重试，并参考 [FFmpeg 与工具配置](/troubleshooting/troubleshooting)。

ProRes 使用固定配置映射：低为 ProRes 422 Proxy，中为 ProRes 422，高和最高均为 ProRes 422 HQ；编码速度在 ProRes 输出摘要中不参与速度档显示。H.264、HEVC 和 VP9 才主要体现“最快 / 均衡 / 高质量”的速度取舍。

### 打开或关闭视频流

“视频”标题右侧开关控制是否包含视频。音频和视频不能同时关闭：当音频也关闭时，界面会阻止关闭最后一个视频流；选择 MP3 或 AAC 音频容器会自动关闭视频并锁定视频开关。重新选择视频容器后，再按需要开启视频。

### 使用代理导出

“常规”中的“使用代理”会在存在代理文件时用代理替代原始素材参与导出。它适合快速预览、审核或低带宽传输；正式母版、精细画面交付通常应关闭它并使用原始素材。

代理不存在时，此选项不会替你生成代理。请先按 [创建与管理代理](/media/offline-proxies) 完成代理生成。

## 音频导出设置

“音频”分组只在来源存在音频时可用。切换为 MP3 或 AAC 纯音频容器时，应用会自动启用音频、关闭视频；没有音频的来源不能选择纯音频容器。

<GuideImage src="/images/export/audio.png" alt="音频设置展开状态" />

### 音频格式随容器变化

音频格式选项会根据上方容器自动收窄：视频容器可提供与之兼容的 AAC 或 MPEG 选项；WebM 使用 Opus；MP3 容器输出 MPEG 音频；AAC 容器输出 AAC。因此当你切换容器时，应用可能同步调整当前音频编码，以保证组合有效。

不要把“容器”与“音频格式”当作任意自由组合。下拉框中未出现的组合目前不受该导出界面支持。

### 采样率、声道和音频层

- 采样率可选择“匹配源”或此格式支持的固定采样率；保持源通常最稳妥。
- 声道可选择单声道、立体声；仅当源文件具有足够声道且格式支持时，才会出现 5.1。
- 使用 MPEG 格式时，可根据容器选择 MP2 或 MP3 音频层；MP2/MP3 不支持 5.1，因此界面会自动回退到立体声。

如果目标是社交媒体或一般播放器，立体声和匹配源采样率通常是合理的起点。若交付环绕声，请先确认接收方要求，且不要在声道不足的源上期待凭空生成真实多声道。

具体可选范围如下；界面会根据前一项动态隐藏无效值：

| 项目              | 可选值                                                                    |
| ----------------- | ------------------------------------------------------------------------- |
| AAC / Opus 采样率 | 匹配源；16000、22050、24000、32000、44100、48000 Hz                       |
| MPEG 采样率       | 匹配源；32000、44100、48000 Hz                                            |
| 声道              | 单声道、立体声；源至少 6 声道时额外提供 5.1                               |
| MPEG 音频层       | MPEG-1 Layer II（MP2）、MPEG-1 Layer III（MP3）；MP3 纯音频容器固定为 MP3 |

### 比特率

比特率选项同样受当前格式和音频编码限制。更高比特率通常保留更多音质细节并增大文件；语音审核、样片与正式音乐交付的需求不同，应该按用途测试。

- MP2：128、160、192、224、256、320、384 kbps；
- MP3：128、160、192、224、256、320 kbps；
- AAC / Opus：16–512 kbps 的分段档位，低码率步进较细、高码率步进较大。

建议流程：

1. 首先选择最终容器；
2. 检查音频开关是否启用；
3. 决定匹配源或目标采样率、声道；
4. 再选适合用途的比特率；
5. 用耳机和目标播放器试听导出的短样本。

若导出后没有声音，先确认来源片段确有音频、音频开关已打开，并检查是否误选了仅视频的设置。

来源集合完全没有音频时，音频开关会关闭并禁用，MP3/AAC 纯音频格式也会从格式列表移除。如果此时原设置恰好是纯音频格式，界面会恢复为 H.264，并保证视频开启。

### 选择音频设置的顺序

音频参数会互相约束，因此建议按固定顺序调整：先确定最终容器，再确认“包含音频”开关，然后选音频格式、采样率、声道和比特率。切换容器或格式后，界面可能把原本不再有效的编码、采样率、声道或比特率调整为最近的可用值；不要只看最后一项，应从上到下复核一次。

### 导出前后的核对

导出前，确认所选片段至少有一条启用的音频来源；多音轨视频还应在媒体箱检查正确的音频绑定。导出后，用目标播放器试听开头、中段和片段连接处，特别检查声道、采样率、音画同步和音量。若只需交付审核样片，可降低比特率；若用于正式交付，先做短样本并以接收方规格为准。

## 导出命名规则

命名规则决定导出文件名，且会因“合并/逐项输出”和导出来源不同而变化。中间设置的“示例”会显示当前聚焦片段实际将使用的文件名；批量导出前务必看它。

<GuideImage src="/images/export/naming.png" alt="命名规则与文件名示例" />

### 可用规则

合并导出可使用**文件名**、**自定名称**或**自定名称-文件名**。逐项输出时，规则会因来源而扩展：

- 字幕来源可使用字幕、时间范围、时间范围-字幕、文件名、文件名-字幕、文件名-时间范围、自定名称、自定名称-字幕和自定名称-时间范围；
- 分镜来源可使用分镜、分镜-关键字、时间范围、时间范围-分镜、文件名、文件名-分镜、文件名-时间范围、自定名称、自定名称-分镜和自定名称-时间范围；
- 素材箱来源可使用文件名、自定义文本或两者组合。

规则列表只显示对当前来源有效的选项。切换来源或合并模式后，若旧规则不再适用，应用会回退为可用规则；请再次检查示例。

### 自定义文本、编号与扩展名

- 只有选择带“自定义”的规则后，“自定义文本”输入框才会生效。
- “起始编号”用于批量输出的顺序编号，最小为 0。
- 扩展名可按设置使用大小写，例如 `.mp4` 或 `.MP4`；这不改变实际媒体编码。

时间范围命名会由片段入点和出点组成。长文本、字幕内容和关键字都可能导致名称很长，所以导出前尤其需要查看示例。

起始编号只用于解决同一批次中规则结果重名的第二个及后续文件：第一个保留基础名，后续加 `-N`。例如起始编号为 3 时，同名的第二、第三个文件会得到 `-3`、`-4`。它不会无条件给每个文件编号。

### 自动清理与去重

为生成可写入的文件名，应用会：

1. 将 Windows 文件名不允许的字符替换为下划线；
2. 去除末尾的点和空格；
3. 控制最终文件名长度，尽量保留扩展名和用于避免冲突的后缀；
4. 在同一批逐项导出中发现大小写不敏感的重名时，自动加序号区分。

这能避免大部分写入失败，但不等同于业务层面的版本管理。若文件名必须符合客户规范，请先在少量片段上验证规则，再运行整批导出。

相关： [输出位置与现有文件](/export/exporting)、[关键字系统](/storyboard/use-keywords)。

## 导出冲突与失败处理

导出冲突通常发生在同名文件已存在、目标目录没有写入权限、源媒体离线，或选定的格式/设备组合不工作时。先保留错误信息和设置截图，再按下面顺序排查。

<GuideImage src="/images/export/conflicts.png" alt="同名文件冲突提示或导出失败状态" />

### 同名文件

在导出前选择“现有文件”的策略：

- 希望人工确认：选“询问要执行的操作”；
- 希望保留旧版本：选“为导出的文件选择一个新名称”；
- 只重跑缺失项：选“跳过”；
- 只有确定旧产物可丢弃时才选“无提示覆盖”。

名称策略还会处理同一批片段之间的重名，但无法替你判断哪个版本才是正确交付。正式输出推荐使用新子文件夹，并保留一次可追溯的导出批次。

当“现有文件”选择**询问要执行的操作**且检测到冲突时，对话框会列出全部冲突文件的名称和完整路径。四个按钮会**一次应用于列表中的所有冲突文件**：

| 按钮         | 本批行为                                 |
| ------------ | ---------------------------------------- |
| 取消         | 取消这次导出，不处理冲突文件             |
| 跳过         | 保留磁盘旧文件，不生成这些冲突输出       |
| 使用唯一名称 | 保留旧文件，为本批冲突输出生成不重复名称 |
| 覆盖         | 替换所有列出的旧文件                     |

按 <kbd>Escape</kbd> 或关闭对话框等同于取消；按确认动作等同于覆盖，因此不要在未核对列表时直接确认。

### 导出没有开始或立即失败

按此顺序检查：

1. 左侧至少勾选了一个有效片段；
2. 所有参与片段的原始素材都在线；
3. 输出目录存在、可写、磁盘空间充足；
4. 不要把视频和音频同时关闭；
5. 纯音频容器只用于带音频的来源；
6. 暂时切到常用组合，例如 H.264/MP4、匹配源、硬件加速；
7. 若硬件加速异常，改为“仅限软件”并重试一小段。

有效选择和输出目录准备好后，底部**导出**会把任务加入串行队列。队首任务显示“已开始导出”，后续任务会提示前面还有多少项；成功后保存本次设置，供“使用上次设置导出”调用。取消队列任务不会删除此前已成功写出的文件。

### 成品异常

| 现象             | 优先检查                                             |
| ---------------- | ---------------------------------------------------- |
| 没有声音         | 来源是否带音频、音频开关、声道/格式组合              |
| 成品画面模糊     | 是否启用代理、质量档、分辨率是否低于预期             |
| 播放器打不开     | 换 H.264/MP4 或确认目标播放器支持 HEVC、ProRes、WebM |
| 导出范围不对     | 重新核对勾选项、每个片段的入出点和预览范围           |
| 文件不在预期位置 | 复查“导出到”、子文件夹和来源第一个片段的目录         |

导出问题与媒体问题常相互关联。继续阅读 [媒体离线与重新链接](/media/offline-proxies) 和 [FFmpeg 与工具配置](/troubleshooting/troubleshooting)。
