# 导出媒体

将所选镜头、媒体或对白片段生成为新的媒体文件。导出完成后仍应保存项目，以便继续整理和制作。

## 选择导出内容

1. 在分镜、媒体箱或字幕面板选择需要的条目。
2. 选择**文件 → 导出…**，或按 **Ctrl + Shift + E**。
3. 在左侧片段列表核对勾选项、数量、顺序和总时长。
4. 单击片段查看右侧预览，单击缩略图可播放当前范围。

可以从多个视频集中选择片段。分镜和字幕面板的来源范围决定可供选择的内容；确认筛选结果后再进入导出。

## 调整导出范围

需要多留一点片头、缩短结尾或移动片段时：

1. 单击导出列表中的目标片段。
2. 放大预览时间线。
3. 拖动蓝色括号的左右边界调整入点、出点，或拖动中间手柄整体移动。
4. 核对列表中的时长并播放确认。

**Ctrl + Z** 撤销，**Ctrl + Shift + Z** 重做。所有来源均支持此操作，原字幕时间、项目分镜和源文件保持原样。

导出范围属于本次准备工作，不随项目文件保存。切换项目或更换来源后，请重新核对范围。范围撤销不撤销输出参数，也不能删除成品或恢复被覆盖文件。

## 选择逐项或合并输出

在**常规**中设置**合并为一个文件**：

- 关闭：每个勾选片段输出独立文件。
- 开启：按列表顺序将片段拼接为一个文件。

合并前逐段确认顺序，混合画幅或帧率时选择符合交付要求的统一规格。这里只拼接所选内容，不提供轨道编排、转场或完整时间线剪辑。

## 设置输出位置

选择**指定文件夹**并单击**选择**，或选择桌面、文档等常用位置。界面中的**原始照片所在的文件夹**对视频同样适用，使用第一个来源的原始媒体目录。

需要分批管理时，开启**存储到子文件夹**并输入名称。检查目标位置可写、磁盘空间充足。

### 处理同名文件

| 设置                       | 结果                         |
| -------------------------- | ---------------------------- |
| 询问要执行的操作           | 遇到冲突时显示列表，由你决定 |
| 为导出的文件选择一个新名称 | 为新文件生成不重复名称       |
| 无提示覆盖                 | 替换已有同名文件             |
| 跳过                       | 保留旧文件，不生成冲突项     |

冲突窗口中的选择会应用于列出的全部冲突文件。覆盖无法通过撤销恢复，确认前请核对完整路径。

## 设置视频

| 选项               | 使用说明                             |
| ------------------ | ------------------------------------ |
| H.264 / MP4        | 常用的视频交付格式                   |
| HEVC / MP4         | 适合高效率压缩，接收设备需兼容       |
| Apple ProRes / MOV | 用于后期交换和高质量中间文件         |
| VP9 / WebM         | 用于 WebM 交付                       |
| 分辨率             | 选择匹配源，或填写自定义宽高         |
| 帧速率             | 匹配源，或选择所需固定帧率           |
| 质量与速度         | 按画质、文件大小与处理时间取舍       |
| 性能               | 可选硬件加速；遇到问题时尝试仅限软件 |

在右侧**来源**和**输出**信息中比较画面规格。预计文件大小仅供安排空间，最终以生成文件为准。

### 画面规格与质量

不需要转换规格时，分辨率和帧速率可选择**匹配源**。自定义尺寸时保持所需宽高比，确认画面没有意外拉伸；可选固定帧率包括 23.976、24、25、29.97、30、50、59.94 和 60 fps。

质量提供低、中、高和非常高，编码速度提供最快、均衡和高质量。根据接收方要求选择，并在输出摘要中核对。提高帧率不会增加原素材已有的运动细节。

选择 ProRes 时，低质量输出 ProRes 422 Proxy，中质量输出 ProRes 422，高和非常高输出 ProRes 422 HQ。需要特定后期规格时，以右侧输出摘要为准。

**常规 → 使用代理**适合快速审核。正式画面交付通常应关闭，并确保原始素材在线；启用此项不会自动创建代理。

## 设置音频

来源包含音频时，可以开启或关闭音频输出，选择可用格式、采样率、声道和比特率。先确定输出格式，再调整音频参数；切换格式后应再次检查。

- 单声道或立体声按交付要求选择；5.1 仅在来源和格式支持时出现。
- 使用匹配源采样率可减少不必要的规格变化。
- 纯音频输出选择 **MP3** 或 **AAC**，此时不输出视频。
- 没有音频的来源不能选择纯音频格式。
- 至少启用一种有效的视频或音频输出。

绑定独立录音的项目，应先确认使用了正确音频。导出后无声时，检查来源、启用状态和音频开关。

### 音频格式与规格

WebM 提供 Opus，MP3 输出 MPEG 音频，AAC 输出 AAC；视频格式中的音频选项以对应下拉菜单为准。MPEG 音频层可按可用选项选择 MP2 或 MP3，纯 MP3 文件固定使用 MP3。

AAC / Opus 可选择匹配源或 16000、22050、24000、32000、44100、48000 Hz；MPEG 提供匹配源或 32000、44100、48000 Hz。源声道不足时不会提供 5.1，MP2 / MP3 也不提供 5.1。

比特率越高通常文件越大。按交付要求选定后，试听开头、中间与片段连接处，确认声道和同步。

## 设置文件名

先选择命名规则，再检查**示例**。规则随来源和合并方式变化：

| 来源     | 可用于命名的内容                               |
| -------- | ---------------------------------------------- |
| 分镜     | 镜头标题、关键字、时间范围、原文件名和自定名称 |
| 字幕     | 字幕文字、时间范围、原文件名和自定名称         |
| 媒体箱   | 原文件名、自定名称及其组合                     |
| 合并输出 | 文件名、自定名称或两者组合                     |

选择包含自定名称的规则后，填写自定义文本。长字幕或关键字可能使名称过长，应在示例中检查，并选择较简洁的规则。切换来源或合并方式后再次核对。

**起始编号**用于区分同一批次内的重复名称，不会给每个文件强制加号。第一个文件保留基础名称，后续同名项追加编号；例如起始编号设为 3，后两个同名项分别追加“-3”“-4”。扩展名大小写只改变名称显示，不改变编码。

## 开始导出与快速导出

1. 确认片段、范围、顺序、输出文件夹和名称。
2. 核对视频与音频规格，正式交付时检查代理选项。
3. 单击**导出**，按提示处理同名文件。
4. 等待顶部任务完成，在输出位置检查成品。
5. 需要把成品加入项目时，在导出前开启**导入项目**。

任务可能先排队。提交后继续编辑不会改变本次导出的已提交设置；需调整时取消并重新准备。取消可能保留已完成的文件，应检查输出目录。

**文件 → 使用上次设置导出**可复用当前项目上次成功导出的设置，快捷键 **Ctrl + Alt + Shift + E**。切换素材或交付要求后，建议先打开完整导出工作区确认参数。

## 检查交付结果

用目标播放器核对清晰度、声画同步、开头结尾和合并接缝。遇到无声、打不开或失败提示，请参阅[故障排查](/troubleshooting/troubleshooting#导出失败或结果异常)。
