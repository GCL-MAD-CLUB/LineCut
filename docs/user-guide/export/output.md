# 输出位置、子文件夹与现有文件

输出位置位于导出设置顶部，决定成品写入何处。应用会记住最近一次手动选择的“指定文件夹”，便于下一次继续使用。

<GuideImage src="/images/export/output.png" alt="输出位置设置" />

## 目的地类型

| 选项                             | 行为                                           | 适合场景                 |
| -------------------------------- | ---------------------------------------------- | ------------------------ |
| 指定文件夹                       | 点击“选择”后自行选一个目录；会恢复最近手选目录 | 交付盘、特定项目目录     |
| 原始素材所在文件夹               | 使用导出来源第一个片段的原始媒体目录           | 希望成品贴近源文件       |
| 桌面 / 文档 / 用户 / 视频 / 图片 | 由系统解析对应的常用目录                       | 临时交付或固定个人工作流 |

选择非“指定文件夹”后，文件夹选择按钮会禁用，因为路径由系统目录或来源路径决定。选择“原始素材所在文件夹”时，要确保第一个来源素材在线且其路径仍可访问。

## 使用子文件夹

勾选“存储到子文件夹”，输入子目录名。成品会写到所选目的地之下的该子目录。

建议以交付批次或日期命名，例如 `client-review-2026-08-28`。不要使用操作系统不允许的路径字符，也不要把子文件夹名当作完整磁盘路径输入；它应只是当前输出目录下的一层名称。

## 现有文件的处理方式

| 选项                       | 实际动作               | 风险与建议                               |
| -------------------------- | ---------------------- | ---------------------------------------- |
| 询问要执行的操作           | 碰到同名文件时由你决定 | 最安全，适合正式交付                     |
| 为导出的文件选择一个新名称 | 自动为新文件附加序号   | 批量导出方便，但请检查最终命名           |
| 无提示覆盖                 | 直接替换同名文件       | 不可逆风险高，只用于确定可覆盖的缓存产物 |
| 跳过                       | 不生成已存在的同名文件 | 适合可重跑批处理                         |

对于无法重新生成的交付文件，推荐使用“询问”或“新名称”。即使你选择了自动新名称，仍应在导出后检查目录，避免把旧版本误发给他人。

## 导出后导入项目

在“常规”中勾选“导入项目”后，成功导出的成品会自动导入当前项目素材箱。这个选项只影响导出完成后的导入动作，不会替代保存项目；若要长期保留新的项目状态，请再保存 `.lcp`。
