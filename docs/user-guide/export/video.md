# 视频导出设置

“视频”分组控制输出画面。它可单独关闭，但视频和音频不能同时关闭；输出为纯音频容器时，视频会自动关闭。

## 容器与视频编码

可选视频容器包括：

- H.264 / MP4：兼容性优先，适合常规交付；
- HEVC (H.265) / MOV：更高压缩效率，但接收方设备和播放器要支持；
- ProRes / MOV：面向后期交换，文件通常较大；
- VP9 / WebM：适合支持 WebM 的网页或工作流。

容器只是文件封装格式的一部分。最终能否在目标设备播放还取决于设备支持的编码、分辨率和音频组合；交付前请用目标播放器实测。

## 分辨率与帧速率

### 匹配源

“匹配源”会沿用来源的尺寸或帧速率，是素材无须规格转换时的首选。混合来源合并导出时，应先试导出并确认结果是否符合预期。

### 自定义分辨率

选择“自定义”后输入宽度和高度。数值最小为 2。建议维持与源一致的宽高比，否则画面可能出现拉伸、黑边或裁切，具体取决于编码处理。

### 帧速率选项

可选匹配源，或 23.976、24、25、29.97、30、50、59.94、60 fps。通常按交付规格选择；不要仅为了提高数字而把低帧率源强行转成高帧率，这不会凭空创造真实运动细节。

## 质量、速度和性能

| 项目     | 含义               | 取舍                                                       |
| -------- | ------------------ | ---------------------------------------------------------- |
| 质量     | 低、中、高、非常高 | 质量越高，通常编码时间和文件体积也越大                     |
| 编码速度 | 快速、平衡、质量   | 越偏向质量，导出通常越慢                                   |
| 性能     | 自动或软件         | 自动会尝试使用可用硬件能力；软件模式适合排查硬件编码兼容性 |

第一次给客户、平台或长期归档输出时，建议选择“高”质量，先做 10–30 秒试片，并在目标环境检查清晰度、运动画面、色彩和音画同步。若自动性能模式失败或结果异常，可用软件模式重试，并参考 [FFmpeg 与工具配置](../troubleshooting/ffmpeg)。

## 使用代理导出

“常规”中的“使用代理”会在存在代理文件时用代理替代原始素材参与导出。它适合快速预览、审核或低带宽传输；正式母版、精细画面交付通常应关闭它并使用原始素材。

代理不存在时，此选项不会替你生成代理。请先按 [创建与管理代理](../media/proxies) 完成代理生成。
