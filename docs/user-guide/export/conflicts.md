# 导出冲突与失败处理

导出冲突通常发生在同名文件已存在、目标目录没有写入权限、源媒体离线，或选定的格式/设备组合不工作时。先保留错误信息和设置截图，再按下面顺序排查。

<GuideImage src="/images/export/conflicts.png" alt="同名文件冲突提示或导出失败状态" />

## 同名文件

在导出前选择“现有文件”的策略：

- 希望人工确认：选“询问要执行的操作”；
- 希望保留旧版本：选“为导出的文件选择一个新名称”；
- 只重跑缺失项：选“跳过”；
- 只有确定旧产物可丢弃时才选“无提示覆盖”。

名称策略还会处理同一批片段之间的重名，但无法替你判断哪个版本才是正确交付。正式输出推荐使用新子文件夹，并保留一次可追溯的导出批次。

## 导出没有开始或立即失败

按此顺序检查：

1. 左侧至少勾选了一个有效片段；
2. 所有参与片段的原始素材都在线；
3. 输出目录存在、可写、磁盘空间充足；
4. 不要把视频和音频同时关闭；
5. 纯音频容器只用于带音频的来源；
6. 暂时切到常用组合，例如 H.264/MP4、匹配源、自动性能；
7. 若自动性能异常，改为软件模式并重试一小段。

## 成品异常

| 现象             | 优先检查                                             |
| ---------------- | ---------------------------------------------------- |
| 没有声音         | 来源是否带音频、音频开关、声道/格式组合              |
| 成品画面模糊     | 是否启用代理、质量档、分辨率是否低于预期             |
| 播放器打不开     | 换 H.264/MP4 或确认目标播放器支持 HEVC、ProRes、WebM |
| 导出范围不对     | 重新核对勾选项、每个片段的入出点和预览范围           |
| 文件不在预期位置 | 复查“导出到”、子文件夹和来源第一个片段的目录         |

导出问题与媒体问题常相互关联。继续阅读 [媒体离线与重新链接](../media/offline-relink) 和 [FFmpeg 与工具配置](../troubleshooting/ffmpeg)。
