# 0.3.2 新增功能

与 `release/0.3.1` 相比，LineCut 0.3.2 强化了素材进入项目和分镜精修两端的工作流。你可以先在导入工作区浏览、筛选和预览本地媒体，再决定复制、校验、组织和绑定方式；完成分镜检测后，也可以直接在源监视器时间线上修正镜头边界。

<GuideImage src="/images/release-notes/v0.3.2.png" alt="0.3.2 导入浏览器和分镜切点时间线" />

## 重新设计的导入工作区

导入工作区现在是一套完整的本地媒体浏览器：

- 从收藏夹、常用位置和磁盘设备进入文件夹，使用面包屑返回上级位置；
- 在缩略图或列表视图中预览支持的媒体，并按名称、创建日期和文件类型筛选；
- 调整缩略图大小，搜索当前文件夹，或显示隐藏文件；
- 选择单个文件、连续范围或整个文件夹。文件夹会递归扫描，待导入栏实时显示已发现的媒体数量；
- 在待导入栏中多选移除、重新扫描文件夹、清除全部或返回来源位置。

已经存在于项目中的同一路径会标记为“已导入”，不能重复加入本次导入。详细步骤见[导入和整理媒体](/media/import-organize)。

## 在导入时复制和校验媒体

开启**复制媒体**后，可将源文件复制到项目所在目录或指定文件夹。选择“复制并进行 MD5 校验”时，LineCut 会在复制后比较源文件和目标文件的摘要；校验失败的文件不会以不可靠副本继续导入。

如果项目尚未保存，“与项目相同”没有可用目标位置。请先保存项目，或改用“选择文件夹…”。复制创建的是磁盘文件副本；关闭复制时，项目仍只保存原路径引用。

## 自动组织和绑定

- **添加到新媒体箱**可把本次结果集中放入一个新媒体箱；
- **自动绑定**可处理全部辅助媒体、仅音频或仅字幕；
- “智能推断绑定”综合文件名、起始时间和时长，“按名称匹配绑定”只使用文件名；
- “直接作为绑定项”移动辅助媒体的绑定关系，“虚拟复制后作为绑定项”先创建项目内条目副本，再保留原条目。

自动绑定只接受达到匹配阈值的组合，不会为了完成任务而强制配对。导入后仍应在媒体箱中抽查视频、音频和字幕是否对应。

## 在源监视器中编辑分镜切点

检测分镜后，源监视器时间线会显示与分镜色标或自定义标签相呼应的切点标记。你可以：

- 单击切点定位并在分镜面板中显示对应镜头；
- 使用 <kbd>Shift</kbd>、<kbd>Ctrl</kbd> 或 Command 选择多个切点并一起拖动；
- 在播放头处添加切点，或输入时间码精确编辑切点；
- 清除所选切点，或清除当前选区内的全部切点；
- 恢复被删除分镜对应的切点；
- 显示或隐藏切点与时间标尺数字。

切点编辑会修改项目中的分镜边界，但不会改写源视频。每次添加、移动、清除或恢复都会进入项目历史，可撤销和重做。详见[调整分镜切点](/source/source-monitor#调整分镜切点)。

## 直接调整字幕和分镜范围

从字幕或分镜面板定位一个条目后，时间线会显示范围边界：

- 拖动左边界或右边界，修改入点或出点；
- 拖动中间手柄，整体移动范围并保持时长；
- 边界拖动期间会临时预览对应帧，松开后恢复播放头位置。

字幕范围会写回字幕条目的时间；分镜范围会移动相邻切点。范围受媒体起止和相邻边界限制。

## 删除区间的可见性和播放

普通删除分镜后，原区间会以斜线填充显示在时间线上，并在连续播放时自动跳过。你仍可手动定位到该区间检查画面，也可选中对应切点执行恢复。删除的分镜会保存在项目状态中，因此保存并重新打开项目后仍能恢复。

## 缩略图和性能改进

- 时间线缩略图可按请求同时生成多种分辨率，显示尺寸变化时选择更合适的缓存；
- 小型字幕缩略图采用更快的缩放路径；
- 缓存写入转入后台，单次缓存写入失败不会使缩略图请求整体失败；
- FFmpeg 工作线程数量受到限制，减少并发任务过度占用处理器的情况；
- 调整列表容器大小时尽量保持视口中央缩略图，降低跳动。

这些改进不改变项目文件中的媒体引用，也不要求手动迁移缓存。首次打开旧项目时，缩略图可能需要重新生成。

## 其他改进

- 关闭、新建或打开项目前的未保存更改提示改为统一的 LineCut 对话框，支持“存储”“不保存”和“取消”；
- 导入浏览器设置与收藏夹保存在工作区配置中；
- 前端源码按应用、核心编辑器和平台适配层重新组织，并增加架构检查；
- 用户指南部署工作流升级到新版 GitHub Pages Actions。

## 升级到 0.3.2 前

1. 保存当前项目，并为重要 `.lcp` 文件保留一份副本；
2. 若计划复制导入媒体，确认目标磁盘有足够空间；
3. 打开旧项目后抽查字幕、分镜和媒体绑定；
4. 用短素材测试导入复制、自动绑定和切点编辑；
5. 首次使用新的时间线编辑时，先通过历史记录确认撤销结果符合预期。

## 已知限制

- 导入浏览器面向 Windows 桌面应用；在普通 Web 预览中不能浏览本地文件系统；
- 自动绑定是基于名称、时间和时长的推断，不能替代人工核对；
- 切点只能在相邻分镜允许的范围内移动，不能产生反向或零长度镜头；
- 删除区间会在播放时跳过，但仍可手动定位，不等同于改写或删除源文件。

遇到升级问题时，请阅读[故障排查](/troubleshooting/troubleshooting)，并在问题报告中附上版本、复现步骤和相关日志。
