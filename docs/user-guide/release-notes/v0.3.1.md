# 0.3.1 更新说明

LineCut 0.3.1 将桌面应用与在线用户指南连接起来，并为问题反馈补充可直接访问的诊断日志入口。本套指南以 0.3.1 源码和界面为核对基准，与该版本一同发布。

<GuideImage src="/images/release-notes/v0.3.png" alt="0.3.1 版本代表性工作区" />

## 0.3.1 新增内容

- 顶部**帮助**菜单不再是预留入口；
- **LineCut 帮助(P)...** 使用系统默认浏览器打开正式帮助中心；
- **显示日志文件(L)...** 使用 Windows 资源管理器打开应用实际写入日志的文件夹；
- 日志继续按天滚动并最多保留最近 14 个文件，便于结合错误编号提交问题；
- 用户指南的版本声明、菜单说明、操作覆盖清单和排错步骤同步到 0.3.1。

帮助中心需要网络连接，但打开日志文件夹不需要网络。这两个命令不会自动上传项目、媒体或日志。发送日志前，请检查其中可能出现的本机路径、项目名和媒体文件名。详细步骤见[查看与提供日志文件](/troubleshooting/troubleshooting#查看与提供日志文件)。

## 0.3 系列主要能力

- 自动分镜检测，并以列表或网格视图整理镜头；
- 分镜堆叠/拆分，以及颜色、标记、评分、自定义标签和批量喷涂标注；
- 层级关键字系统，含父子节点、同义词、输入解析、建议和组合筛选；
- 字幕搜索、过滤、选择、标注和按字幕范围导出；
- 视频、音频、字幕绑定，以及内嵌字幕轨道处理；
- 代理生成和使用；
- 可配置的视频/音频导出、命名、冲突策略和导出后导入项目；
- `.lcp` 项目保存、自动保存恢复、编辑历史和媒体重新链接。

## 升级时建议确认

1. 保存一份当前项目副本和素材清单；
2. 在测试项目中检查 FFmpeg/ffprobe 路径与代理流程；
3. 用短片段测试既有导出预设；
4. 若使用关键字树，打开项目后检查父子关系和同义词；
5. 确认自动保存目录和快照数量仍符合你的磁盘策略。
6. 从**帮助**菜单分别验证默认浏览器和日志文件夹能够打开。
