# 0.3.3 新增功能

本页以 `release/0.3.3` 相对 `release/0.3.2` 的代码变化为基准，说明 0.3.3 的实际操作与升级影响。安装包是否已经发布、发布时间和下载渠道请以项目 Releases 为准；文档版本更新本身不表示已上传安装包。

0.3.3 把“只看一个视频里的一个结果列表”扩展为可在多个视频之间持续检索、整理和导出的工作流。搜索可以选择过滤或高亮，通过匹配导航核对上下文；字幕/分镜面板保存来源工作区和最近预览位置。自动分镜增加合并与覆盖确认，导出范围拥有独立撤销历史，后台处理也减少了对界面的整体阻塞。

## 升级变化速览

| 功能         | 0.3.3 的行为                                                | 需要注意的边界                       |
| ------------ | ----------------------------------------------------------- | ------------------------------------ |
| 搜索         | 字幕/分镜使用统一过滤与高亮栏，支持规则、循环导航和序号跳转 | 高亮保留非匹配项，全选可能包含它们   |
| 来源         | 多视频合并显示，按来源分组排序，分别写回编辑                | 字幕每个视频一次选择一条轨道         |
| 来源工作区   | 面板菜单恢复组合、播放帧和各自的选择历史                    | 保存在本机，不嵌入 `.lcp`            |
| 自动分镜     | 支持批量检测、缺失时自动检测，以及合并/覆盖确认             | 原始媒体必须在线；覆盖清空旧镜头整理 |

## 统一搜索：过滤、高亮与匹配导航

字幕与分镜顶部均可选择**模式：过滤 / 高亮**。过滤隐藏不满足文本条件的条目；高亮保留通过其他过滤器的条目，并突出可显示的命中文字。高亮尤其适合核对相邻台词或镜头，不必反复清空查询。

两者提供包含、包含所有、包含单词、不含、开头为、结尾为、为空、不为空八种规则。高亮不提供“不含”“为空”“不为空”，因为这些条件没有适合高亮的命中文字。分镜另有标题、关键字和任何可搜索字段的范围；字幕检索纯文本、说话人、样式、色标及自定义标签。

1. 先选来源，输入有区分度的词，选择规则。
2. 要保留上下文，切换高亮，用**上一个搜索项 / 下一个搜索项**或无修饰键的左右方向键导航。
3. 要直接跳到第 N 条命中，单击当前序号输入数字，Enter 或失焦提交，Esc 取消。
4. 最后核对条目勾选。导航计数是匹配条目数，同一条内命中多次仍是一条；高亮中的可见列表不等于仅包含命中结果。

搜索忽略大小写，按字母、数字、下划线组成的词解析多个条件；不提供中文自然语言分词或用户正则表达式。其他星级、旗标、颜色和选择过滤继续生效。高亮导航会把临时选择替换为目标单条，修改查询、规则或分镜范围后有匹配时也会自动定位并选中首条；因此继续搜索可能改变刚才的批量选择。完整规则及示例见[使用字幕](/subtitles/subtitles#搜索、过滤和排序字幕)与[使用分镜](/storyboard/storyboards#搜索高亮和来源历史)。

## 多来源字幕、分镜和关键字整理

来源菜单按媒体箱层级显示。可以同时勾选多个视频，字幕在各视频子菜单选择一条轨道；同一视频改选另一轨道会替换旧选择。无字幕视频可保留为来源，全部取消后显示“未选择”，不会删除内容。文件夹圆点提示下级已有来源，不是全选按钮。

多来源列表增加**来源**列，并始终以来源为第一排序键；其他排序在每个来源内部生效。来源列可调整宽度、双击复位，长名称最多换行四行后省略。点击条目时源监视器切换至它自己的视频/轨道，来源内部相同编号不会混淆。

搜索、选择、评分、旗标、色标、喷涂、删除和导出支持统一处理。分镜合并和堆叠按视频分别执行，不跨视频创建镜头或堆叠；不同视频各只选一条时，不能仅凭总数为二执行组成堆叠。跨视频拼接应使用合并导出。

关键字按项目统一管理，多个来源可共用层级、同义词和最近使用记录。合并已有目录后，重命名或删除会更新仍使用这些关键字的镜头；镜头关键字的直接赋值仍按各视频保存。详见[多来源整理的边界](/subtitles/subtitles#多来源整理的边界)、[多来源分镜与合并操作](/storyboard/storyboards#多来源分镜与合并操作)、[使用关键字](/storyboard/use-keywords)。

## 来源工作区与来源选择历史

媒体箱打开视频可建立新的面板来源工作区。通过面板菜单可以返回先前工作区，恢复来源组合、活动媒体、轨道和最近播放帧。来源菜单旁的前后按钮在当前工作区内恢复手动选择变化，最多向后十步，到两端禁用；返回后再修改会截断前进路径。

普通播放和点击行不会不断添加来源历史步骤。面板菜单的**关闭**只关闭当前来源工作区，**关闭全部**清空该面板的来源工作区；通用的**关闭面板**才移除停靠标签。

这些记录按项目 ID 和面板实例写入本机状态配置，包括来源列宽和排序方向；不随 `.lcp` 迁移，也不保证恢复搜索文本、过滤器或临时勾选。来源导航、搜索导航、项目撤销三者分别处理不同状态，见[来源工作区与导航历史](/workspace/workspace#来源工作区与导航历史)。

## 分镜识别：自动补齐、批量提交与结果保护

分镜来源菜单新增没有分镜的在线视频时，会自动提交检测；已有分镜直接显示，不因勾选而重建。媒体箱右键的**分镜识别**可以对所选视频批量提交，分镜面板剪刀按钮可以对当前来源主动重新识别。

已有镜头或可恢复删除记录时，应用先询问**合并 / 覆盖 / 取消**。合并在现有有效镜头中补充新切点，保留现有整理并按分割规则传递标注；覆盖会重建基础划分，清空旧镜头标注、删除记录和堆叠，恢复默认标题。检测途中又有人工编辑时，结果提交前再次询问，避免沿用早先决定而覆盖新工作。

同一目标不会重复提交；切换项目、替换媒体或取消后，过期/半完成结果不会写入新的项目目标。原始媒体脱机时，即使代理可以播放，自动分镜仍不可用。完整条件见[检测镜头切点](/storyboard/storyboards#检测镜头切点)。

## 字幕只读与分镜导出范围编辑

字幕原始文字和时间码保持只读，源监视器中的字幕范围用于检查和播放，不能通过拖动改写；字幕导出范围也不能用分镜导出控件修改。旧指南中“拖动字幕范围会改写时间”的说明不再适用于 0.3.3。

分镜在编辑工作区仍可通过时间线修正切点，改变项目基础划分；在**导出工作区**可以单独拖动当前分镜片段入点、出点或整体范围，调整成品范围而不改变项目切点。

导出范围支持编辑菜单与 Ctrl + Z / Ctrl + Shift + Z 撤销/重做，一次拖动归为一次操作。它不撤销导出设置，也不能恢复已覆盖的磁盘文件。刷新来源时保留仍匹配片段 ID 和源路径的范围；切换项目清空这套临时历史。任务提交后使用当时的快照，之后的编辑不会回写已排队任务。见[调整分镜的导出范围](/export/exporting#调整分镜的导出范围)。

## 后台队列与性能改进

统一任务队列先登记排队状态，再授予执行槽。任务不再整体阻塞工作区，可在处理期间继续浏览和准备其他操作。最多三项分镜检测并行，其他媒体处理和导出仍独占执行、遵循队列顺序；取消全部时暂停补位，等待底层工作清理。

分镜检测在有界队列中重叠解码和推理，共享模型会话并短暂保温，减少相邻任务反复加载模型。Windows 提取请求 D3D11VA，推理尝试 DirectML；硬件解码是否工作还取决于 FFmpeg、源编码和驱动，不能用 GPU 推理可用推断解码必定成功。具体并行预算与诊断日志见仓库技术文档 `docs/storyboard-event-detection.md`。

缩略图读取、生成与写缓存的路径经过重整：封面读取不再触发全视频分析；时间线取帧控制缓冲和临时文件资源；分镜缩略图修正帧边界取样。媒体箱会自动检查在线素材的封面缓存与内嵌文本字幕数据，按缺失项重新分析并复用已有轨道。字幕解析复用正则表达式，减少逐条重复初始化。

以上变化不意味着无限并发、无内存开销或固定倍数加速。慢磁盘、长素材、高分辨率和复杂编码仍会增加耗时，模型保温期间也继续占用内存。处理过程中请保持源盘和输出盘在线。见[任务进度与取消](/workspace/workspace#任务进度与取消)与[故障排查](/troubleshooting/troubleshooting#_0-3-3-搜索、来源和队列排查)。

## 升级到 0.3.3 前后

1. 在旧版本手动保存重要项目，再复制 `.lcp` 和无法重新获取的源素材作为备份。
2. 确认安装的是 0.3.3 对应构建，使用兼容的 FFmpeg/ffprobe；本机路径和缓存设置可在首选项核对。
3. 打开项目后确认字幕标注、分镜切点、堆叠、关键字、绑定和代理关系；升级不会自动对已有分镜执行覆盖检测。
4. 等待必要的缓存和缺失数据补充分析，再建立多来源组合；检查高亮模式下的选择集合。
5. 第一次重新识别已整理视频时，先理解合并与覆盖的区别；需要比较方案时保存项目副本。
6. 导出前复核范围、来源顺序、命名去重和原始/代理设置，完成后保存项目整理结果。

当前内容模型仍为 **V4**，0.3.3 没有新增项目内容版本。面板来源工作区及本机导出设置与 `.lcp` 是不同存储层；切换电脑时仍需重新建立本机界面状态。更早版本项目会沿既有迁移链打开，兼容性判断应以项目内容版本为准，而不是仅比较应用的小版本号。

## 已知限制与排错入口

分镜检测提供切点建议，当前事件模型标记为 `bootstrap_uncalibrated`；需人工复核特殊转场与误切漏切。位图字幕不支持文字搜索，高亮不关闭其他过滤器，跨来源堆叠不支持，浮动面板和预留剪辑菜单仍未提供可执行功能。

故障反馈请注明实际构建版本、来源数量、字幕轨、过滤/高亮模式、任务名称和是否使用代理，并从**帮助 → 显示日志文件**收集对应时间的日志。详见[当前限制与使用边界](/reference/limitations)与[故障排查](/troubleshooting/troubleshooting)。历史变化见[0.3.2 新增功能](/release-notes/v0.3.2)和[0.3.1 更新说明](/release-notes/v0.3.1)。
