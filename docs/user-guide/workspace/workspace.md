# 工作区、面板与任务

LineCut 的界面围绕“导入、编辑、导出”三个工作区组织。编辑工作区由可停靠面板组成；应用菜单负责项目级命令，顶部进度区负责显示长时间运行的任务。

本页先介绍面板布局，再逐项说明菜单与任务状态。第一次使用时建议按顺序阅读；熟悉以后可直接通过右侧页内目录跳到需要的操作。

## 面板、停靠与工作区布局

### 打开与显示面板

从 **窗口** 菜单可以显示源播放器、项目媒体箱、字幕、分镜和历史记录。菜单中的勾选表示该面板当前已打开；选择未勾选项会重新显示它。

媒体箱还可按文件夹打开多个项目媒体箱视图，方便同时处理不同素材箱。

### 切换、关闭和重新打开

- 同一区域的多个面板以标签页显示，单击标签切换。
- 单击聚焦面板后，可用 <kbd>Ctrl</kbd> + <kbd>W</kbd> 关闭它。
- 关闭面板不会删除项目内容；从**窗口**菜单可随时重新打开标准面板。

标签太多、无法全部放进标题栏时，单击右侧的**显示全部标题**按钮；在溢出列表中选择面板即可将其设为当前标签。

### 使用面板菜单

单击标签右侧的面板菜单按钮，或右键单击面板标签：

| 命令               | 当前行为                                               |
| ------------------ | ------------------------------------------------------ |
| 关闭面板           | 关闭当前标签；项目数据保持不变                         |
| 关闭组中的其他面板 | 保留当前标签，关闭同一停靠区域中的其他标签             |
| 浮动面板           | 当前版本为禁用的预留命令，尚不能把面板变成独立浮动窗口 |
| 面板组设置         | 当前版本为禁用的预留子菜单，尚无可配置项目             |

当一个组中只有当前面板时，“关闭组中的其他面板”会禁用。个别面板还可能在通用命令之后提供自己的菜单项。

### 移动和拆分面板

1. 按住面板标签并拖动。
2. 拖到另一个标签栏中间，可与该区域的面板并列为标签页。
3. 拖到目标区域的左、右、上或下方停靠指示区，可创建新的分隔区域。
4. 拖动分隔线可调整相邻区域大小。

拖动过程中只在停靠指示区松开。若放回原标签栏，会改变标签顺序；放到边缘指示区才会拆成新的左右或上下区域。当前版本不支持浮动窗口。

LineCut 会保持每个区域的标签顺序、活动标签、分割方向和比例。

### 布局保存与恢复

应用会把工作区布局自动保存到全局工作区配置中，下一次启动时恢复。布局属于应用环境而不是单个 `.lcp` 项目：切换项目不会改变你的面板安排。

如果误关了面板，使用**窗口**菜单恢复即可；如果布局被压缩得难以操作，逐个重新打开面板并拖回需要的位置。

### 与工作区切换的关系

“导入 / 编辑 / 导出”是任务入口。编辑工作区使用可停靠面板；导入和导出工作区则显示专用任务页面。切换工作区不会删除媒体、字幕、分镜或面板布局。

## 应用菜单参考

顶部菜单是对当前工作区和当前选择的快捷入口。灰色项目不是故障：它表示当前没有满足该命令的项目、面板、选择或任务状态。

<GuideImage src="/images/workspace/application-menu.png" alt="展开的文件、编辑和窗口菜单" />

### 文件菜单

| 命令               | 作用                                       | 何时可用                       |
| ------------------ | ------------------------------------------ | ------------------------------ |
| 新建项目           | 创建一个空项目；先处理当前项目的未保存更改 | 没有阻塞性任务时               |
| 打开项目…          | 从磁盘选择并打开 `.lcp`                    | 没有阻塞性任务时               |
| 打开最近使用的内容 | 从子菜单打开最近项目                       | 最近列表非空且没有阻塞性任务时 |
| 关闭               | 关闭当前聚焦面板，不关闭项目               | 编辑工作区有聚焦面板时         |
| 关闭项目           | 关闭当前项目并回到无项目状态               | 已打开项目且没有阻塞性任务时   |
| 保存               | 写回当前项目路径；未命名项目先选择位置     | 当前项目存在且可保存时         |
| 另存为…            | 写入新路径，并把新文件设为当前项目         | 当前项目存在且可保存时         |
| 保存副本…          | 写入独立副本，但继续编辑当前项目           | 当前项目存在且可保存时         |
| 还原               | 丢弃未保存项目改动，回到最近手动保存状态   | 项目有未保存改动时             |
| 替换素材…          | 为一个在线文件条目选择同类替代文件         | 媒体箱恰好选择一个在线文件时   |
| 链接媒体…          | 为所选离线条目重新指定文件                 | 媒体箱选择了离线媒体时         |
| 设为脱机…          | 主动断开所选在线媒体的文件连接             | 媒体箱选择了在线媒体时         |
| 导入…              | 选择视频、音频或字幕加入当前项目/媒体箱    | 项目可编辑且没有阻塞性任务时   |
| 导入最近使用的文件 | 从子菜单再次导入最近路径                   | 最近媒体列表非空且项目可编辑时 |
| 导出…              | 用当前字幕、分镜或媒体选择打开导出工作区   | 当前聚焦区域提供有效导出选择时 |
| 使用上次设置导出   | 跳过设置页并按上次成功记录的设置提交       | 有有效选择且存在可复用设置时   |
| 退出               | 请求关闭应用；未保存项目会先询问           | 没有阻塞性任务时               |

“最近项目”和“最近导入”只是快捷列表，不是项目备份。原文件已经移动时，仍要按 [重新链接](/media/offline-proxies) 或 [最近项目与自动保存](/projects/projects) 的流程处理。

### 编辑菜单

| 命令     | 作用范围与结果                                                   |
| -------- | ---------------------------------------------------------------- |
| 撤销     | 回退一项项目历史；当前没有可撤销事件时禁用                       |
| 重做     | 恢复下一项已撤销事件；从旧状态产生新编辑后，原未来历史不再可重做 |
| 复制     | 把当前聚焦面板支持的项目条目写入内部剪贴板；当前主要用于媒体箱   |
| 粘贴     | 把内部剪贴板内容复制到当前目标媒体箱；不会复制磁盘文件           |
| 清除     | 删除/移除当前聚焦面板中的选择，具体语义由媒体箱、字幕或分镜决定  |
| 重复     | 在支持的面板创建选择的项目副本；当前主要用于媒体箱               |
| 全选     | 选择当前聚焦面板中筛选后可见的全部项目                           |
| 取消全选 | 清空当前聚焦面板的临时选择                                       |
| 首选项…  | 打开全局路径、自动备份和媒体工具设置                             |

这些命令都作用于当前聚焦、且声明支持相应操作的编辑面板。先单击字幕、分镜或媒体箱中的目标区域，再执行命令；若焦点在文本输入框，输入控件通常优先接收普通文本编辑快捷键。

“首选项”打开全局设置，不受项目内容影响。具体选项见 [首选项](../projects/preferences)。

### 窗口菜单

窗口菜单逐项提供**源监视器**、**项目**子菜单中的项目媒体箱、**字幕**、**分镜**和**历史记录**。未勾选的标准面板会被创建并显示；已勾选的面板会被带到当前标签。项目子菜单可以按媒体文件夹打开多个项目媒体箱视图，每个条目对应一个可独立停靠的面板实例。

面板的停靠、拆分和恢复布局请参阅 [面板、停靠与工作区布局](/workspace/workspace)。

### 当前预留的菜单

“剪辑”和“帮助”在当前版本是预留入口，没有可执行的菜单命令。不要把它们当作已实现功能；在线用户指南应通过 GitHub Pages 地址在浏览器中打开。若你的仓库启用了默认托管地址，它是 `https://gcl-mad-club.github.io/LineCut/`。

相关： [键盘快捷键](./shortcuts)、[任务进度与取消](/workspace/workspace)。

## 任务进度与取消

导入媒体、分析媒体、生成代理、重新链接和导出会作为后台任务运行。运行时，顶部会显示任务名称和进度，底部状态栏也会说明正在执行的任务数量。

<GuideImage src="/images/workspace/tasks.png" alt="单个可取消任务的顶部进度条" />

### 读取进度

- 只有一个任务时：顶部显示任务名称、百分比进度条；任务可取消时，右侧会出现取消按钮。
- 同时有多个任务时：顶部显示“正在执行 N 项操作”和多条堆叠进度条；底部状态栏同步显示总数。
- 任务完成后进度条会消失，应用回到正常状态；失败会以应用的错误/提示机制报告。

进度百分比来自任务报告的当前值与总量。部分媒体步骤只能给出有限进度，因此不要把短时间不变化直接视为卡死。

### 取消任务

仅在任务提供取消能力且当前只有一个任务时，顶部取消按钮可用。点击后会先显示“正在取消任务”，应用等待底层操作确认结束。不要连续点击、不要在取消过程中立即关闭素材盘或移动源文件。

多个任务并行时，当前顶部的汇总视图不提供逐项取消按钮。应等待不需要的任务结束，或在确认项目状态后关闭应用；桌面窗口关闭流程会请求取消正在运行的任务。

取消并不保证撤销已经完成的步骤：例如批量导入中已经成功加入项目的媒体会保留，尚未完成的项目不会加入。重新打开项目后，检查素材箱、历史记录和输出目录，再决定是否继续或清理。

### 阻塞性任务与安全操作

大多数媒体处理任务是阻塞性的：运行时，工作区切换和某些项目/菜单命令会暂时禁用，以避免并发改写同一状态。此时建议：

1. 等待任务完成或按可用的取消流程结束；
2. 查看底部状态与任何警告；
3. 确认素材、代理或导出文件实际状态；
4. 保存项目后再进行大范围编辑或关闭。

如果进度长期停滞，记录任务名称、百分比、错误信息和媒体类型，再按 [性能、缓存与稳定性](/troubleshooting/troubleshooting) 或 [导入与导出失败排查](/troubleshooting/troubleshooting) 排查。
