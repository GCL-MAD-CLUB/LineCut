# 工作区、面板与任务

使用顶部**导入、编辑、导出**切换任务界面。切换工作区后，项目素材和整理结果会保留。

## 安排面板布局

从**窗口**菜单打开源监视器、项目媒体箱、分镜、字幕和历史记录。

1. 按住面板标签拖动。
2. 拖到另一标签栏，可组合为标签页。
3. 拖到边缘停靠指示区，可拆为左右或上下排列。
4. 拖动区域分隔线调整大小。

应用会在下次启动时恢复布局。当前不支持将面板移为独立浮动窗口。

标签过多时，通过**显示全部标题**选择面板。关闭当前面板可按 **Ctrl + W**，也可在面板菜单选择**关闭面板**。从窗口菜单重新打开即可继续工作。

## 来源工作区与导航历史

分镜和字幕面板中的“来源工作区”，是一组视频、字幕轨和最近浏览位置，用于在不同素材集合之间切换。它与顶部三个工作区分别使用。

### 选择与返回来源

1. 打开面板来源菜单，按媒体箱层级选择视频；字幕可展开视频选择轨道。
2. 勾选多个来源集中浏览，取消最后一项可清空当前视图。
3. 在面板菜单中选择已有来源工作区，返回先前集合和浏览位置。
4. 使用标题行的上一个、下一个来源选择按钮，回退或前进来源变化。

来源导航保留最多十步回退，到两端时按钮变灰。回退后重新修改来源，将替换原来的前进记录。

面板菜单中的**关闭**和**关闭全部**移除来源工作区，不删除项目媒体。它们与**关闭面板**是不同命令。

### 锁定作用域

单击两个来源历史按钮之间的锁图标，固定该面板的来源和字幕轨。锁定后，来源菜单与历史按钮禁用，双击其他媒体也不会改变此面板来源；仍可在当前范围内搜索、标注和预览。

锁定时可从面板菜单切换已有来源工作区，或关闭它们。再次单击锁图标解除。字幕和分镜各自独立锁定。

来源浏览记录在当前电脑恢复。将项目交给另一台电脑时，请重新选择所需范围；导出前也应重新检查搜索、过滤和勾选项。

## 理解当前焦点

菜单、快捷键和标注通常作用于最后单击的活动面板。操作前先确认焦点：

- 全选只选择当前面板筛选后可见项。
- 删除按当前面板的对象执行。
- 编辑工作区撤销项目操作，导出工作区撤销待导出范围。
- 输入框获得焦点时，按键优先用于文字编辑。
- 来源导航改变浏览范围，不用于撤销标记或删除。

## 任务进度与取消

导入、分析、分镜识别、检索准备、生成代理和导出时，顶部显示任务与进度。任务可能先排队；某些步骤的百分比会短暂停留，请结合任务名称和文件规模判断。

处理期间可继续浏览或进行允许的操作。不要移动正在使用的源文件，也不要断开素材盘、代理盘或输出盘。

只有一个可取消任务时，顶部提供取消按钮。单击后等待**正在取消任务**结束；多个任务的汇总显示不提供逐项取消。取消可能保留已导入的素材或已生成的文件，完成后应核对项目和输出位置。

持续没有进展时，记录任务名称和提示，参阅[故障排查](/troubleshooting/troubleshooting)。

## 获取帮助与日志

**帮助 → Locution Pro 帮助**在默认浏览器打开用户指南，需要网络连接。

**帮助 → 显示日志文件**打开日志所在文件夹。反馈问题时，选择发生问题时段的日志，并检查其中是否含有需要遮去的路径和项目名称。完整说明见[查看与提供日志文件](/troubleshooting/troubleshooting#查看与提供日志文件)。

常用按键见[键盘快捷键](/workspace/shortcuts)。
