# 应用菜单参考

顶部菜单是对当前工作区和当前选择的快捷入口。灰色项目不是故障：它表示当前没有满足该命令的项目、面板、选择或任务状态。

<GuideImage src="/images/workspace/application-menu.png" alt="展开的文件、编辑和窗口菜单" />

## 文件菜单

| 命令                           | 作用                                       | 何时可用                     |
| ------------------------------ | ------------------------------------------ | ---------------------------- |
| 新建、打开、打开最近使用的内容 | 创建项目、打开 `.lcp` 或最近项目           | 没有阻塞性任务时             |
| 关闭                           | 关闭当前聚焦的面板                         | 在编辑工作区且有聚焦面板时   |
| 关闭项目                       | 关闭当前项目；有未保存改动时会要求处理     | 当前项目存在且无阻塞性任务   |
| 保存、另存为、保存副本         | 保存当前项目、改用新路径保存、保存独立副本 | 当前项目可保存时             |
| 还原                           | 回到最近一次保存的项目状态                 | 项目有未保存改动时           |
| 替换素材                       | 为一个已选且在线的媒体选择替代文件         | 素材箱中恰好选中一个在线媒体 |
| 链接媒体                       | 为已选离线媒体重新指定文件                 | 素材箱中选中离线媒体         |
| 设为脱机                       | 将所选在线媒体标记为离线                   | 素材箱中选中在线媒体         |
| 导入、导入最近使用的文件       | 导入媒体或重复导入最近路径                 | 项目可编辑且没有阻塞性任务   |
| 导出、使用上次设置导出         | 打开导出工作区，或按上次可用设置快速提交   | 当前选区支持导出时           |
| 退出                           | 关闭应用；有未保存改动会要求处理           | 没有阻塞性任务时             |

“最近项目”和“最近导入”只是快捷列表，不是项目备份。原文件已经移动时，仍要按 [重新链接](../media/offline-relink) 或 [最近项目与自动保存](../projects/recent-restore-autosave) 的流程处理。

## 编辑菜单

撤销、重做、复制、粘贴、清除、重复、全选和取消全选都作用于当前聚焦、且支持相应操作的编辑面板。先单击字幕、分镜或素材箱中的目标区域，再执行编辑命令；若焦点在文本输入框，输入控件通常优先接收普通文本编辑快捷键。

“首选项”打开全局设置，不受项目内容影响。具体选项见 [首选项](../projects/preferences)。

## 窗口菜单

窗口菜单用于显示或聚焦源监视器、项目媒体箱、字幕、分镜和历史记录面板。勾选状态表示该面板目前已经打开；再次选择可将它带回工作区。项目媒体箱可以按媒体文件夹打开多个视图。

面板的停靠、拆分和恢复布局请参阅 [面板、停靠与工作区布局](./panels)。

## 当前预留的菜单

“剪辑”和“帮助”在当前版本是预留入口，没有可执行的菜单命令。不要把它们当作已实现功能；在线用户指南应通过 GitHub Pages 地址在浏览器中打开。若你的仓库启用了默认托管地址，它是 `https://gcl-mad-club.github.io/LineCut/`。
