# 面板、停靠与工作区布局

## 打开与显示面板

从 **窗口** 菜单可以显示源播放器、项目媒体箱、字幕、分镜和历史记录。菜单中的勾选表示该面板当前已打开；选择未勾选项会重新显示它。

媒体箱还可按文件夹打开多个项目媒体箱视图，方便同时处理不同素材箱。

## 切换、关闭和重新打开

- 同一区域的多个面板以标签页显示，单击标签切换。
- 单击聚焦面板后，可用 <kbd>Ctrl</kbd> + <kbd>W</kbd> 关闭它。
- 关闭面板不会删除项目内容；从**窗口**菜单可随时重新打开标准面板。

## 移动和拆分面板

1. 按住面板标签并拖动。
2. 拖到另一个标签栏中间，可与该区域的面板并列为标签页。
3. 拖到目标区域的左、右、上或下方停靠指示区，可创建新的分隔区域。
4. 拖动分隔线可调整相邻区域大小。

LineCut 会保持每个区域的标签顺序、活动标签、分割方向和比例。

## 布局保存与恢复

应用会把工作区布局自动保存到全局工作区配置中，下一次启动时恢复。布局属于应用环境而不是单个 `.lcp` 项目：切换项目不会改变你的面板安排。

如果误关了面板，使用**窗口**菜单恢复即可；如果布局被压缩得难以操作，逐个重新打开面板并拖回需要的位置。

## 与工作区切换的关系

“导入 / 编辑 / 导出”是任务入口。编辑工作区使用可停靠面板；导入和导出工作区则显示专用任务页面。切换工作区不会删除媒体、字幕、分镜或面板布局。
