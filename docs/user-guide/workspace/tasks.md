# 任务进度与取消

导入媒体、分析媒体、生成代理、重新链接和导出会作为后台任务运行。运行时，顶部会显示任务名称和进度，底部状态栏也会说明正在执行的任务数量。

<GuideImage src="/images/workspace/tasks.png" alt="单个可取消任务的顶部进度条" />

## 读取进度

- 只有一个任务时：顶部显示任务名称、百分比进度条；任务可取消时，右侧会出现取消按钮。
- 同时有多个任务时：顶部显示“正在执行 N 项操作”和多条堆叠进度条；底部状态栏同步显示总数。
- 任务完成后进度条会消失，应用回到正常状态；失败会以应用的错误/提示机制报告。

进度百分比来自任务报告的当前值与总量。部分媒体步骤只能给出有限进度，因此不要把短时间不变化直接视为卡死。

## 取消任务

仅在任务提供取消能力且当前只有一个任务时，顶部取消按钮可用。点击后会先显示“正在取消任务”，应用等待底层操作确认结束。不要连续点击、不要在取消过程中立即关闭素材盘或移动源文件。

多个任务并行时，当前顶部的汇总视图不提供逐项取消按钮。应等待不需要的任务结束，或在确认项目状态后关闭应用；桌面窗口关闭流程会请求取消正在运行的任务。

取消并不保证撤销已经完成的步骤：例如批量导入中已经成功加入项目的媒体会保留，尚未完成的项目不会加入。重新打开项目后，检查素材箱、历史记录和输出目录，再决定是否继续或清理。

## 阻塞性任务与安全操作

大多数媒体处理任务是阻塞性的：运行时，工作区切换和某些项目/菜单命令会暂时禁用，以避免并发改写同一状态。此时建议：

1. 等待任务完成或按可用的取消流程结束；
2. 查看底部状态与任何警告；
3. 确认素材、代理或导出文件实际状态；
4. 保存项目后再进行大范围编辑或关闭。

如果进度长期停滞，记录任务名称、百分比、错误信息和媒体类型，再按 [性能、缓存与稳定性](../troubleshooting/performance) 或 [导入与导出失败排查](../troubleshooting/import-export) 排查。
