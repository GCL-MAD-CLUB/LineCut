# 键盘快捷键

快捷键随工作区和面板焦点变化。先单击目标面板；编辑文字或使用下拉菜单时，按键优先用于当前控件。

## 项目和文件

| 按键                   | 操作             |
| ---------------------- | ---------------- |
| Ctrl + N               | 新建项目         |
| Ctrl + O               | 打开项目         |
| Ctrl + I               | 导入媒体         |
| Ctrl + S               | 保存             |
| Ctrl + Shift + S       | 另存为           |
| Ctrl + Alt + S         | 保存副本         |
| Ctrl + W               | 关闭当前面板     |
| Ctrl + Shift + W       | 关闭项目         |
| Ctrl + Q               | 退出应用         |
| Ctrl + Shift + E       | 导出选择         |
| Ctrl + Alt + Shift + E | 使用上次设置导出 |

## 编辑和选择

| 按键                        | 操作                             |
| --------------------------- | -------------------------------- |
| Ctrl + Z / Ctrl + Shift + Z | 撤销 / 重做                      |
| Ctrl + C / Ctrl + V         | 在支持的区域复制 / 粘贴          |
| Ctrl + A                    | 全选当前可见项                   |
| Ctrl + Shift + A            | 取消选择                         |
| Delete / Backspace          | 删除当前选择                     |
| Shift + Delete              | 在字幕或分镜面板波纹删除         |
| Ctrl + 单击                 | 增减不连续选择                   |
| Shift + 单击                | 选择连续范围                     |
| 方向键                      | 移动选择，图标视图上下键按行移动 |
| Shift + 方向键              | 扩展连续选择                     |
| Ctrl + Shift + 方向键       | 保留原选择并添加扩展范围         |

导出工作区的撤销与重做只调整待导出范围，不回退编码设置或磁盘文件。

## 源监视器

| 按键                | 操作                       |
| ------------------- | -------------------------- |
| Space               | 播放 / 暂停                |
| 左 / 右方向键       | 上一帧 / 下一帧            |
| J / K / L           | 反向播放 / 暂停 / 正向播放 |
| 按住 K 再按住 J / L | 低速向后 / 向前查看        |
| Ctrl + 滚轮         | 以指针位置缩放画面         |
| Alt + 滚轮          | 以画面中心缩放             |

## 分镜和字幕标注

| 按键                                    | 操作                   |
| --------------------------------------- | ---------------------- |
| P / X / U                               | 留用 / 排除 / 清除旗标 |
| 0–5                                     | 设置星级               |
| [ / ]                                   | 降低 / 提高星级        |
| 6 / 7 / 8 / 9                           | 红 / 黄 / 绿 / 蓝色标  |
| Shift + 标注键，或开启 Caps Lock 后标注 | 标注并前进到下一项     |
| 喷涂时按住 Alt                          | 擦除关键字、标签或旗标 |
| 关键字喷涂时按住 Shift                  | 显示最近关键字选择     |

关键字面板的最近使用区域展开时，可按住 **Alt** 再按数字，按九宫格位置快速使用关键字；上排 7–9、中排 4–6、下排 1–3。输入文字时此操作不生效。

## 搜索和文字输入

| 位置                   | 按键              | 操作                            |
| ---------------------- | ----------------- | ------------------------------- |
| 高亮搜索的面板或搜索框 | 左 / 右方向键     | 上一个 / 下一个匹配，到两端循环 |
| 匹配序号输入框         | Enter / Esc       | 确认跳转 / 取消输入             |
| 最近搜索列表           | 上下方向键、Enter | 选择并使用记录                  |
| 标题、标签或关键字编辑 | Enter / Esc       | 确认 / 取消                     |
| 首选项                 | Tab / Shift + Tab | 移动焦点                        |
| 项目首页               | Esc               | 返回工作区                      |

高亮搜索启用且查询非空时，左右方向键优先导航匹配项。需要恢复普通选择移动时，清空搜索或切换过滤模式；源监视器内的左右键仍用于逐帧。
