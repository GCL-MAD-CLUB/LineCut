# 键盘快捷键

> 适用版本：LineCut 0.3.3。本文以 `release/0.3.3` 分支实现为准。

<GuideImage src="/images/workspace/shortcuts.png" alt="源监视器与字幕面板的快捷键提示" />

快捷键在焦点位于可编辑文字输入框时可能由输入控件优先处理。以下 `Ctrl` 在 macOS 语义中可由主修饰键替代；LineCut 当前主要面向 Windows。

## 项目与菜单

| 快捷键                                                             | 命令                            |
| ------------------------------------------------------------------ | ------------------------------- |
| <kbd>Ctrl</kbd> + <kbd>N</kbd>                                     | 新建项目                        |
| <kbd>Ctrl</kbd> + <kbd>O</kbd>                                     | 打开项目                        |
| <kbd>Ctrl</kbd> + <kbd>I</kbd>                                     | 导入媒体                        |
| <kbd>Ctrl</kbd> + <kbd>S</kbd>                                     | 保存项目                        |
| <kbd>Ctrl</kbd> + <kbd>Shift</kbd> + <kbd>S</kbd>                  | 项目另存为                      |
| <kbd>Ctrl</kbd> + <kbd>Alt</kbd> + <kbd>S</kbd>                    | 保存项目副本                    |
| <kbd>Ctrl</kbd> + <kbd>W</kbd>                                     | 关闭聚焦面板                    |
| <kbd>Ctrl</kbd> + <kbd>Shift</kbd> + <kbd>W</kbd>                  | 关闭项目                        |
| <kbd>Ctrl</kbd> + <kbd>Q</kbd>                                     | 退出应用                        |
| <kbd>Ctrl</kbd> + <kbd>Z</kbd>                                     | 撤销                            |
| <kbd>Ctrl</kbd> + <kbd>Shift</kbd> + <kbd>Z</kbd>                  | 重做                            |
| <kbd>Ctrl</kbd> + <kbd>C</kbd> / <kbd>V</kbd>                      | 在当前支持的项目区域复制 / 粘贴 |
| <kbd>Ctrl</kbd> + <kbd>A</kbd>                                     | 全选当前支持区域                |
| <kbd>Ctrl</kbd> + <kbd>Shift</kbd> + <kbd>A</kbd>                  | 取消当前支持区域的选择          |
| <kbd>Backspace</kbd> 或 <kbd>Delete</kbd>                          | 清除当前支持区域的内容或选择    |
| <kbd>Shift</kbd> + <kbd>Delete</kbd>                               | 在字幕/分镜面板执行波纹删除     |
| <kbd>Ctrl</kbd> + <kbd>Shift</kbd> + <kbd>E</kbd>                  | 导出选择                        |
| <kbd>Ctrl</kbd> + <kbd>Alt</kbd> + <kbd>Shift</kbd> + <kbd>E</kbd> | 使用上次设置快速导出            |

## 源播放器

| 快捷键                      | 命令                        |
| --------------------------- | --------------------------- |
| <kbd>Space</kbd>            | 播放 / 暂停                 |
| <kbd>←</kbd> / <kbd>→</kbd> | 上一帧 / 下一帧             |
| <kbd>J</kbd>                | 倒放或降低反向 Shuttle 速度 |
| <kbd>K</kbd>                | 暂停 Shuttle 播放           |
| <kbd>L</kbd>                | 正放或提高正向 Shuttle 速度 |

## 字幕和分镜标注

这些快捷键作用于已聚焦的字幕或分镜面板中的当前条目/选择：

| 按键                                                      | 标记                      |
| --------------------------------------------------------- | ------------------------- |
| <kbd>P</kbd>                                              | 设置留用旗标              |
| <kbd>X</kbd>                                              | 设置排除旗标              |
| <kbd>U</kbd>                                              | 清除旗标                  |
| <kbd>0</kbd>–<kbd>5</kbd>                                 | 设置 0–5 星               |
| <kbd>[</kbd> / <kbd>]</kbd>                               | 降低 / 提升星级           |
| <kbd>6</kbd> / <kbd>7</kbd> / <kbd>8</kbd> / <kbd>9</kbd> | 设置红 / 黄 / 绿 / 蓝色标 |

按住 <kbd>Shift</kbd> 或开启 <kbd>Caps Lock</kbd> 再执行标注快捷键时，面板会自动前进到下一项，适合连续审核。

## 列表和网格选择

媒体箱、字幕和分镜面板获得焦点后可用方向键移动选择：

| 按键                                                 | 行为                                                              |
| ---------------------------------------------------- | ----------------------------------------------------------------- |
| <kbd>←</kbd>/<kbd>↑</kbd>、<kbd>→</kbd>/<kbd>↓</kbd> | 移动到前一项或后一项；媒体箱/分镜图标视图的上、下会按网格列数跨行 |
| <kbd>Shift</kbd> + 方向键                            | 从选择锚点扩展连续范围                                            |
| <kbd>Ctrl</kbd>/Command + <kbd>Shift</kbd> + 方向键  | 保留原选择并加入扩展范围                                          |

焦点位于输入框或下拉菜单时，方向键优先用于编辑文字或选择菜单项。

> [!TIP]
> 快捷键会随面板焦点变化。若按键没有生效，先单击目标面板并确认当前不是文本输入状态。

## 0.3.3 搜索与范围编辑快捷键

| 所在位置与条件                                              | 按键                    | 作用                              |
| ----------------------------------------------------------- | ----------------------- | --------------------------------- |
| 字幕/分镜搜索为高亮、有查询和匹配，焦点在搜索框、条目或面板 | 无修饰键的左 / 右方向键 | 上一个 / 下一个匹配项，到两端循环 |
| 搜索匹配序号输入框                                          | Enter / 失去焦点        | 提交目标序号并定位                |
| 搜索匹配序号输入框                                          | Esc                     | 取消序号草稿                      |
| 导出工作区、分镜来源且存在范围修改                          | Ctrl + Z                | 撤销分镜导出范围                  |
| 导出工作区、范围有可重做记录                                | Ctrl + Shift + Z        | 重做分镜导出范围                  |

高亮导航有效时，无修饰键左右方向键优先于字幕/分镜的普通选择移动；输入序号或编辑标题/标签等其他输入框仍优先处理文字。过滤模式或空查询时，搜索导航不接管方向键；高亮且查询非空但没有匹配时，按左右键不会移动到结果，要恢复普通选择请切回过滤或清空查询。源监视器有焦点时左右键仍用于逐帧；因此先确认焦点所在面板。

来源选择前后按钮目前使用鼠标触发，不要把搜索导航左右键当作来源历史快捷键。编辑工作区的撤销仍针对项目事件；导出撤销不修改编码设置，也不删除已导出文件。
