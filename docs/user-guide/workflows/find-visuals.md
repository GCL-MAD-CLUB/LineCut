# 按画面查找镜头

当你知道需要怎样的场景，却不知道它出现在哪段视频中时，可以用画面描述查找分镜。例如，从活动素材中寻找“观众举手”或从旅行视频中寻找“海边日落”。

## 开始前

- 导入需要查找的视频，保持原始文件在线。
- 安装语义检索组件。
- 在分镜面板选择所需视频，等待镜头识别完成。

视频无需字幕，也无需预先添加标题和关键字。

## 搜索画面

1. 将分镜搜索模式设为**语义**。
2. 输入一个明确的视觉描述，例如“穿红色衣服的人站在舞台上”。
3. 首次使用时，等待初始化和分镜索引构建完成。
4. 从匹配度较高的结果开始检查。图标会显示命中画面，位置标记提示它在镜头中的时间。
5. 单击缩略图预览完整镜头，核对动作、前后画面与可用长度。
6. 提高阈值缩小结果；结果过少时，降低阈值或简化描述。

匹配度表示相关程度，不能代替审片。一次只表达一个主要画面需求，通常更容易比较结果。

## 留下可复用的选择

为确认的镜头设置留用旗标、星级和关键字，保存项目。随后可清空语义查询，改用这些标记筛选并导出。

没有语义检索组件时，可在图标视图人工浏览，并按标题或关键字搜索。进一步操作见[使用分镜](/storyboard/storyboards)和[使用关键字](/storyboard/use-keywords)。
