# 导出所选片段或成片

## 1. 确认来源

在字幕、分镜或媒体箱中完成选择后，切换到**导出**工作区。来源列表会显示可导出的片段；使用每行复选框和“全选”决定本次输出范围。

## 2. 选择输出方式

- **逐项输出**：每个选择片段分别写成一个文件，适合素材库、社媒切片和独立引用。
- **合并输出**：把选择片段按当前顺序合并为一个文件，适合生成粗剪或连续成片。

然后选择目标位置、是否新建子文件夹，以及输出后是否自动导回项目。

## 3. 设置编码与命名

1. 选择容器与视频编码，或只保留音频。
2. 选择与源一致或自定义分辨率、帧率和质量。
3. 按需求配置音频编码、采样率、声道和比特率。
4. 选择名称规则；逐项输出时应特别检查起始编号和扩展名大小写。
5. 选择同名文件处理方式：每次询问、生成唯一名称、覆盖或跳过。

## 4. 提交和检查

点击**导出**后，任务会立即开始，或在已有任务时排入队列。完成后到目标目录检查文件的时长、画面、音频和命名；若勾选“导入到项目”，输出文件会自动成为项目媒体。

## 导出前检查

- 来源列表中至少有一个勾选片段。
- 输出目录存在且有足够空间。
- 若原始媒体脱机，确认是否要允许使用代理导出。
- 不希望覆盖旧文件时，将同名文件处理设为“询问”或“唯一名称”。
