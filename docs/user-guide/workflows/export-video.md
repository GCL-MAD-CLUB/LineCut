# 导出所选片段或成片

> 适用版本：LineCut 0.3.3。本文以 `release/0.3.3` 分支实现为准。

## 1. 确认来源

在字幕、分镜或媒体箱中完成选择后，切换到**导出**工作区。来源列表会显示可导出的片段；使用每行复选框和“全选”决定本次输出范围。

## 2. 选择输出方式

- **逐项输出**：每个选择片段分别写成一个文件，适合素材库、社媒切片和独立引用。
- **合并输出**：把选择片段按当前顺序合并为一个文件，适合生成粗剪或连续成片。

然后选择目标位置、是否新建子文件夹，以及输出后是否自动导回项目。

## 3. 设置编码与命名

1. 选择容器与视频编码，或只保留音频。
2. 选择与源一致或自定义分辨率、帧率和质量。
3. 按需求配置音频编码、采样率、声道和比特率。
4. 选择名称规则；逐项输出时应特别检查起始编号和扩展名大小写。
5. 选择同名文件处理方式：每次询问、生成唯一名称、覆盖或跳过。

## 4. 提交和检查

点击**导出**后，任务会立即开始，或在已有任务时排入队列。完成后到目标目录检查文件的时长、画面、音频和命名；若勾选“导入项目中”，输出文件会自动成为项目媒体。

## 导出前检查

- 来源列表中至少有一个勾选片段。
- 输出目录存在且有足够空间。
- 若原始媒体脱机，确认是否要允许使用代理导出。
- 不希望覆盖旧文件时，将同名文件处理设为“询问”或“唯一名称”。

按模块查看每项设置：[导出工作区概览](/export/exporting)、[视频设置](/export/exporting)、[音频设置](/export/exporting)、[命名规则](/export/exporting)。

## 0.3.3 范围调整与队列复核

来源是分镜时，先单击片段行，在右侧预览拖动入点、出点或中间手柄。Ctrl + Z / Ctrl + Shift + Z 只撤销/重做导出范围，项目切点不变；字幕和普通媒体来源的范围不能用此方法修改。

多来源片段逐个保留自己的媒体路径和范围。合并成片前检查导出列表顺序；使用“原始照片所在的文件夹”时，目的地来自第一个片段，不会按每个视频分别创建目录。

提交后任务使用当时的来源和设置快照，并与其他后台操作排队。后来调整设置不影响已提交批次。取消后保留已成功写出的文件，撤销不能恢复被覆盖的成品；要修订已提交结果，使用新的批次目录重新导出。
