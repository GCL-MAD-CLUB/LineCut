# 导出所选片段或成片

选择所需镜头、媒体或对白片段后，可以逐项交付，也可以按列表顺序输出为一个文件。

## 准备片段

1. 在目标面板核对来源、搜索与筛选条件。
2. 选择所需条目，执行**文件 → 导出…**。
3. 在左侧列表检查勾选项和顺序。
4. 单击每段预览，拖动蓝色括号微调范围。

## 设置输出

1. 选择目标文件夹，必要时创建独立子文件夹。
2. 选择文件格式、分辨率和帧率，再确认音频。
3. 逐项输出时检查每段命名；合并时开启**合并为一个文件**。
4. 正式交付通常关闭**使用代理**，确保原始素材在线。
5. 查看文件名示例，选择适合的同名文件处理方式。

## 导出并核对

单击**导出**，等待任务完成。在输出文件夹检查画面、声音、片头片尾和拼接顺序，再交付。

导出生成媒体文件，项目需要单独保存。更多设置见[导出媒体](/export/exporting)；失败时见[故障排查](/troubleshooting/troubleshooting)。
