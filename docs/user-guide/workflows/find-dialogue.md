# 通过字幕找到片段

适合查找采访、课程或节目中已经有字幕的对白。没有字幕时，可使用[按画面查找镜头](/workflows/find-visuals)；本流程不会自动听写音频。

## 准备字幕

1. 导入视频，选择它的内嵌文字字幕轨。
2. 如使用外部字幕，导入后先绑定到对应视频。
3. 在字幕来源菜单中选择轨道，试听几处确认时间相符。

## 搜索并核对

1. 知道原话时，使用**过滤**或**高亮**，输入关键词。
2. 只知道主题时，安装语义检索组件后选择**语义**并描述所需含义。
3. 多视频查找时，在来源菜单继续选择其他视频的字幕轨。
4. 逐条预览，确认对白前后的上下文完整。
5. 为候选片段设置星级或留用旗标。

高亮模式仍显示非匹配项；需要全选搜索结果时，先切换过滤模式。

## 选择并导出

按住 **Ctrl** 多选片段，选择**文件 → 导出…**。在预览中微调入点和出点以保留完整语句，再设置逐项或合并输出。

保存项目以保留标注。更多操作见[使用字幕](/subtitles/subtitles)及[导出媒体](/export/exporting)。
