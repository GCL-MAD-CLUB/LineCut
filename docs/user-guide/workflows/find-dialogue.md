# 通过字幕找到片段

## 适用场景

当你已知道一句台词、人物名称、产品名或知识点，但不知道它在长视频中的位置时，字幕是最快的入口。此流程不会修改原始媒体，只会把你的选择和标注记录在项目中。

## 操作步骤

1. 在媒体箱激活目标视频；如果同一个项目有多个视频，确认源播放器显示的是正确素材。
2. 打开**字幕**面板，在字幕轨选择控件中选择正确轨道。
3. 在搜索框输入关键词。先使用少量、具有区分度的词，再根据结果调整。
4. 点击某条字幕，源播放器会定位到该条字幕的开始位置；使用播放按钮确认前后语境。
5. 勾选准备导出的条目；如果只想暂时查看它们，使用“仅查看已选字幕”的筛选项。
6. 对值得保留的条目设置星级、留用旗标、色标或自定义标签。
7. 继续搜索并重复标注。完成后按标注条件筛选，检查所有已选择条目。
8. 从字幕面板的**导出**菜单，或切换至导出工作区，输出所选片段。

## 提高结果质量

- 字幕文本来自当前轨道；搜不到时先换轨，或确认外部字幕是否已绑定到该视频。
- 先用搜索缩小范围，再用星级、旗标、色标或标签做二次筛选；不同标注适合表达不同业务含义。
- 字幕条目的选择和项目标注不同：**选择**用于当前导出和查看，星级/旗标/色标/标签用于长期整理。
- 搜索结果需要逐条试听确认，尤其是相同词出现在不同话题、否定语境或转述中时。
