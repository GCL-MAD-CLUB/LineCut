# 整理分镜并建立关键字

> 适用版本：LineCut 0.3.3。本文以 `release/0.3.3` 分支实现为准。

## 目标

这一流程用于“知道画面类型，但不知道它出现在哪里”的素材整理。例如为课程、采访或纪录片标出人物、场景、动作和物体，并在以后按这些条件找到镜头。

## 操作步骤

1. 在媒体箱激活一个视频，打开**分镜**面板。
2. 执行镜头切点检测；新增缺失来源可自动检测，媒体箱右键也可批量识别。已有结果时选择合并、覆盖或取消，完成后核对分镜。
3. 在列表或图标视图中浏览分镜。点击缩略图可让源播放器从该镜头开始播放。
4. 对需要保留的镜头设置星级、留用/排除旗标或色标；必要时输入标题。
5. 打开关键字面板，先创建稳定的大类，例如“人物”“地点”“镜头类型”。
6. 在大类下建立更具体的子关键字，例如“人物 → 主讲人”“地点 → 教室”。
7. 选择一个或多个分镜，为它们添加关键字；同一分镜可以拥有多个关键字。
8. 使用关键字、标记和搜索组合筛选，检查分类是否一致；将连续且相关的镜头堆叠起来。
9. 选择最终镜头并进入导出工作区。

## 组织建议

- 关键字树的第一层应保持少而稳定，避免把每个临时描述都做成顶级节点。
- 把同义词放在同一个关键字上，而不是创建两个意思相同的节点。
- 星级和旗标表达“是否值得使用”，关键字表达“画面是什么”；不要用一种标记代替另一种。
- 连续镜头需要作为整体使用时再堆叠；只要希望仍能单独选择它们，就保持未堆叠。

详见[检测镜头切点](/storyboard/storyboards)、[堆叠、展开和拆分分镜](/storyboard/storyboards)和[关键字系统概览](/storyboard/use-keywords)。

## 多视频整理与重新识别

在分镜来源菜单同时勾选多个视频，先按来源分组浏览，再统一评分、旗标和关键字。关键字目录及最近使用记录按项目共享，镜头赋值仍归属于各视频。来源列用于确认操作目标；普通选中、搜索高亮和导出勾选并不是同一层状态。

补漏切点时优先检查合并识别，覆盖重建会清空旧镜头标注、堆叠和删除记录。检测运行期间可以继续编辑，但提交时发生冲突会再次询问结果处理。多个视频选中的镜头可以一起导出；组成堆叠和合并分镜则按视频分别执行，不能建立跨视频堆叠。

只需要调整成品起止时，进入导出工作区编辑分镜导出范围并用独立撤销核对；需要长期修正镜头基础划分时，回编辑工作区调整切点。完成整理后保存 `.lcp`，不要把本机来源工作区当作素材归档。
