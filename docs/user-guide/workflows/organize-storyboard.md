# 整理分镜并建立关键字

适合审片、素材筛选和建立可复用的项目素材分类。整个过程无需字幕。

## 浏览并校正镜头

1. 导入视频，在分镜来源菜单中选择它，等待识别完成。
2. 使用图标视图快速浏览，单击缩略图预览完整镜头。
3. 在源监视器中修正明显误切或漏切。
4. 多视频集中审看时，继续添加来源；需要固定范围时开启锁定。

## 建立筛选标准

用旗标区分留用和排除，以星级记录质量或优先级。先审核少量镜头，确定统一标准后再批量应用。

## 描述镜头内容

1. 建立人物、地点、景别或动作等少量关键字分类。
2. 选择镜头，通过添加框或关键字树赋值。
3. 对连续镜头使用喷涂工具，加快重复标注。
4. 用关键字快捷过滤与星级筛选检查结果。

关键字属于整个项目。修改分类名称或删除父级前，应检查其他视频中的使用情况。

## 组合相关镜头

将同一段落的多个镜头组成堆叠，保持画面浏览整洁。堆叠保留各镜头；需要改变基础切分时才使用合并或清除切点。

保存项目后，可按分类挑选并导出。详细操作见[使用分镜](/storyboard/storyboards)和[使用关键字](/storyboard/use-keywords)。
