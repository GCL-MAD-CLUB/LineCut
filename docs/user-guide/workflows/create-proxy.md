# 生成代理以流畅预览

> 适用版本：LineCut 0.3.3。本文以 `release/0.3.3` 分支实现为准。

## 什么时候应使用代理

如果拖动、逐帧、播放或浏览缩略图时明显卡顿，可为活动视频创建代理。代理是用于预览的替代媒体；项目仍保留原始素材引用，导出时是否使用代理由导出设置控制。

## 创建代理

1. 在媒体箱中选中或激活需要处理的视频。
2. 从右键菜单打开 **代理 → 创建代理…**。
3. 在“帧大小”中选择**完整**、**二分之一**、**四分之一**或**自定义**。自定义宽高必须使用有效的偶数尺寸。
4. 选择代理预设：H.264 MP4、H.264 MP4 All-Intra、H.264 QuickTime、VP8 WebM 或 VP9 WebM。
5. 选择保存位置：原始媒体旁的 `代理` 文件夹、自定义位置，或首选项的缓存路径。
6. 点击确认，观察任务进度；可以从任务进度中取消。
7. 完成后，源播放器的预览会使用新代理。媒体箱中原始视频仍是项目的正式媒体。

## 使用与移除代理

- 已有代理时，可在媒体箱的 **代理** 子菜单连接不同文件、分离当前代理，或重新连接完整分辨率媒体。
- 原始媒体脱机但代理已连接时，项目仍可用代理继续预览；导出前应确认是否允许在导出设置中使用代理。
- 分离代理只解除项目与代理文件的关系，不等同于删除磁盘上的代理文件。

更多说明见[创建、连接和分离代理](/media/offline-proxies)和[性能、缓存与代理](/troubleshooting/troubleshooting)。

## 0.3.3 代理与后台任务的边界

代理生成通过统一后台队列执行，可以切换工作区继续浏览；排队期间尚未开始转码。原始媒体脱机而代理在线时，字幕和分镜来源仍可用于预览，但自动分镜检测必须读取在线原始文件。创建代理不会自动补回丢失的原文件，也不会改变当前事件模型的检测精度。

切换完整/代理预览会尽量保留播放位置和状态；不同来源工作区各自记录最近帧。正式导出前复核“使用代理”选项和分辨率，移交项目时分别提供原始素材和确实需要的代理。
