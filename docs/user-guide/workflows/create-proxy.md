# 生成代理以流畅预览

当高分辨率或高码率视频播放不流畅时，为它创建较轻量的代理文件，再继续审片。

## 创建代理

1. 在媒体箱选择原始文件在线的视频。
2. 右键选择**代理 → 创建代理…**。
3. 选择二分之一、四分之一或适合审看的帧大小。
4. 选择代理格式和输出位置，确认有足够磁盘空间。
5. 提交并等待完成。

## 切换并检查

在源监视器的预览来源菜单选择**代理**。检查开头、中间和结尾，确认画面、时长和声音对应。

代理帮助预览；镜头检测与画面检索准备仍需原始文件。原始文件暂时脱机时，可用已连接代理继续审看。

## 准备正式输出

导出前通常关闭**使用代理**，确认原始素材在线。只需快速审核时可开启此项，但应告知接收方这是审核文件。

已有代理的连接与完整媒体重连见[管理离线媒体与代理](/media/offline-proxies)。
