# 管理离线媒体与代理

离线与代理是两种不同状态：离线表示项目找不到原文件；代理则是主动连接的轻量替代文件，用于改善预览性能。代理不能修复错误的素材路径，也不应被当作原始素材备份。

本页先处理路径变化和重新链接，再说明代理的创建、连接、使用和移除。

## 脱机、替换和重新链接

当原始媒体被移动、重命名、删除或所在磁盘不可用时，项目中的条目会脱机。脱机项目仍保存你的字幕标记、分镜和媒体箱结构，但通常无法使用原始媒体预览或导出。

### 手动设为脱机

选择在线条目后，右键选择**设为脱机…**。这只改变项目中的连接状态，不会删除文件。适合在临时断开素材、准备交接或测试代理工作流时使用。

### 重新链接媒体

1. 选择一个或多个脱机条目，右键选择**链接媒体…**。
2. 在“链接媒体”对话框中单击一个尚未处理的剪辑行；表格会显示剪辑名称、原文件名、原路径、媒体开始和磁带名称。
3. 按需要设置匹配属性和“自动重新链接其他媒体”。
4. 点击**附加**，在文件选择框中选择对应的替代文件。
5. 成功项显示勾号并计入“已处理”；点击**跳过**会略过当前项并前进，点击**全部跳过**会结束整批。
6. **取消**关闭对话框；已经成功连接的项目不会因此回滚。
7. 完成后检查源播放器、字幕与媒体箱状态。

视频、音频和字幕的选择框会分别限制为相应类型的扩展名，避免把明显不匹配的文件链接到条目。

### 替换素材

对于仍在线的单个文件条目，可用**替换素材…**选择新的同类本地文件。替换后，项目条目保留而文件路径和关联的媒体信息更新。需要永久保留原版本时，先创建项目副本。

### 自动重新链接

链接对话框默认开启“自动重新链接其他媒体”。你手动选择一个文件后，LineCut 会在同一目录中查找其他候选文件并尝试附加。

当前实现实际使用**文件名**（默认勾选）和可选的**文件扩展名**判断自动匹配。界面中还显示“媒体开始”“磁带名称”两个匹配复选框，但 v0.3.1 的自动链接逻辑尚未用它们筛选候选文件；不要依赖它们防止误匹配。对同名文件，应逐条确认。

“使用媒体浏览器附加文件”在当前版本只改变系统选择框标题中的“附加/选择”措辞，仍然打开同一种系统文件选择器；它不会切换成独立的媒体浏览器界面。关闭“自动重新链接其他媒体”可强制逐条附加，适合目录中有许多同名版本时使用。

### 重新连接完整分辨率媒体

如果原始视频脱机但项目仍连接着代理，可在 **代理 → 重新连接完整分辨率媒体…** 中选择原始视频。连接成功后，项目可以重新使用完整分辨率预览和原始媒体导出。

代理相关操作见[创建、连接和分离代理](/media/offline-proxies)。

## 创建、连接和分离代理

代理是为预览准备的替代视频文件。它与原始媒体的项目条目相连，但不是原始素材的替身备份。

### 创建代理

选中一个在线的视频，在右键菜单选择 **代理 → 创建代理…**。创建对话框提供：

- 帧大小：完整、二分之一、四分之一或自定义宽高；
- 预设：H.264 MP4、H.264 MP4 All-Intra、H.264 QuickTime、VP8 WebM、VP9 WebM；
- 水印：当前版本仅提供“无”；
- 保存位置：原始媒体旁的代理文件夹、自定义目录或首选项缓存路径。

选择**自定义**帧大小后才能编辑宽、高，数值最小为 2，并应使用编码器可接受的偶数尺寸。位置菜单中的**选择位置…**会打开目录选择器；取消选择会恢复先前位置，选过的自定义目录之后会作为一项保留在菜单中。首选项缓存路径为空时，应先在首选项中设置可写目录。

点击确认后对话框关闭并开始后台任务；已有代理生成任务运行时确认按钮会禁用。可从顶部任务进度取消，取消后不会把半成品路径登记为项目代理。成功时媒体箱保存代理关联，并提示“预览代理已生成”。细节和选择建议见[生成代理以流畅预览](/workflows/create-proxy)。

### 连接已有代理

选择一个或多个视频，使用 **代理 → 连接代理…**，再在文件选择器中选择现有代理视频。连接后，可在源播放器中使用代理预览。

连接代理使用与重新链接媒体相同的批量对话框：可选择当前行、附加、跳过、全部跳过和自动处理同目录的其他候选。代理文件选择器只接受支持的视频扩展名；连接成功仍应切到源监视器的“代理”模式逐个确认画面、时长和帧率是否匹配。

### 在资源管理器中显示

**代理 → 在资源管理器中显示**打开当前连接代理所在的位置。它只在项目已经有代理路径时可用，适合检查文件是否仍存在或准备复制到另一台电脑。

### 分离代理

选择带代理的视频，执行 **代理 → 分离代理**。分离只清除项目中的代理关联，不删除磁盘上的代理文件。若不再需要该文件，请自行在资源管理器中确认后删除。

### 原始媒体脱机时

若原始视频脱机但代理仍连接，LineCut 可继续使用代理预览。要恢复完整分辨率，选择 **代理 → 重新连接完整分辨率媒体…**，然后选取原视频文件。

> [!WARNING]
> 导出是否使用代理由导出设置决定。需要最高质量交付时，应重新连接原始媒体，并在导出前核对“使用代理”设置。
