# 管理离线媒体与代理

媒体脱机表示项目找不到原始文件。代理是用于预览的轻量视频副本。原始媒体离线而代理在线时，仍可继续审看，但镜头检测和画面检索准备需要原始文件。

## 重新链接媒体

1. 接好素材磁盘，确认文件可访问。
2. 在媒体箱选择脱机条目，右键选择**链接媒体…**。
3. 在链接窗口中选择剪辑，单击**附加**并选择对应文件。
4. 检查成功标记，再处理剩余项。
5. 完成后在源监视器核对画面与声音，并保存项目。

**跳过**略过当前项，**全部跳过**结束整批；取消不会撤回已成功完成的链接。

开启**使用媒体浏览器附加文件**可在应用内浏览；关闭后使用系统文件选择器。

### 自动重新链接其他媒体

开启此选项后，选择一个文件会同时在其所在目录中查找其他素材，不搜索子目录。可按文件名、扩展名、媒体开始或磁带名称限制匹配。

同名文件较多时，关闭自动重新链接并逐条附加。匹配属性缺失时，减少不适用的条件，并以实际画面核对为准。

## 替换或暂时断开素材

- 选择一个在线文件，执行**替换素材…**，可改用同类文件。先保存副本，再检查既有分镜和标注是否仍适用。
- 选择**设为脱机…**可暂时断开项目连接，不会删除磁盘文件。

## 创建代理

1. 选择在线的视频，右键进入**代理 → 创建代理…**。
2. 选择完整、二分之一、四分之一或自定义帧大小。
3. 选择代理预设，如 H.264 MP4、H.264 MP4 All-Intra、H.264 QuickTime、VP8 WebM 或 VP9 WebM。
4. 选择原始媒体旁的代理文件夹、指定文件夹或首选项缓存位置，提交创建。
5. 等待完成，在播放器预览来源菜单切换到**代理**。

代理需要额外空间。选择尺寸时兼顾流畅度与审看片细节；正式交付通常仍使用原始素材。水印当前仅提供“无”。

## 连接和分离已有代理

使用**代理**子菜单中的连接命令选择已有代理，检查内容、时长和帧率是否对应。通过**分离代理**取消关联，不会删除代理文件。

原始视频脱机时，使用**代理 → 重新连接完整分辨率媒体…**重新选择原视频。连接成功后，可切回**完整**预览。

## 使用代理导出

导出设置中的**使用代理**适合快速审核。正式画面交付前通常应关闭，并确认原始素材在线。代理不会自动生成，缺失时请先创建或重新连接。

如果画面模糊或范围不一致，检查当前使用的完整媒体与代理是否正确。相关说明见[导出媒体](/export/exporting)和[故障排查](/troubleshooting/troubleshooting)。
