# 管理音频与字幕轨

视频、音频和字幕可以作为独立条目存在，也可以通过绑定形成同一视频的可选轨道。对于容器内已有的音频或字幕流，LineCut 还可以把它们分解成项目中的独立虚拟条目。

本页说明两种操作的适用场景、执行步骤、结果验证和失败排查。

## 绑定音频和字幕到视频

绑定用于表达“这条音频或字幕属于哪个视频”。绑定后，辅助媒体会归入目标视频，方便在源播放器和字幕面板中集中预览与整理。只有**音频和字幕**可以绑定到视频，视频不能绑定到另一个视频。

### 使用绑定对话框

1. 在媒体箱中选择一个或多个音频/字幕条目。
2. 如同时选中一个视频，它会自动成为目标；否则点击工具栏的绑定按钮或右键 **绑定媒体**。
3. 在“目标视频”下拉框选择视频。
4. 检查“已选媒体”摘要，点击**绑定**。

也可以把音频或字幕直接拖到视频标题上完成绑定。

如果选择中已经包含且只包含一个目标视频，目标下拉框会优先使用该视频；否则可从项目中可用视频列表选择。只选择视频、只选择文件夹，或选择了不能作为辅助轨的条目时，绑定命令会禁用。

### 绑定后的表现

- 已绑定的辅助媒体在媒体箱中以目标视频的子项关系显示。
- 激活视频后，绑定的字幕可在字幕轨中选择；绑定音频会作为该视频的关联音频参与预览。
- 绑定关系保存到项目文件；移动或重新链接文件后，只要条目仍存在，关系会保留。

### 解除绑定

选择已绑定的音频或字幕后，工具栏和右键菜单会提供**解除绑定**。解除绑定不会删除辅助媒体或视频，只是让它恢复为独立项目条目。

多选时，只有选择中的可绑定辅助媒体都已经绑定，工具栏才会切换到解除绑定动作。解除后应在媒体箱根级或原文件夹中查找这些独立条目。

### 常见情况

- 外部字幕导入后字幕面板为空：先确认激活的是正确视频，再检查字幕是否绑定到它。
- 多条字幕要绑定同一视频：可以多选后一次绑定。
- 视频包含的内嵌流不必先外部绑定：可使用[分解内嵌音轨和字幕流](/media/tracks-binding)创建虚拟条目，再按需要整理。

## 分解内嵌音轨和字幕流

某些视频文件同时包含多个音轨和字幕流。媒体箱的**分解音轨和字幕**功能会读取这些内嵌流，并为它们创建项目中的虚拟条目，方便选择、绑定和使用。

### 操作步骤

1. 在媒体箱中选中一个在线的视频条目。
2. 点击工具栏的“分解音轨和字幕”按钮，或右键选择**分解音轨和字幕**。
3. 等待媒体探测任务完成。LineCut 会创建可用的虚拟音轨和虚拟字幕条目。
4. 在媒体箱中检查新条目的语言、编码和来源关系；如有多个字幕轨，按[字幕轨与字幕显示](/subtitles/subtitles)选择要使用的轨道。

分解命令只在**恰好选择一个在线、尚未处于分解状态的视频**时可用。项目只读、媒体任务繁忙、选择了多个视频或视频已脱机时，按钮和菜单会禁用。

<GuideImage src="/images/media/embedded-tracks.png" alt="分解后的视频及虚拟音轨/字幕" />

### 重要说明

- 分解是项目组织操作，不会把内嵌流另存为独立 `.wav` 或 `.srt` 文件。
- 视频必须在线且项目不可处于只读状态。
- 如果视频没有可用内嵌音轨或字幕流，分解后不会创建对应条目。
- 需要真正的外部文件时，请在其他工具中提取，或导出对应内容后再导入。

### 分解后如何确认和使用

分解完成后先回到媒体箱查看新增条目的类型，而不要立刻假定它们已经参与播放。虚拟音轨和虚拟字幕仍需按项目中的绑定关系工作：选择目标视频，确认所需音频/字幕轨已启用；有多个语言或版本时，逐条预览再决定保留哪一条。

重复执行分解不会把内嵌流变成新的媒体文件。若素材箱已经存在同一来源的虚拟条目，应先检查已有条目的绑定，而不是反复分解来解决“没有声音”或“没有字幕”。

### 失败时的最小排查

1. 确认选中的确实是在线的视频，而不是音频、字幕或文件夹；
2. 在源监视器确认该视频可正常读取；
3. 查看任务或警告中的媒体探测信息；
4. 确认 FFmpeg 与 ffprobe 路径有效后，用一个短视频复测；
5. 分解成功但看不到内容时，检查绑定和字幕轨显示，而不是重新导入同一文件。

若分解失败，先检查[FFmpeg、ffprobe 与工具路径](/troubleshooting/troubleshooting)。
