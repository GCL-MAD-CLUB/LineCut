# 管理音频与字幕轨

独立录音和外部字幕可绑定到视频，便于在预览与检索时一起使用。视频本身已有的音轨和字幕，也可以在项目中分别整理。画面浏览和分镜整理无需先绑定字幕。

## 绑定辅助媒体

1. 在媒体箱中选择一个或多个音频或字幕条目。
2. 使用工具栏或右键菜单中的**绑定媒体**。
3. 在**目标视频**中选择对应视频；选择中已包含一个视频时，先核对默认目标。
4. 检查已选媒体摘要，单击**绑定**。
5. 打开目标视频，试听音频或选择字幕轨，核对是否对应。

也可将音频或字幕拖到视频标题上绑定。视频不能绑定到另一个视频；当前选择不适用时，绑定命令会显示为灰色。

## 解除绑定

选择已绑定的音频或字幕，执行**解除绑定**。辅助媒体恢复为独立条目，原文件和视频均保留。

多选时，请核对所选条目是否均已绑定；不确定时分批处理。

## 整理内嵌音轨和字幕

1. 选择一个原始文件在线的视频。
2. 单击**分解音轨和字幕**，或使用同名右键命令。
3. 等待完成，查看新增音轨与字幕条目的语言、来源和启用状态。
4. 打开视频，逐轨检查实际内容。

分解用于项目内管理，不会在磁盘上生成独立音频或字幕文件。没有对应内嵌内容时，不会出现该类条目。

## 选择字幕轨

打开字幕面板的来源菜单，展开视频并勾选轨道。同一视频一次选择一条；多个视频可各选一条集中检索。需要另一条轨道时，在同一菜单切换。

字幕为空时，检查外部文件是否绑定正确、轨道是否启用以及素材是否在线。位图字幕和烧录字幕不能用于文字检索。更多说明见[使用字幕](/subtitles/subtitles)。

## 核对声音与同步

绑定后应试听开头、中间和结尾，确认录音属于当前视频且时间一致。绑定并不自动修复录制时的错位或变速。

预览或导出无声音时，先检查音频是否启用及导出音频开关，再参阅[故障排查](/troubleshooting/troubleshooting)。
