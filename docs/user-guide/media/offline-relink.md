# 脱机、替换和重新链接

当原始媒体被移动、重命名、删除或所在磁盘不可用时，项目中的条目会脱机。脱机项目仍保存你的字幕标记、分镜和媒体箱结构，但通常无法使用原始媒体预览或导出。

## 手动设为脱机

选择在线条目后，右键选择**设为脱机…**。这只改变项目中的连接状态，不会删除文件。适合在临时断开素材、准备交接或测试代理工作流时使用。

## 重新链接媒体

1. 选择一个或多个脱机条目，右键选择**链接媒体…**。
2. 在“链接媒体”对话框中选择当前要处理的剪辑。
3. 点击**附加**，在文件选择框中选择对应的替代文件。
4. 继续附加、跳过当前项，或全部跳过剩余项。
5. 完成后检查源播放器、字幕与媒体箱状态。

视频、音频和字幕的选择框会分别限制为相应类型的扩展名，避免把明显不匹配的文件链接到条目。

## 替换素材

对于仍在线的单个文件条目，可用**替换素材…**选择新的同类本地文件。替换后，项目条目保留而文件路径和关联的媒体信息更新。需要永久保留原版本时，先创建项目副本。

## 自动重新链接

链接对话框默认开启“自动重新链接其他媒体”。你手动选择一个文件后，LineCut 会在同一目录中查找其他候选文件并尝试附加。

当前实现实际使用**文件名**（默认勾选）和可选的**文件扩展名**判断自动匹配。界面中还显示“媒体开始”“磁带名称”两个匹配复选框，但 v0.3.0 的自动链接逻辑尚未用它们筛选候选文件；不要依赖它们防止误匹配。对同名文件，应逐条确认。

## 重新连接完整分辨率媒体

如果原始视频脱机但项目仍连接着代理，可在 **代理 → 重新连接完整分辨率媒体…** 中选择原始视频。连接成功后，项目可以重新使用完整分辨率预览和原始媒体导出。

代理相关操作见[创建、连接和分离代理](/media/proxies)。
