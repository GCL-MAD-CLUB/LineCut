# 绑定音频和字幕到视频

绑定用于表达“这条音频或字幕属于哪个视频”。绑定后，辅助媒体会归入目标视频，方便在源播放器和字幕面板中集中预览与整理。只有**音频和字幕**可以绑定到视频，视频不能绑定到另一个视频。

## 使用绑定对话框

1. 在媒体箱中选择一个或多个音频/字幕条目。
2. 如同时选中一个视频，它会自动成为目标；否则点击工具栏的绑定按钮或右键 **绑定媒体**。
3. 在“目标视频”下拉框选择视频。
4. 检查“已选媒体”摘要，点击**绑定**。

也可以把音频或字幕直接拖到视频标题上完成绑定。

## 绑定后的表现

- 已绑定的辅助媒体在媒体箱中以目标视频的子项关系显示。
- 激活视频后，绑定的字幕可在字幕轨中选择；绑定音频会作为该视频的关联音频参与预览。
- 绑定关系保存到项目文件；移动或重新链接文件后，只要条目仍存在，关系会保留。

## 解除绑定

选择已绑定的音频或字幕后，工具栏和右键菜单会提供**解除绑定**。解除绑定不会删除辅助媒体或视频，只是让它恢复为独立项目条目。

## 常见情况

- 外部字幕导入后字幕面板为空：先确认激活的是正确视频，再检查字幕是否绑定到它。
- 多条字幕要绑定同一视频：可以多选后一次绑定。
- 视频包含的内嵌流不必先外部绑定：可使用[分解内嵌音轨和字幕流](/media/embedded-tracks)创建虚拟条目，再按需要整理。
