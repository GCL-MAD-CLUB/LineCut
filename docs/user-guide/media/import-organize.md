# 导入和整理媒体

媒体进入项目后才可以被预览、绑定、生成分镜或导出。导入并不会移动或复制磁盘上的原文件；媒体箱保存的是项目中的组织结构和文件引用。

本页从选择文件开始，说明待导入列表、媒体探测、媒体箱文件夹、列表和图标视图，以及重命名、隐藏、移除和删除等管理操作。

## 导入媒体

LineCut 支持在一个项目中导入多个视频、音频和字幕。视频和音频会先经过媒体探测；外部字幕作为独立字幕条目加入项目，之后可绑定到某个视频。

### 支持的导入扩展名

| 类型 | 扩展名                                                          |
| ---- | --------------------------------------------------------------- |
| 视频 | `mkv`、`mp4`、`mov`、`webm`、`avi`、`ts`、`m2ts`、`mpeg`、`mpg` |
| 音频 | `wav`、`mp3`、`m4a`、`aac`、`flac`、`ogg`、`opus`、`wma`        |
| 字幕 | `srt`、`ass`、`ssa`、`vtt`、`webvtt`                            |

实际能否正常预览、探测或导出仍取决于文件内的编码，以及当前 FFmpeg 配置。

### 使用导入工作区

1. 点击顶部的**导入**工作区。
2. 分别使用**添加视频**、**添加音频**、**添加字幕**选择多个文件。
3. 所选文件先进入待导入列表；可点击单行的移除图标，或点击**清除**放弃全部待导入项。
4. 检查列表中的名称、类型和所在位置，点击**导入全部**。
5. 导入完成后，视频、音频和字幕会出现在项目中；若有媒体探测提示，会显示在应用顶部的导入提示区域。

### 从媒体箱快速导入

在编辑工作区中可使用媒体箱工具栏的导入按钮，或右键单击媒体箱空白处 / 文件夹并选择**导入…**。文件会加入当前媒体箱或你打开的目标媒体箱。

也可以使用 **文件 → 导入…** 或 <kbd>Ctrl</kbd> + <kbd>I</kbd>。该入口允许在同一个选择框中挑选支持的媒体和字幕格式。

在 Windows 桌面应用的媒体箱**列表视图**中，还可以把系统资源管理器里的文件直接拖到列表区域。只有当列表出现拖入高亮时松开才会导入；图标视图、只读项目或正在阻塞操作时不接收这种拖入。无法识别的文件会按导入校验规则报告或忽略。

### 重复文件与取消任务

- 导入工作区按文件路径（忽略大小写和斜杠形式）识别已导入媒体；选择已有路径会被忽略。
- 同一次选择中的重复路径也只会保留一次。
- 媒体探测属于可见任务；导入多个视频或音频时可以取消。已经成功导入的项会保留，未完成项不会加入项目。
- 项目处于只读状态时不能导入，先在媒体箱解除只读。

外部字幕导入后若没有显示在目标视频的字幕面板中，请继续[绑定音频和字幕到视频](/media/tracks-binding)。

## 媒体箱、文件夹与视图

媒体箱是项目内的组织结构，不会移动硬盘上的实际文件。一个项目可有根级“项目媒体”和任意层级的媒体箱文件夹；同一应用窗口也可以打开多个指向不同媒体箱的面板。

### 新建与整理媒体箱

1. 在需要放置内容的媒体箱中点击“新建媒体箱”按钮，或右键单击空白处选择**新建素材箱**。
2. 输入名称并确认。新媒体箱默认创建在当前媒体箱范围内。
3. 右键单击文件夹并选择**重命名**可修改单个文件夹名称。
4. 选择媒体或文件夹后，通过 **移动到素材箱** 选择目标文件夹或“项目媒体（根目录）”。
5. 不能把一个媒体箱移动到自身或它的子媒体箱中。

使用“通过选择项新建素材箱”可一次复制当前选择并创建文件夹，适合从筛选结果快速建立一个整理集合。

在列表中单击文件夹左侧箭头可原位展开/折叠；双击文件夹行的普通区域会进入该媒体箱。把媒体或文件夹标题拖到目标文件夹可移动所选条目；拖回当前范围的空白处会移动到当前媒体箱。移动多选内容时，会同时处理选择中的媒体和文件夹，并阻止形成“文件夹移入自身或后代”的循环结构。

### 列表与图标视图

媒体箱顶部提供两种视图：

- **列表视图**：适合按名称、时长、视频/音频信息和状态查看大量条目；可调整列表行高。
- **图标视图**：适合用视频缩略图快速浏览；可调整图标大小。

两种视图使用同一项目内容，切换不会改变素材顺序、绑定或项目文件。

列表表头支持按标签、标题、帧率、媒体开始、媒体结束、持续时间、视频信息或音频信息排序；再次单击当前列会切换升序/降序。拖动表头分隔线可调整列宽，双击分隔线恢复默认值。列表中的“启用”和“隐藏”复选框可以直接修改单条媒体状态；文件夹行只提供隐藏复选框。

### 选择、复制、粘贴和重复

- 单击只选择一个条目；<kbd>Ctrl</kbd>/Command + 单击切换不连续条目，<kbd>Shift</kbd> + 单击选择从锚点到当前行的连续范围。
- 方向键移动当前选择；图标视图的上/下方向键会按当前网格列数跨行移动。按住 <kbd>Shift</kbd> 可扩展范围，<kbd>Ctrl</kbd>/Command + <kbd>Shift</kbd> 会把范围加入原选择。
- 从空白处拖出选择框可批量选择；<kbd>Shift</kbd> + 框选追加，<kbd>Ctrl</kbd>/Command + 框选切换框内条目。未按修饰键单击空白处会清空选择。
- 使用**编辑 → 全选 / 取消选择**可批量处理当前可见范围。
- **复制 / 粘贴**会在项目媒体箱中创建新的项目条目和文件夹结构，不会复制磁盘上的原始媒体文件。
- **重复**同样创建项目条目副本；重复的媒体会按“原名称 复制01”这类方式生成新显示名称。
- 复制包含绑定关系时，复制后的音频/字幕会关联到相应的新视频副本，而不是意外指回原视频。

界面右键菜单中目前有两个都显示为“复制”的命令：靠前的一项是**复制到剪贴板**，分隔线后的另一项执行**重复所选项目条目**。在界面文案修正前，可根据位置和结果区分；粘贴需要剪贴板中已有媒体箱条目。

### 搜索、隐藏和只读

- 顶部“搜索媒体”只过滤当前媒体箱范围内可见名称和文件夹。
- 右键菜单的**隐藏**让条目或文件夹暂时不显示；开启**查看隐藏内容**可把它们重新显示出来。
- 媒体箱顶部的笔/锁按钮切换项目只读状态。只读时不能导入、删除、移动、重命名、标记、绑定、分解或更改代理；解除只读后才能修改。
- 在媒体箱空白处右键选择**全部启用**，可一次启用或禁用当前范围内的全部媒体条目；文件夹不参与媒体“启用”状态。

媒体条目本身的状态和编辑见[管理媒体条目](/media/import-organize)。

## 管理媒体条目

### 重命名项目中的显示名称

媒体箱中的名称是项目显示名称，不会修改硬盘上的原始文件名。

1. 在列表视图中双击媒体名称，或右键选择合适的重命名入口。
2. 输入新名称后按 <kbd>Enter</kbd> 或将焦点移出输入框确认；按 <kbd>Escape</kbd> 取消。
3. 该名称用于媒体箱显示和部分导出命名规则。

首次单击已选中的标题单元格并稍候也会进入重命名。只有媒体或文件夹的标题可编辑；帧率、时间、视频信息和音频信息列用于查看与排序，不能在表格中改写。

### 启用与禁用

每个媒体条目都有“启用”状态。可直接使用列表中的复选框，也可右键选择**启用**；多选时，该命令按当前选择是否全部启用，在“全部启用所选”和“全部禁用所选”之间切换。禁用后，条目不会作为正常活动媒体参与预览；例如禁用的视频不能拖到源播放器预览。需要临时排除素材又不想删除时，优先使用禁用或隐藏。

### 隐藏与查看隐藏内容

隐藏用于整理界面，不会脱机、不删除文件，也不会改写原始媒体。右键菜单中选择**查看隐藏内容**后，隐藏条目和文件夹会重新出现在当前媒体箱，便于恢复或继续操作。

### 从媒体箱激活预览

双击视频条目，或把它拖到源播放器，能把该视频设为活动预览。源播放器、字幕和分镜面板会随活动视频更新。音频和字幕若已绑定到该视频，将在对应功能中可用。

拖动媒体标题还可以完成三类操作：拖到视频标题上绑定音频/字幕，拖到媒体箱文件夹中移动，拖到源监视器激活视频。禁用的视频不能拖入源监视器；只读项目仍可预览，但不能用拖动修改绑定或文件夹结构。

### 移除与删除的区别

在媒体箱中选择条目后使用删除/清除，操作的是**项目条目**：它会从当前 `.lcp` 项目移除，不会删除原始视频、音频、字幕或代理文件。

> [!WARNING]
> 移除一个视频会使绑定到该视频的辅助媒体失去该绑定关系。需要保留后续编辑空间时，先保存项目副本。

右键菜单中的**清除**、工具栏垃圾桶以及 <kbd>Backspace</kbd>/<kbd>Delete</kbd> 都会移除所选项目条目。当前右键菜单的**脱机编辑(O)…**是禁用的预留命令，不代表已经实现脱机剪辑工作流。

### 从媒体箱导出视频

选中在线的视频条目，右键选择 **导出 → 导出…**，或使用**使用上次设置导出**。该方式以选中的视频作为来源；若视频已脱机，导出入口不可用。复杂的片段选择请使用[字幕](/subtitles/subtitles)或[分镜](/storyboard/storyboards)后进入导出工作区。
