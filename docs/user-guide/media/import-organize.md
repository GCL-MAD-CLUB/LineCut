# 导入和整理媒体

将视频、音频、图像和可选字幕加入项目后，即可开始预览、整理与导出。导入默认使用原文件位置；需要集中保管时，开启复制媒体。

## 浏览并选择素材

1. 打开顶部**导入**工作区，从左侧选择磁盘或常用位置。
2. 双击文件夹进入，使用面包屑返回上级。
3. 按文件类型、名称和日期筛选或排序，选择列表或缩略图视图。
4. 勾选文件，或选择文件夹并等待其子文件夹扫描完成。
5. 在底部待导入栏核对本次选择。

单击星形按钮可收藏位置。列表中的“—”表示该项信息尚未取得或不适用。

**Shift + 单击**选择连续项，文件区中的 **Ctrl + A** 选择当前可见项。已导入的同一路径会显示**已导入**。扫描中的文件夹暂不能导入；无法读取时可右键选择**重新扫描文件夹**，或移除后选择可访问的子文件夹。

在待导入栏中，使用 **Ctrl** 或 **Shift** 多选，再按 **Delete** 移除；右键菜单可清除全部或查看所在文件夹。移除待导入项不会删除磁盘文件。

## 设置组织方式

### 添加到新媒体箱

在**组织媒体**中开启**添加到新媒体箱**并输入名称。本次素材将集中放入新媒体箱；同名时会自动区分名称。

媒体箱用于项目内分类。它与磁盘上的文件夹分别管理，移动项目条目不会移动原文件。

### 复制媒体

开启**复制媒体**后，选择复制方式和目标位置。

| 选项                | 结果                                   |
| ------------------- | -------------------------------------- |
| 复制并进行 MD5 校验 | 复制后检查完整性，耗时可能较长         |
| 复制且不校验        | 生成副本，不执行额外完整性检查         |
| 与项目相同          | 复制到项目文件所在文件夹，需先保存项目 |
| 选择文件夹          | 复制到自行指定的位置                   |

项目会使用复制后的文件。同名文件保留，新副本自动区分名称。请在确认副本可用后，再决定如何保管原素材。

### 自动绑定音频和字幕

有独立录音或字幕时，可开启**自动绑定**，选择全部、仅音频或仅字幕，并选择智能推断或按名称匹配。

**直接绑定**将辅助媒体归到目标视频；**虚拟复制后绑定**保留原条目，另建项目条目用于绑定，不会复制磁盘文件。

名称相近的多机位或多语言素材可能需要人工核对。未自动匹配时仍可完成导入，再按[管理音频与字幕轨](/media/tracks-binding)手动绑定。

## 完成导入

1. 确认文件夹扫描结束，待导入数量正确。
2. 检查复制目标、可用空间和媒体箱名称。
3. 单击**导入**，等待登记完成。
4. 切换到**编辑**工作区，在媒体箱中检查条目和预览。

后续媒体分析可能继续进行，部分缩略图和轨道信息稍后出现。失败的项目保留在待导入栏，修正问题后可重试；已成功的项目会保留。

## 在媒体箱中整理

使用列表或图标视图浏览，按名称搜索和排序。通过右键菜单或工具栏创建媒体箱、重命名、复制、粘贴、重复和移动条目；双击视频可在源监视器打开。

- **复制、粘贴和重复**创建项目内条目，不复制磁盘上的原文件。
- **隐藏**改变浏览时的可见性；需要时恢复显示隐藏项。
- **禁用**让条目暂不参与相应操作，需要使用时重新启用。
- **删除**从项目中移除所选条目，不删除原始媒体。
- 媒体箱顶部的笔 / 锁按钮切换**项目只读**状态。只读时可以预览，编辑前需解除只读。

列表中的启用与隐藏复选框可直接更改状态；右键菜单中的**查看隐藏内容**可显示已隐藏项。重命名仅改变项目中的显示名称，不改变磁盘文件名。

拖动条目到媒体箱文件夹可移动分类位置。文件夹可多级组织，双击进入，使用路径导航返回上级。通过窗口菜单可分别打开不同媒体箱视图。

删除媒体前请确认关联的分镜、标注和轨道是否仍需要保留，必要时保存项目副本。完成整理后按 **Ctrl + S** 保存。

## 管理媒体连接

原文件被移动或磁盘未连接时，条目可能显示脱机。请使用**链接媒体…**重新选择文件，或为大文件[创建代理](/media/offline-proxies)。查看完整的[支持格式](/reference/supported-formats)。
