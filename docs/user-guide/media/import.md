# 导入媒体

LineCut 支持在一个项目中导入多个视频、音频和字幕。视频和音频会先经过媒体探测；外部字幕作为独立字幕条目加入项目，之后可绑定到某个视频。

## 支持的导入扩展名

| 类型 | 扩展名                                                          |
| ---- | --------------------------------------------------------------- |
| 视频 | `mkv`、`mp4`、`mov`、`webm`、`avi`、`ts`、`m2ts`、`mpeg`、`mpg` |
| 音频 | `wav`、`mp3`、`m4a`、`aac`、`flac`、`ogg`、`opus`、`wma`        |
| 字幕 | `srt`、`ass`、`ssa`、`vtt`、`webvtt`                            |

实际能否正常预览、探测或导出仍取决于文件内的编码，以及当前 FFmpeg 配置。

## 使用导入工作区

1. 点击顶部的**导入**工作区。
2. 分别使用**添加视频**、**添加音频**、**添加字幕**选择多个文件。
3. 所选文件先进入待导入列表；可点击单行的移除图标，或点击**清除**放弃全部待导入项。
4. 检查列表中的名称、类型和所在位置，点击**导入全部**。
5. 导入完成后，视频、音频和字幕会出现在项目中；若有媒体探测提示，会显示在应用顶部的导入提示区域。

## 从媒体箱快速导入

在编辑工作区中可使用媒体箱工具栏的导入按钮，或右键单击媒体箱空白处 / 文件夹并选择**导入…**。文件会加入当前媒体箱或你打开的目标媒体箱。

也可以使用 **文件 → 导入…** 或 <kbd>Ctrl</kbd> + <kbd>I</kbd>。该入口允许在同一个选择框中挑选支持的媒体和字幕格式。

## 重复文件与取消任务

- 导入工作区按文件路径（忽略大小写和斜杠形式）识别已导入媒体；选择已有路径会被忽略。
- 同一次选择中的重复路径也只会保留一次。
- 媒体探测属于可见任务；导入多个视频或音频时可以取消。已经成功导入的项会保留，未完成项不会加入项目。
- 项目处于只读状态时不能导入，先在媒体箱解除只读。

外部字幕导入后若没有显示在目标视频的字幕面板中，请继续[绑定音频和字幕到视频](/media/bind)。
