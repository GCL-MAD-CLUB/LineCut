# 管理媒体条目

## 重命名项目中的显示名称

媒体箱中的名称是项目显示名称，不会修改硬盘上的原始文件名。

1. 在列表视图中双击媒体名称，或右键选择合适的重命名入口。
2. 输入新名称后按 <kbd>Enter</kbd> 或将焦点移出输入框确认；按 <kbd>Escape</kbd> 取消。
3. 该名称用于媒体箱显示和部分导出命名规则。

## 启用与禁用

每个媒体条目都有“启用”状态。禁用后，条目不会作为正常活动媒体参与预览；例如禁用的视频不能拖到源播放器预览。需要临时排除素材又不想删除时，优先使用禁用或隐藏。

## 隐藏与查看隐藏内容

隐藏用于整理界面，不会脱机、不删除文件，也不会改写原始媒体。右键菜单中选择**查看隐藏内容**后，隐藏条目和文件夹会重新出现在当前媒体箱，便于恢复或继续操作。

## 从媒体箱激活预览

双击视频条目，或把它拖到源播放器，能把该视频设为活动预览。源播放器、字幕和分镜面板会随活动视频更新。音频和字幕若已绑定到该视频，将在对应功能中可用。

## 移除与删除的区别

在媒体箱中选择条目后使用删除/清除，操作的是**项目条目**：它会从当前 `.lcp` 项目移除，不会删除原始视频、音频、字幕或代理文件。

> [!WARNING]
> 移除一个视频会使绑定到该视频的辅助媒体失去该绑定关系。需要保留后续编辑空间时，先保存项目副本。

## 从媒体箱导出视频

选中在线的视频条目，右键选择 **导出 → 导出…**，或使用**使用上次设置导出**。该方式以选中的视频作为来源；若视频已脱机，导出入口不可用。复杂的片段选择请使用[字幕](/subtitles/selection-export)或[分镜](/storyboard/views-selection)后进入导出工作区。
