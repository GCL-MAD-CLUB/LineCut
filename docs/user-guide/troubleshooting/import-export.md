# 导入与导出失败排查清单

下面的清单按“最容易验证、最少改变项目”的顺序排列。每执行一步后，先在短样本上复测，避免在未知状态下反复改动大量设置。

<GuideImage src="/images/troubleshooting/import-export.png" alt="截图占位：任务进度或错误通知" />

## 导入失败

1. 确认文件仍在磁盘上且自己能用其他播放器打开；
2. 确认扩展名属于当前 [支持的格式](../reference/supported-formats)；
3. 在首选项确认 ffprobe 与 FFmpeg 可用；
4. 用一个短、常见编码的 MP4 或 SRT 测试应用是否可正常导入；
5. 对单个异常文件，尝试用外部工具生成副本后再导入，并保留原文件。

## 导出失败

1. 确认导出来源至少勾选了一项，且每一项引用的媒体在线；
2. 改到一个本地、可写、空间充足的指定输出目录；
3. 选择“询问”或“新名称”来排除同名冲突；
4. 使用 H.264/MP4、匹配源、自动性能做一个短试片；
5. 若失败，切换到“仅限软件”，再检查 FFmpeg 路径；
6. 记录错误信息后再调整编码、画质或代理选项。

## 成功但结果不符合预期

- 范围错误：检查勾选项、字幕入出点、分镜范围和合并模式；
- 没声音：检查来源音频绑定、音频开关和纯视频/纯音频容器；
- 文件质量差：检查分辨率、质量档和是否使用代理；
- 新文件找不到：检查输出目的地、子文件夹以及“导入项目”是否勾选；
- 打不开：换目标播放器或改用兼容性更广的 H.264/MP4。

## 提交问题前的最小复现

复制一个短的非敏感媒体，记下从新建项目到失败的每一步。附上截图、错误文本、应用版本和导出设置；不要上传含有保密内容的原始素材。
