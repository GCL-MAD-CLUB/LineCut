# 性能、缓存与稳定性

长视频、高分辨率素材、多轨音频、密集缩略图和自动分镜检测都会增加 CPU、GPU、内存、磁盘与媒体解码的负担。性能问题应先通过缩小工作集和验证代理来定位，而不是直接改变全部项目设置。

<GuideImage src="/images/troubleshooting/performance.png" alt="缓存与代理相关设置" />

## 预览不流畅

1. 确认源媒体未离线，且位于稳定的本地磁盘或可靠存储；
2. 为当前视频生成代理，先用较小尺寸验证效果；
3. 避免同时打开大量高分辨率媒体和后台导出；
4. 检查磁盘剩余空间，特别是缓存和代理所在磁盘；
5. 重启应用后只打开一个小项目，判断问题是否与特定项目有关。

代理有利于编辑流畅度，但正式输出要明确选择是否使用代理。详细做法见 [创建与管理代理](../media/proxies)。

## 缓存策略

首选项中可以设置缓存目录。选择空间充足、读写稳定的本地位置；不要把缓存设为经常断开的移动盘或会被系统清理的临时位置。变更缓存位置前，请完成当前导出并保存项目。

自动保存快照也会使用缓存相关位置。降低自动保存间隔或提高快照上限会增加写入频率和磁盘占用；它们应在数据恢复需求与磁盘负担之间折中。

## 自动检测或导出耗时很长

这是媒体分析与转码的正常成本。先在短片段测试；确认范围无误后再处理长素材。导出时，较高质量、质量优先编码、较大分辨率和软件编码通常耗时更多。不要在任务运行时移动源素材或断开输出磁盘。

若应用持续无响应，保留任务状态和最后的错误信息，避免强制退出后立即覆盖自动保存恢复结果。重新打开后先确认项目和素材状态，再继续操作。
