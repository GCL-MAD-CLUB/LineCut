# 故障排查

先保存当前项目，并记录屏幕上的提示。按下面对应现象检查；仍无法解决时，使用页面末尾的日志与反馈方法。

## 媒体工具不可用

导入、分析、生成代理或导出立即失败时：

1. 打开**编辑 → 首选项 → 媒体工具**。
2. 检查 FFmpeg 和 ffprobe 路径是否对应实际可用文件。
3. 自行安装工具时，建议使用同一发行包中的两个程序。
4. 没有可用工具时，重新运行安装程序选择内置 FFmpeg。
5. 确定设置后，重新提交任务。

重置工具路径只恢复默认命令名称，不会安装缺失程序。

## 无法导入或看不到素材

确认当前已创建项目、文件类型受支持、文件可读取且未被其他程序独占。选择文件夹时需等待扫描结束，无法读取的目录可重新扫描或改为选择可访问子目录。

同一路径显示**已导入**时，请到媒体箱查找，不必重复导入。导入后部分缩略图和轨道信息需要等待分析。复制导入失败时，检查目标盘空间和权限，修正后重试待导入栏中的剩余项。

## 媒体脱机或画面为空

1. 连接素材盘，确认原文件位置。
2. 在媒体箱检查条目是否启用。
3. 对脱机项执行**链接媒体…**。
4. 如只连接了代理，在播放器中选择**代理**预览。
5. 需要检测、检索准备或导出静帧时，先恢复原始文件。

完整步骤见[管理离线媒体与代理](/media/offline-proxies)。

## 分镜没有出现或切点不准确

检查来源菜单是否选中视频、原始文件是否在线，等待识别任务结束。已有分镜时可主动重新切分，但覆盖前应保存副本。

淡入淡出、特殊转场或快速动作可能需要人工修正。使用源监视器[添加、移动或清除切点](/source/source-monitor#调整分镜切点)。

## 没有语义搜索或检索结果不理想

- 搜索模式没有**语义**：重新运行安装程序，确认语义检索组件已安装。
- 显示初始化或构建提示：等待完成；素材较多时准备时间较长。
- 分镜准备失败：确认原始视频在线、缓存盘可写且有足够空间。
- 结果过少：降低阈值，清除其他筛选条件，简化查询。
- 结果不相关：用具体画面描述搜索分镜，用对白主题搜索字幕，并播放核对。
- 无字幕内容：确认字幕来源和绑定；语义搜索不会生成字幕。

使用方法见[按画面查找镜头](/workflows/find-visuals)。

## 预览卡顿或磁盘空间不足

为高分辨率或高码率视频创建代理，并在源监视器切换到代理预览。检查素材盘、代理盘和缓存盘连接稳定，避免在处理期间移动文件。

在首选项中更换缓存位置只影响后续生成的缓存，不会迁移旧文件。自动保存位置独立设置，清理磁盘前请先保留原始素材、项目和需要的恢复文件。

## 保存失败或需要找回工作

检查项目位置是否可写、磁盘是否在线且空间充足。可尝试另存到可写位置，避免继续覆盖唯一副本。

需要恢复时，在首选项确认自动保存位置，打开所需的自动保存文件，核对后另存。**还原**只返回最近一次成功保存，可能已包含自动写回的内容。详见[自动保存与恢复](/projects/projects#自动保存与恢复)。

## 导出失败或结果异常

1. 检查已勾选有效片段，输出目录可写且有足够空间。
2. 确认原始素材在线；使用代理输出时，核对代理连接。
3. 检查至少启用了有效的视频或音频输出。
4. 确认同名文件提示已处理。
5. 硬件加速失败时，改用**仅限软件**重试。
6. 文件无法播放时，确认接收设备支持格式，必要时改用 H.264 / MP4。

无声时检查来源音频、绑定和音频开关。模糊时检查代理、分辨率和质量。范围错误时，重新核对导出列表与蓝色括号。取消后应检查已完成的文件。

完整设置见[导出媒体](/export/exporting)。

## 菜单或快捷键没有生效

单击目标面板，确认当前未在输入文字。检查项目是否只读、条目是否启用、来源是否锁定，以及命令是否适用于当前选择。

高亮搜索的左右方向键用于导航匹配项；逐帧操作应先聚焦源监视器。

## 查看与提供日志文件

1. 记下出现问题的时间、操作和报错内容。
2. 选择**帮助 → 显示日志文件**。
3. 找到对应时段的日志，复制一份用于反馈。
4. 检查日志中的路径、项目名称等信息，遮去不希望公开的内容。
5. 在[问题反馈页面](https://github.com/GCL-MAD-CLUB/LineCut/issues)说明应用版本、系统、操作步骤、媒体格式与提示。

不要提交私人素材或完整项目。确需样本时，先制作不含敏感内容且能重现问题的最小样本。反馈安全问题请使用[私密漏洞报告](https://github.com/GCL-MAD-CLUB/LineCut/security/advisories/new)。
