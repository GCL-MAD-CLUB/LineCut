# 当前限制与使用边界

> 适用版本：LineCut 0.3.3。本文以 `release/0.3.3` 分支实现为准。

本页列出当前桌面版的明确边界，帮助你在正式项目中建立可靠工作流。功能会随版本变化；本指南描述的是 LineCut 0.3.3 当前实现。

<GuideImage src="/images/reference/limitations.png" alt="功能边界示例" />

## 平台与运行环境

- 当前桌面产品面向 Windows 10 / 11；
- 本地文件选择、项目保存、系统文件夹、FFmpeg 任务等能力需要在桌面应用中运行；
- GitHub Pages 上的本指南只是静态网站，不是可在线运行的编辑器。

## 项目文件不是素材副本

`.lcp` 项目记录的是编辑状态和对本机媒体路径的引用，不会把视频、音频或代理文件打包进去。移动、改名或删除素材后，项目会出现离线项，需重新链接。分享项目时，请一并交付素材并尽量保持目录结构。

## 临时界面状态

字幕面板中的当前搜索词、过滤条件和临时选择不是项目内容的一部分。重新打开项目后，不能依赖这些临时视图恢复；标签、颜色、评分、关键字、分镜等已写入项目的编辑状态则应保存后保留。

## 自动保存的边界

自动保存是恢复辅助，不是版本管理：它按首选项中的间隔写入快照，并遵循全局快照数量上限。仍应在关键节点手动保存 `.lcp`，特别是在大批量标注、重新链接、导出前和交付前。

## 媒体与编码

导入和导出兼容性取决于 FFmpeg、ffprobe、显卡驱动、源文件编码以及目标播放器。扩展名受支持不等于每个文件或设备组合都能成功；遇到问题要保留源文件信息、导出设置和报错文本，方便复现。

## 功能语义的注意点

- 代理用于提高预览流畅度或快速审核导出，不能替代原始素材归档；
- 分镜自动检测给出镜头切点建议，仍应人工复核；
- 关键字的父子关系会影响匹配与筛选，修改树结构前应理解 [关键字管理](/storyboard/use-keywords)；
- 自动重新链接只扫描手动选中文件所在的同一层目录，不会递归搜索子目录；启用媒体开始或磁带名称匹配时还依赖 ffprobe 可读取相应元数据。详见 [媒体离线与重新链接](/media/offline-proxies)。

这些边界不是故障；把它们纳入日常工作流程，反而能让项目更可恢复、更可交接。

## 0.3.3 多来源、编辑和检测边界

- 字幕和分镜可以跨多个视频搜索、标注和导出；字幕同一视频只选择一条轨道，不能在同一个面板并列它的两条字幕轨。
- 多来源列表在来源排序为正序或倒序时先按来源分组，再按来源内部列排序；设为“无”时按其他列跨来源排序。各视频保留自己的时间坐标，不组成一条全局可编辑时间线。
- 合并分镜和堆叠按视频分别执行，不能组成跨视频镜头或堆叠；跨视频拼接使用合并导出。
- 字幕文本和时间只读，源监视器中的字幕范围及字幕导出范围不可拖动改写。分镜导出范围编辑与项目切点编辑分别保存历史。
- 高亮搜索保留非匹配项；全选可能包括它们。高亮导航按匹配条目计数，并不按命中的文字片段计数。
- 原始媒体脱机而代理在线时，可以浏览和预览；分镜自动检测仍需要原始媒体在线。
- 最多三项分镜检测并行，其他任务独占执行；非阻塞界面不等于无限并行，也不代表可以在处理期间移动源文件。
- 自动检测的事件模型仍标记为 `bootstrap_uncalibrated`，并非已在所有素材上验证的精确切点标准；淡入淡出、转场和特殊编码须人工复核。
- 来源工作区在本机恢复，不嵌入 `.lcp`；关闭全部来源工作区不删除项目数据，但不能再用来源历史返回被关闭的工作区。
