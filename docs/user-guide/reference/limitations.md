# 当前限制与使用边界

安排正式工作前，请确认以下条件；需要具体操作时，可按链接进入相应主题。

## 媒体与项目

- 桌面应用面向 Windows 10 / 11，64 位。
- 项目文件不包含原始媒体。交接时同时提供素材，路径变化后重新链接。
- 代理可用于预览和审核输出，但不能替代原始素材归档。
- 镜头检测、画面检索准备和原始分辨率静帧导出需要原始视频在线。
- 更改缓存或自动保存位置，不会迁移旧文件。

保管与恢复方式见[创建和管理项目](/projects/projects)。

## 搜索与字幕

- 语义检索需要安装可选组件。它用于寻找相关内容，不能保证每个结果都符合意图。
- 分镜语义检索依据画面，字幕语义检索依据已有字幕；均不提供音频听写。
- 字幕面板中的文字与原始时间只读。导出预览可单独调整输出范围。
- 位图字幕和烧录字幕不能直接用于文字检索。
- 同一视频在一个字幕面板中一次显示一条轨道。
- 高亮搜索保留非匹配项，全选前应确认是否需要切换过滤模式。

## 镜头整理和导出

- 自动镜头识别需要人工检查，尤其是转场、闪光和快速运动处。
- 不同视频可以集中检索和标注；合并镜头与堆叠分别在各视频内进行。
- 跨视频拼接应使用合并导出；不提供多轨时间线编排、转场和特效制作。
- 临时导出范围不随项目保存，撤销范围也不能恢复已覆盖的成品。
- 色标与自定义标签互斥。
- 关键字层级不支持直接移动，调整父级需新建正确分类并重新赋值。

## 本机使用环境

面板布局、来源浏览记录和最近导出设置在当前电脑使用；复制项目到另一台电脑后需重新检查。临时搜索、过滤和勾选不宜作为交付记录，重要决定应写入标记并保存。

处理任务期间保持相关磁盘连接。取消可能保留已完成的部分结果，应核对项目和输出文件后继续。

格式条件见[支持的格式与兼容性](/reference/supported-formats)。
