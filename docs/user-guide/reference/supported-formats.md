# 支持的格式与兼容性

LineCut 的导入、预览、分析和导出依赖媒体文件本身以及 FFmpeg/ffprobe 的解码能力。文件扩展名能帮助应用分类，但同一扩展名内部的编码差异仍可能影响是否能正常工作。

<GuideImage src="/images/reference/supported-formats.png" alt="导入文件选择器的格式筛选" />

## 可导入的文件类型

| 类型 | 当前导入筛选包含的扩展名                                                 | 用途                              |
| ---- | ------------------------------------------------------------------------ | --------------------------------- |
| 视频 | `.mkv`、`.mp4`、`.mov`、`.webm`、`.avi`、`.ts`、`.m2ts`、`.mpeg`、`.mpg` | 预览、分镜、导出、与字幕/音频绑定 |
| 音频 | `.wav`、`.mp3`、`.m4a`、`.aac`、`.flac`、`.ogg`、`.opus`、`.wma`         | 音频素材或绑定到视频              |
| 字幕 | `.srt`、`.ass`、`.ssa`、`.vtt`、`.webvtt`                                | 搜索、标注、按字幕创建导出范围    |

“支持扩展名”不保证每一个文件都能解码。比如同为 MP4 的文件可能采用不同视频或音频编码；若导入失败，请先查看 [FFmpeg 与工具配置](/troubleshooting/troubleshooting)。

## 内嵌字幕与外部字幕

视频文件可以包含内嵌字幕流；也可以单独导入外部字幕文件。导入后，请在素材箱中确认字幕已绑定到正确视频，必要时使用 [绑定视频、音频和字幕](/media/tracks-binding)。

外部字幕内容的解析能力以当前支持的 SRT、ASS/SSA 和 WebVTT 为准。复杂排版、特效或格式私有字段未必会完整保留为可编辑语义；重要项目请先导入一小段核对时间轴和文字。

## 当前可导出的容器

| 导出项       | 扩展名  | 典型用途                         |
| ------------ | ------- | -------------------------------- |
| H.264        | `.mp4`  | 通用视频交付                     |
| HEVC (H.265) | `.mp4`  | 高效率压缩，需确认目标设备兼容性 |
| Apple ProRes | `.mov`  | 后期交换与高质量中间文件         |
| VP9          | `.webm` | WebM 工作流                      |
| MP3          | `.mp3`  | 纯音频交付                       |
| AAC 音频     | `.aac`  | 纯音频交付                       |

导出页会限制不合理的组合：例如纯音频容器不能包含视频，来源没有音频时不能选择纯音频容器。完整设置说明见 [导出工作区概览](/export/exporting)。

## 最稳妥的兼容性策略

给不确定的平台或用户交付时，优先以 H.264/MP4、小样本试导出和目标环境实测为准。若是专业后期交接，先和接收方确认其需要的 ProRes、帧率、分辨率与音频规格。不要只依据扩展名判断成功。
