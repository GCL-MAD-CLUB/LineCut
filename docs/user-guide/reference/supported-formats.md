# 支持的格式与兼容性

导入前确认文件类型，交付前确认接收方的编码与规格要求。同一扩展名可能包含不同编码，能否正常使用还取决于文件内容和媒体工具。

## 可导入的文件

| 类型 | 扩展名                                                  |
| ---- | ------------------------------------------------------- |
| 视频 | MKV、MP4、MOV、WebM、AVI、TS、M2TS、MTS、MPEG、MPG、M4V |
| 音频 | WAV、MP3、M4A、AAC、FLAC、OGG、Opus、WMA、AIFF          |
| 图像 | JPG、JPEG、PNG、WebP、BMP、TIF、TIFF、GIF               |
| 字幕 | SRT、ASS、SSA、VTT、WebVTT                              |

图像可作为项目媒体导入；导入支持不代表每类媒体都具备与视频相同的分镜或检索能力。

视频的内嵌文字字幕和绑定的外部字幕可用于对白检索。位图字幕、烧录字幕不能直接用于文字检索；复杂字幕排版不作为字幕编辑功能提供。详见[使用字幕](/subtitles/subtitles)。

## 视频与音频输出

| 编码 / 格式   | 扩展名 | 常见用途     |
| ------------- | ------ | ------------ |
| H.264         | .mp4   | 常规视频交付 |
| HEVC（H.265） | .mp4   | 高效率压缩   |
| Apple ProRes  | .mov   | 后期交换     |
| VP9           | .webm  | WebM 交付    |
| MP3           | .mp3   | 音频交付     |
| AAC           | .aac   | 音频交付     |

可用音频选项随输出格式与来源变化，选择框中未提供的组合不可直接使用。设置方法见[导出媒体](/export/exporting)。

## 静帧输出

**导出帧**提供 BMP、DPX、GIF、JPEG、OpenEXR、PNG、Targa 和 TIFF，默认 PNG。通过源监视器的分镜模式导出，使用原始视频分辨率。

完整步骤见[导出当前帧](/source/source-monitor#导出当前帧)。

## 兼容性核对

首次处理一类素材时，先检查能否导入、预览和正确定位。交付前使用目标播放器核对画面与声音；较通用的视频交付可选择 H.264 / MP4。

HEVC、ProRes、WebM 和专业图像格式需确认接收软件支持。遇到问题时，记录媒体编码和报错，按[故障排查](/troubleshooting/troubleshooting)处理。
