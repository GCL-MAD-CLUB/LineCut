# 使用源监视器

源监视器用于查看当前激活的视频、音频、字幕或分镜位置。它既是播放器，也是字幕检索、分镜检查和导出预览共同使用的定位与精修中心。

本页集中说明播放控制、画面缩放、时间线导航、范围调整和分镜切点编辑。范围或切点编辑会写入项目，但不会改写源媒体。

## 预览、播放与逐帧控制

源播放器显示媒体箱中当前激活的视频。可在媒体箱双击视频，或将视频拖到播放器来切换预览源。

### 基本播放

| 控件或按键                                    | 行为                            |
| --------------------------------------------- | ------------------------------- |
| 播放 / 暂停按钮或 <kbd>Space</kbd>            | 切换播放状态                    |
| 上一帧 / 下一帧或 <kbd>←</kbd> / <kbd>→</kbd> | 按当前视频帧率逐帧移动          |
| <kbd>J</kbd>                                  | 反向 Shuttle 播放或加快反向速度 |
| <kbd>K</kbd>                                  | 暂停 Shuttle 播放               |
| <kbd>L</kbd>                                  | 正向 Shuttle 播放或加快正向速度 |

播放器会尽量让绑定音频与画面同步。逐帧和精确定位会暂时优先保证画面位置；高码率素材发生延迟时，建议创建代理。

### 播放速度与 J、K、L 组合

连续按 <kbd>J</kbd> 会逐级提高反向 Shuttle 速度，连续按 <kbd>L</kbd> 会逐级提高正向速度；<kbd>K</kbd> 停止 Shuttle。按住 <kbd>K</kbd> 的同时按住 <kbd>J</kbd> 或 <kbd>L</kbd> 可低速反向或正向查看，松开组合键后停止。焦点在可编辑文本框、面板未处于活动状态，或同时按住 Ctrl/Alt 时，这些播放器快捷键不会接管输入。

慢速播放会使用适合审听的音频处理方式，但不会改变原始媒体。反向、高倍速和逐帧主要用于定位；最终仍应以正常速度复核音画同步。

### 切换完整媒体和代理

播放器右侧的预览来源菜单提供**完整**和**代理**：

- 选择**完整**会读取原始视频；原始媒体脱机时，界面会提示先重新链接；
- 选择**代理**会读取已连接的代理；没有代理时不能凭此菜单自动创建代理；
- 原始视频脱机而代理在线时，LineCut 会继续用代理预览；重新连接完整分辨率媒体后可切回完整。

切换来源时会保留当前帧和播放状态。详情见[管理离线媒体与代理](/media/offline-proxies)。

### 缩放画面

播放器工具栏可选择**适合**或 10%、25%、50%、75%、100%、150%、200%、400%、800% 和 1600%。选择新的固定档位会把画面平移量复位到中心。

还可以直接在画面上滚轮缩放：

- <kbd>Ctrl</kbd>/Command + 滚轮：以鼠标所在位置为缩放中心；
- <kbd>Alt</kbd> + 滚轮：以画面中心为缩放中心；
- 没有修饰键的滚轮不会缩放画面。

缩放只改变播放器显示，不改变项目、素材分辨率或最终导出尺寸。

### 拖入视频

把媒体箱中的视频拖到播放器可激活它。禁用媒体不能拖入预览；脱机视频也无法正常加载。请在操作前确认媒体箱中的启用状态和连接状态。

### 与字幕和分镜的联动

- 点击字幕条目时，播放器会跳转到该字幕的开始位置并可播放该段内容。
- 点击分镜缩略图时，播放器会跳转到镜头的开始帧。
- 当前播放位置会用于字幕和分镜的跟随显示，便于核对检索结果。

有关时间线精确操作，请阅读[时间线、缩放与时间码](/source/source-monitor)。

## 时间线、缩放与时间码

源播放器底部时间线用于浏览当前视频的帧范围。它显示当前游标、可见时间范围和刻度，并与播放位置同步。

### 定位与拖动

- 单击时间线位置可跳转到对应帧。
- 在时间线按住并横向拖动可连续定位；拖到可见范围左右边缘外时，时间线会自动滚动，直到视频起点或终点。
- 使用上一帧/下一帧按钮或方向键做帧级微调。

时间线上的字幕或分镜范围以填充条、左右边界和中间手柄显示。拖动范围控件会写回当前字幕时间或分镜边界；在范围以外拖动仍只改变播放位置。

### 使用概览条平移和缩放

时间线下方的概览条表示当前可见范围在整个视频中的位置：

1. 按住概览条中间的高亮范围并左右拖动，可平移到更早或更晚的时间；
2. 拖动左边界或右边界可改变时间线显示跨度；向内缩小跨度会放大时间线，向外扩大跨度会缩小时间线；
3. 缩放会尽量保持原可见范围的中心位置，并受视频长度和最小可见帧数限制。

### 使用滚轮平移和缩放

- 在时间标尺上直接滚动：按帧向前或向后移动播放头；
- 在播放控制行或下方概览条直接滚动：以当前可见范围中心为锚点缩放；
- 在播放控制行或概览条按住 <kbd>Alt</kbd> 滚动：保持当前跨度，向更早或更晚的位置平移；
- 缩小可快速纵览长素材，放大可在剪辑点、字幕起止和镜头边界附近精细检查。

### 时间码编辑

时间码显示当前播放位置，并支持输入和擦洗两种操作。

#### 输入时间码

1. 单击时间码进入编辑并全选原值；在编辑状态中单击可放置光标，双击会重新全选。
2. 输入目标时间码或帧位置。
3. 按 <kbd>Enter</kbd> 确认跳转，或移开焦点提交。
4. 按 <kbd>Escape</kbd> 取消修改。

只有能被当前帧率解析、且位于 0 到媒体总帧数之间的值才会生效；无效或越界输入会被忽略，并保留原播放位置。

#### 拖动时间码逐帧擦洗

1. 在时间码上按住鼠标左键，稍候到擦洗状态启动；
2. 向左或向右拖动，每移动一定像素就向前或向后改变一帧；
3. 松开鼠标结束。擦洗会暂停播放，并且这次松开不会再进入文本编辑。

## 调整字幕和分镜范围

从字幕或分镜面板打开完整范围预览后，时间线上会出现可编辑范围。左、右边界分别控制入点和出点，中间的短手柄用于整体移动。

### 更改入点或出点

1. 在字幕或分镜面板中单击缩略图画面，或双击条目，载入完整范围。
2. 必要时用下方概览条放大时间线。
3. 拖动范围左边界以更改入点，或拖动右边界以更改出点。
4. 拖动期间查看临时预览帧；松开后，画面恢复到操作前的播放头位置。
5. 回到字幕或分镜面板，确认持续时间和相邻条目边界。

字幕范围会更新该字幕的开始/结束时间。分镜范围会移动相邻切点，因此一个镜头变长时，相邻镜头会相应变短。边界不能越过另一个边界，也不能超出媒体范围。

### 移动整个范围

拖动填充条中间的手柄可同时移动入点和出点，并保持范围长度。移动会限制在媒体起点与终点之间。对分镜而言，最终结果仍受相邻镜头边界约束。

一次连续拖动会归入同一历史操作。结果不符合预期时，可使用 <kbd>Ctrl</kbd> + <kbd>Z</kbd> 撤销。

> [!NOTE]
> 只有从字幕或分镜条目载入、且仍关联到该条目的范围才会写回项目。普通浏览产生的临时范围不会凭空创建字幕或分镜。

## 调整分镜切点

分镜检测或手动添加切点后，时间线顶部会显示切点标记。标记颜色来自切点右侧分镜的色标；带自定义标签的分镜使用白色，没有标记则使用灰色。切点代表右侧分镜的开始帧。

### 显示、定位和选择切点

1. 在时间标尺上右键，确认**显示切点**已勾选；需要精确读数时也勾选**时间标尺数字**。
2. 单击切点可将播放头定位到该帧，并让分镜面板显示对应镜头。
3. 按住 <kbd>Shift</kbd>、<kbd>Ctrl</kbd> 或 Command 单击，添加或移除多个切点。
4. 单击切点标签区域的空白处清空切点选择。

右键时间线后可选择**转到下一个切点**或**转到上一个切点**。命令以当前播放头为基准，不要求先选中切点。

### 添加切点

1. 把播放头定位到现有分镜内部；不能位于媒体起点、终点或已有切点上。
2. 右键时间线并选择**添加切点**。
3. 当前分镜在播放头处分为左右两个镜头，新切点自动选中。

新镜头会继承原镜头的标记；标题会生成不重复的默认值。添加切点会进入历史记录，可撤销。

### 拖动一个或多个切点

- 直接拖动单个切点以逐帧修正边界；拖动期间画面预览目标帧，松开后恢复原播放头。
- 先多选切点，再拖动其中任意一个，可让整组切点移动相同帧数。
- 连续切点移动受最左、最右相邻镜头限制，不会产生反向或零长度镜头。

需要输入精确值时，右键所选切点并选择**编辑切点...**。输入有效时间码后选择**确定**；对话框会显示允许范围，并可用**上一个**/**下一个**连续检查，或选择**删除**清除当前切点。

### 清除切点

| 命令            | 作用范围                                       |
| --------------- | ---------------------------------------------- |
| 清除所选的切点  | 合并所选切点两侧的分镜；支持一次处理多个切点   |
| 清除切点        | 清除当前字幕/分镜选区起止范围内的全部切点      |
| 编辑切点 → 删除 | 清除正在编辑的单个切点，并转到相邻切点继续检查 |

合并分镜时，左侧保留镜头会覆盖到右侧结束帧。它保留标题，并汇总合并镜头的最高星级、留用状态和关键字；被合并镜头的独立标记不再作为单独条目保留。

### 恢复普通删除的分镜

从分镜面板执行普通**删除**后，时间线仍保留该区间和切点，并以斜线填充表示“无分镜区域”。连续播放会自动跳过该范围，但仍可手动定位检查源画面。

1. 在斜线切点上单击；可用修饰键选择多个已删除切点。
2. 右键并选择**从选中的切点恢复**。
3. 恢复后的分镜按时间顺序重新编号，并重新出现在分镜面板。

只有选择全部属于已删除区域的切点时，恢复命令才可用。**波纹删除**会闭合到后续镜头并清理对应标记，不保留同样的独立恢复入口；需要撤回时请使用历史记录。

### 操作建议

- 确认字幕起止或镜头切点时，先放大时间线，再用方向键逐帧检查。
- 批量移动切点前先保存项目副本，或确认历史面板能看到当前操作。
- 浏览长素材时，先缩小或平移，不要在极度放大的时间线中拖动很远距离。
- 如果时间线或预览长期无响应，先检查素材是否脱机、代理是否可用以及磁盘缓存空间。

### 与字幕和分镜的配合

时间线只作用于当前活动视频。选中字幕或分镜后，先观察源监视器是否已载入对应范围；在范围边界、范围中间手柄或切点上拖动会修改项目，其他位置的单击和拖动只用于定位。

当切换活动视频、重新链接素材或改用代理后，先重新定位一次再继续审看。这样可以确认时间码、缩略图与当前媒体来源仍一致。
