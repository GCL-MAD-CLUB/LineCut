# 使用源监视器

源监视器用于查看当前激活的视频、音频、字幕或分镜位置。它既是播放器，也是字幕检索、分镜检查和导出预览共同使用的定位中心。

本页集中说明播放控制、画面缩放、时间线导航和时间码输入，避免在多个页面之间来回查找。

## 预览、播放与逐帧控制

源播放器显示媒体箱中当前激活的视频。可在媒体箱双击视频，或将视频拖到播放器来切换预览源。

### 基本播放

| 控件或按键                                    | 行为                            |
| --------------------------------------------- | ------------------------------- |
| 播放 / 暂停按钮或 <kbd>Space</kbd>            | 切换播放状态                    |
| 上一帧 / 下一帧或 <kbd>←</kbd> / <kbd>→</kbd> | 按当前视频帧率逐帧移动          |
| <kbd>J</kbd>                                  | 反向 Shuttle 播放或加快反向速度 |
| <kbd>K</kbd>                                  | 暂停 Shuttle 播放               |
| <kbd>L</kbd>                                  | 正向 Shuttle 播放或加快正向速度 |

播放器会尽量让绑定音频与画面同步。逐帧和精确定位会暂时优先保证画面位置；高码率素材发生延迟时，建议创建代理。

### 播放速度与 J、K、L 组合

连续按 <kbd>J</kbd> 会逐级提高反向 Shuttle 速度，连续按 <kbd>L</kbd> 会逐级提高正向速度；<kbd>K</kbd> 停止 Shuttle。按住 <kbd>K</kbd> 的同时按住 <kbd>J</kbd> 或 <kbd>L</kbd> 可低速反向或正向查看，松开组合键后停止。焦点在可编辑文本框、面板未处于活动状态，或同时按住 Ctrl/Alt 时，这些播放器快捷键不会接管输入。

慢速播放会使用适合审听的音频处理方式，但不会改变原始媒体。反向、高倍速和逐帧主要用于定位；最终仍应以正常速度复核音画同步。

### 切换完整媒体和代理

播放器右侧的预览来源菜单提供**完整**和**代理**：

- 选择**完整**会读取原始视频；原始媒体脱机时，界面会提示先重新链接；
- 选择**代理**会读取已连接的代理；没有代理时不能凭此菜单自动创建代理；
- 原始视频脱机而代理在线时，LineCut 会继续用代理预览；重新连接完整分辨率媒体后可切回完整。

切换来源时会保留当前帧和播放状态。详情见[管理离线媒体与代理](/media/offline-proxies)。

### 缩放画面

播放器工具栏可选择**适合**或 10%、25%、50%、75%、100%、150%、200%、400%、800% 和 1600%。选择新的固定档位会把画面平移量复位到中心。

还可以直接在画面上滚轮缩放：

- <kbd>Ctrl</kbd>/Command + 滚轮：以鼠标所在位置为缩放中心；
- <kbd>Alt</kbd> + 滚轮：以画面中心为缩放中心；
- 没有修饰键的滚轮不会缩放画面。

缩放只改变播放器显示，不改变项目、素材分辨率或最终导出尺寸。

### 拖入视频

把媒体箱中的视频拖到播放器可激活它。禁用媒体不能拖入预览；脱机视频也无法正常加载。请在操作前确认媒体箱中的启用状态和连接状态。

### 与字幕和分镜的联动

- 点击字幕条目时，播放器会跳转到该字幕的开始位置并可播放该段内容。
- 点击分镜缩略图时，播放器会跳转到镜头的开始帧。
- 当前播放位置会用于字幕和分镜的跟随显示，便于核对检索结果。

有关时间线精确操作，请阅读[时间线、缩放与时间码](/source/source-monitor)。

## 时间线、缩放与时间码

源播放器底部时间线用于浏览当前视频的帧范围。它显示当前游标、可见时间范围和刻度，并与播放位置同步。

### 定位与拖动

- 单击时间线位置可跳转到对应帧。
- 在时间线按住并横向拖动可连续定位；拖到可见范围左右边缘外时，时间线会自动滚动，直到视频起点或终点。
- 使用上一帧/下一帧按钮或方向键做帧级微调。

时间线上的字幕范围以填充条和左右边界显示，只用于提示当前聚焦字幕的起止范围；在时间线拖动不会改写字幕时间码。

### 使用概览条平移和缩放

时间线下方的概览条表示当前可见范围在整个视频中的位置：

1. 按住概览条中间的高亮范围并左右拖动，可平移到更早或更晚的时间；
2. 拖动左边界或右边界可改变时间线显示跨度；向内缩小跨度会放大时间线，向外扩大跨度会缩小时间线；
3. 缩放会尽量保持原可见范围的中心位置，并受视频长度和最小可见帧数限制。

### 使用滚轮平移和缩放

- 在时间线控制区直接滚动：以当前可见范围中心为锚点缩放；
- 按住 <kbd>Alt</kbd> 滚动：保持当前跨度，向更早或更晚的位置平移；
- 缩小可快速纵览长素材，放大可在剪辑点、字幕起止和镜头边界附近精细检查。

### 时间码编辑

时间码显示当前播放位置，并支持输入和擦洗两种操作。

#### 输入时间码

1. 单击时间码进入编辑并全选原值；在编辑状态中单击可放置光标，双击会重新全选。
2. 输入目标时间码或帧位置。
3. 按 <kbd>Enter</kbd> 确认跳转，或移开焦点提交。
4. 按 <kbd>Escape</kbd> 取消修改。

只有能被当前帧率解析、且位于 0 到媒体总帧数之间的值才会生效；无效或越界输入会被忽略，并保留原播放位置。

#### 拖动时间码逐帧擦洗

1. 在时间码上按住鼠标左键，稍候到擦洗状态启动；
2. 向左或向右拖动，每移动一定像素就向前或向后改变一帧；
3. 松开鼠标结束。擦洗会暂停播放，并且这次松开不会再进入文本编辑。

### 操作建议

- 确认字幕起止或镜头切点时，先放大时间线，再用方向键逐帧检查。
- 浏览长素材时，先缩小或平移，不要在极度放大的时间线中拖动很远距离。
- 如果时间线或预览长期无响应，先检查素材是否脱机、代理是否可用以及磁盘缓存空间。

### 与字幕和分镜的配合

时间线只控制当前活动视频的浏览位置。选中字幕或分镜后，先观察源监视器是否已定位到对应入点；如需精确确认范围，再放大时间线并逐帧检查。字幕、分镜和导出范围的改变不会通过拖动这条浏览时间线直接写入，避免把“定位”误当成“剪辑”。

当切换活动视频、重新链接素材或改用代理后，先重新定位一次再继续审看。这样可以确认时间码、缩略图与当前媒体来源仍一致。
