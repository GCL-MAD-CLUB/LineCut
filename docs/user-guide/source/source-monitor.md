# 使用源监视器

源监视器用于审看当前媒体、核对检索结果和检查镜头边界。在媒体箱双击视频，或单击分镜、字幕条目，即可打开对应内容。

## 播放与定位

| 控件或按键                  | 操作                             |
| --------------------------- | -------------------------------- |
| 播放按钮 / Space            | 播放或暂停                       |
| 上一帧、下一帧 / 左右方向键 | 逐帧检查                         |
| J / L                       | 反向或正向播放，连续按可提高速度 |
| K                           | 停止变速播放                     |
| 按住 K 再按住 J / L         | 低速向后或向前查看               |

先单击源监视器，确保快捷键作用于播放器。反向和高速播放适合定位，音画同步应以正常速度检查。

单击时间线跳转，拖动播放头连续定位。单击时间码可输入目标位置，按 **Enter** 或移开焦点确认，按 **Esc** 取消；越界或无效输入不会改变位置。按住时间码稍候再左右拖动，可逐帧擦洗。

## 调整画面和时间线显示

播放器工具栏提供**适合**及固定缩放比例。**Ctrl + 滚轮**以指针位置缩放，**Alt + 滚轮**以画面中心缩放。这些操作只改变查看大小。

时间线下方概览条可平移和缩放可见范围：拖动中部平移，拖动两端改变跨度。在播放控制行或概览条滚动可缩放，按住 **Alt** 滚动可平移。在时间标尺上滚动用于移动播放头。

## 切换完整媒体与代理

通过预览来源菜单选择**完整**或**代理**。没有代理时，请先在媒体箱创建或连接；原始媒体脱机时，可使用已连接的代理继续预览。

[管理离线媒体与代理](/media/offline-proxies)介绍了完整操作。

## 检查片段范围

单击分镜缩略图或双击镜头可打开完整范围；选择字幕可预览对白范围。字幕模式中的原始范围只供查看，不能拖动修改。

编辑工作区的分镜范围可调整：拖动左右边界改变入点、出点，拖动中间手柄移动范围。分镜边界与相邻镜头相连，调整后请检查相邻镜头时长。使用 **Ctrl + Z** 可撤销。

导出工作区允许独立调整所有来源的待导出范围，详见[在导出预览中调整范围](#在导出预览中调整范围)。

## 调整分镜切点

切点表示一个镜头的开始位置。编辑前确认当前为**编辑**工作区的分镜模式。

### 显示和添加切点

1. 右键时间标尺，开启**显示切点**；需要时显示时间标尺数字。
2. 单击已有切点可定位，右键菜单可转到上一个或下一个切点。
3. 将播放头定位到镜头内部。
4. 单击播放按钮左侧的添加切点图标，或右键选择**添加切点**。

新切点将镜头分为两段。媒体首尾和已有切点处不能重复添加。

### 移动与精确编辑

直接拖动切点修正位置。按住 **Ctrl** 或 **Shift** 多选后，拖动其中一个可整体移动；切点不能越过相邻边界。

需要精确输入时，右键选择**编辑切点…**，填写允许范围内的时间码并确认。可用**上一个 / 下一个**继续检查。

### 清除切点

右键选择**清除所选的切点**，合并相邻镜头；**清除切点**处理当前范围内的切点。编辑切点对话框也可删除当前切点。

合并后独立镜头数量和标记会变化。执行批量清除前保存副本，完成后检查标题、关键字和星级。

## 恢复普通删除的分镜

普通删除的分镜区间以斜线显示，连续播放时会跳过，但可手动查看原画面。

1. 单击已删除区间的切点，可用修饰键多选。
2. 右键选择**从选中的切点恢复**。
3. 回到分镜面板检查镜头和标记，并保存项目。

只有所选切点均属于已删除区间时，该命令才可用。波纹删除不提供此恢复方式，应使用撤销。

## 导出当前帧

在编辑工作区的分镜模式中，播放按钮右侧的摄像机图标用于**导出帧**。

1. 定位到所需画面，单击摄像机图标；播放暂停。
2. 确认名称，默认包含媒体名称、时间码和 Still 编号。
3. 选择 BMP、DPX、GIF、JPEG、OpenEXR、PNG、Targa 或 TIFF，默认 PNG。
4. 单击**浏览…**选择输出文件夹。
5. 需要继续在项目中使用时，勾选**导入到项目中**，再单击**确定**。

静帧读取原视频并使用原始分辨率，即使正在查看代理。原始媒体脱机时请先重新链接；同名图片不会被覆盖。

## 在导出预览中调整范围

1. 在导出列表单击片段，载入右侧预览。
2. 拖动蓝色括号左端或右端，修改待导出入点或出点；拖动中间手柄整体移动范围。
3. 核对时长，并从范围内播放检查；正向播放会停在右括号。
4. 使用 **Ctrl + Z / Ctrl + Shift + Z** 撤销或重做范围调整。

分镜、字幕和媒体箱来源均可调整。此处只改变待导出片段，不改变项目切点、原字幕时间或原始素材；撤销不会恢复已输出或覆盖的文件。

继续阅读[导出媒体](/export/exporting#调整导出范围)。
