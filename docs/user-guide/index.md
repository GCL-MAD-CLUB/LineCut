## 从哪里开始

- 第一次使用，请依次阅读[安装与首次启动](/getting-started/install)、[创建第一个项目](/getting-started/first-project)。
- 已经导入素材但需要找一句台词，请看[通过字幕找到片段](/workflows/find-dialogue)。
- 需要按画面内容整理素材，请看[整理分镜并建立关键字](/workflows/organize-storyboard)。
- 已经选好片段并准备交付，请看[导出所选片段或成片](/workflows/export-video)。

## 本站的使用方式

左侧目录按任务和功能分组；右上角的搜索会在本机浏览器内搜索整套指南。文章中的**截图占位**标出后续应补充的界面截图位置和应呈现的状态；它们不是程序中的按钮或提示。

> [!TIP]
> 用户指南以 LineCut v0.3.0 的已发布功能为准。若你的应用界面与本文不同，请先确认使用的版本，再参阅对应的更新说明。

## 反馈文档问题

如果文章缺少步骤、图示或与实际行为不符，可在页面底部通过“在 GitHub 上修改此页”提交修改建议，也可在项目的 Issues 中说明所用版本、操作步骤和截图。
