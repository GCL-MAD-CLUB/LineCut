# 历史记录、撤销与分支

## 撤销与重做

| 操作 | 快捷键                                            | 作用                       |
| ---- | ------------------------------------------------- | -------------------------- |
| 撤销 | <kbd>Ctrl</kbd> + <kbd>Z</kbd>                    | 回退一项项目操作           |
| 重做 | <kbd>Ctrl</kbd> + <kbd>Shift</kbd> + <kbd>Z</kbd> | 恢复刚撤销的下一项项目操作 |

撤销和重做作用于当前项目操作。输入框内编辑文字时，应用会优先让输入控件处理常规文本编辑，避免把文字编辑意外变成项目回退。

## 打开历史记录面板

选择 **窗口 → 历史记录**。面板从顶部到下方显示项目的基础状态和随后发生的操作，例如导入、重命名、标记、绑定、分镜检测、代理和导出相关操作。

1. 点击非当前状态的历史条目。
2. LineCut 跳转到该条目代表的项目状态。
3. 当前状态以下的条目会以“未来”状态显示；你可以重做回去，或从当前位置继续编辑。

## 从历史位置继续编辑

在旧状态上做出新的项目更改后，原来的“未来”分支不会继续作为独立分支保存。若你想保留两种方案，应先**保存副本**，再在各自项目文件中继续修改。

## 删除当前事件及后续历史

历史面板底部的删除按钮会将项目回到当前条目的上一个事件状态，并永久删除该条目及其后的历史记录。该动作无法撤销。

在删除前：

- 先检查是否只是需要普通撤销或跳转；
- 若可能还会比较这条分支，先保存项目副本；
- 不要把历史记录当作长期版本管理工具，重要阶段应保存单独 `.lcp` 文件。

项目的手动保存与自动备份见[最近项目、还原与自动备份](/projects/recent-restore-autosave)。
