# 创建和管理项目

项目保存媒体箱组织、轨道关系、镜头划分和标注。原始媒体仍位于自己的文件夹中，保存项目时请一并妥善保管素材。

## 使用项目首页

启动时默认显示项目首页。单击**新建项目**、**打开项目**或最近项目名称即可开始；右上角主页按钮可再次打开首页。

在**筛选最近的文件**中输入名称，或单击列标题排序。最近项目只是访问入口，原文件移动或删除后需要重新选择。首页可拖动和调整大小，双击标题栏恢复铺满；按 **Esc** 或单击**返回工作区**继续编辑。

是否在启动时显示首页，可在[首选项](/projects/preferences)中设置。

## 新建和打开项目

- **文件 → 新建项目**：创建空项目，快捷键 **Ctrl + N**。
- **文件 → 打开项目…**：选择已有 `.lcp` 文件，快捷键 **Ctrl + O**。
- **文件 → 打开最近使用的内容**：快速返回最近项目。

当前项目有未保存更改时，先选择存储、不保存或取消。打开后若提示媒体脱机，按[重新链接媒体](/media/offline-proxies#重新链接媒体)恢复。

## 保存工作

| 命令     | 快捷键           | 结果                             |
| -------- | ---------------- | -------------------------------- |
| 保存     | Ctrl + S         | 保存当前项目；首次保存需选择位置 |
| 另存为   | Ctrl + Shift + S | 保存为新文件，并继续编辑新文件   |
| 保存副本 | Ctrl + Alt + S   | 另存独立副本，继续编辑当前文件   |

建议在大批量删除、覆盖分镜或重新分类前保存副本。项目保存不会复制原始素材。

**文件 → 还原**返回当前项目最近一次成功保存的状态，包含已启用的自动写回保存。执行后，之后的未保存更改会丢弃；仅需回退个别操作时，应使用撤销。

## 自动保存与恢复

默认每 5 分钟检查项目变化，每个项目最多保留 20 个自动保存文件。设置位于**编辑 → 首选项 → 自动保存**。

自动保存文件位于独立配置的位置，默认是缓存目录下的 **Locution Pro Auto-Save**。开启**自动保存也会保存当前项目**后，也会写回当前项目；未命名项目仍需先手动保存一次。

### 恢复自动保存文件

1. 如当前项目仍可打开，先保存副本。
2. 在首选项中确认自动保存位置，找到所需时间附近的 `.lcp` 文件。
3. 使用**文件 → 打开项目…**打开该文件。
4. 核对媒体连接、镜头划分和标注。
5. 使用**另存为**保存到正式项目位置。

达到版本上限后，该项目最旧的自动保存文件会被移除。更改位置不会迁移旧文件；自动保存也不会备份原始素材。重要节点请保留独立副本。

## 使用历史记录

按 **Ctrl + Z** 撤销，按 **Ctrl + Shift + Z** 重做。也可打开**窗口 → 历史记录**，单击条目返回对应状态。

回到旧状态后继续编辑，原先后续操作将不能作为另一条方案继续保留。需要比较方案时，先保存项目副本。历史面板的删除按钮会删除当前条目及其后的历史，且无法撤销，请先确认是否只需普通回退。

导出工作区中的撤销用于临时导出范围，来源导航按钮用于切换浏览范围；两者均不同于项目历史。

## 移交项目

1. 保存项目，必要时保留交付副本。
2. 一并复制 `.lcp`、原始视频、音频、外部字幕及需要继续使用的代理。
3. 在接收电脑打开项目，对脱机条目重新链接。
4. 核对音频、字幕、代理、分镜和关键字，再保存项目。
5. 重新确认输出位置、筛选条件和待导出选择。

面板布局、来源浏览记录和最近导出设置属于当前电脑的使用环境。复制项目后，请重新核对这些设置；临时选择、搜索和导出范围调整不作为项目交付内容。

打开旧项目后首次保存前，保留原文件副本。由当前应用重新保存的项目可能无法在较早应用中打开。

## 关闭项目

**文件 → 关闭项目**关闭当前项目并保留应用；**文件 → 退出**关闭应用。有未保存更改时，按提示处理。

**文件 → 关闭**或 **Ctrl + W** 关闭当前面板。需要重新显示时，从**窗口**菜单打开。
