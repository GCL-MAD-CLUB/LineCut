# 创建和管理项目

LineCut 项目文件保存媒体引用、字幕、分镜、标记和工作状态，但不复制原始视频、音频或字幕文件。可靠的项目管理既包括正确使用保存命令，也包括维护素材路径和理解自动备份边界。

本页集中说明项目从创建到交接的完整生命周期。涉及缓存和工具路径的全局设置，请另见“首选项”。

## 新建、打开、保存和关闭项目

### 新建项目

选择 **文件 → 新建项目** 或按 <kbd>Ctrl</kbd> + <kbd>N</kbd>。新建项目会清空当前项目的媒体和整理状态；若当前项目有未保存更改，LineCut 会先询问如何处理。

新建后可立刻导入媒体。未保存项目会在顶部显示为“未命名项目”，并在存在修改时显示未保存标记。

### 打开项目

1. 选择 **文件 → 打开项目…**，或按 <kbd>Ctrl</kbd> + <kbd>O</kbd>。
2. 选择 `.lcp` 文件。
3. 若当前项目有未保存更改，先决定保存、放弃或取消打开。
4. 打开后检查媒体箱和源播放器；如果素材位置已经变化，按[脱机、替换和重新链接](/media/offline-proxies)处理。

也可从 **文件 → 打开最近使用的内容** 快速打开之前的项目。失效的最近项目会在打开失败后从列表移除。

### 保存、另存为与保存副本

| 命令     | 快捷键                                            | 行为                                               |
| -------- | ------------------------------------------------- | -------------------------------------------------- |
| 保存     | <kbd>Ctrl</kbd> + <kbd>S</kbd>                    | 保存到当前 `.lcp` 路径；未命名项目会先要求选择路径 |
| 另存为   | <kbd>Ctrl</kbd> + <kbd>Shift</kbd> + <kbd>S</kbd> | 写入新文件，并把新文件变成当前项目                 |
| 保存副本 | <kbd>Ctrl</kbd> + <kbd>Alt</kbd> + <kbd>S</kbd>   | 写入另一份 `.lcp`，但继续编辑原项目                |

保存副本适合在尝试大范围整理或交付一个版本前留出可恢复的独立文件。不要把“保存副本”误当成原始媒体备份：项目文件不包含视频本身。

<GuideImage src="/images/projects/create-open-save.png" alt="文件菜单中的项目保存命令" />

### 关闭项目与退出

- **文件 → 关闭项目** 或 <kbd>Ctrl</kbd> + <kbd>Shift</kbd> + <kbd>W</kbd>：关闭当前项目，保留应用窗口。
- **文件 → 关闭** 或 <kbd>Ctrl</kbd> + <kbd>W</kbd>：关闭当前聚焦的面板，不等同于关闭项目。
- **文件 → 退出** 或 <kbd>Ctrl</kbd> + <kbd>Q</kbd>：退出应用。

如果项目有未保存更改，关闭或退出时会显示“保存项目”对话框。选择**存储(S)**会先保存再继续，选择**不保存(D)**会放弃自上次手动保存以来的更改，选择**取消**会返回应用。

对话框打开且没有正在存储时，也可直接按 <kbd>S</kbd> 选择“存储”，按 <kbd>D</kbd> 选择“不保存”；这些字母快捷键不能与 Ctrl、Shift 或 Alt 组合。存储进行中三个按钮都会暂时禁用，等待完成后再继续原来的新建、打开、关闭或退出动作。

### 还原到上次保存

**文件 → 还原** 会把当前工作区还原到最近一次手动保存的状态，并丢弃之后的未保存项目更改。执行前请确认不需要这些更改；若只想回到某个操作节点，使用[历史记录、撤销与分支](/projects/projects)。

## 最近项目、还原与自动备份

### 最近项目

每次成功打开或保存项目后，LineCut 会把项目路径记录到 **文件 → 打开最近使用的内容**。它只是一个快捷入口，不会复制项目文件或原始媒体。

- 如果文件被移动、删除或没有访问权限，打开会失败；该无效条目会从最近列表中移除。
- 最近项目不保证原始媒体仍在线。项目打开后如有脱机媒体，请重新链接。
- 最近导入的媒体也会出现在导入相关的最近列表中，便于重复使用常见素材。

### 自动备份快照如何工作

LineCut 会按照**首选项中的自动备份检测间隔**在缓存目录创建项目工作区快照。默认是每 5 分钟检测一次，最多保留 20 个快照。

自动备份有三个重要特性：

1. 只有工作区内容发生变化时才会写入新快照；没有变化不会重复占用空间。
2. 快照位于缓存根目录下的 `LineCut Auto-Save` 文件夹中，文件扩展名也是 `.lcp`。
3. “最多保留自动备份快照”对整个自动备份目录生效，不是每个项目各自保留该数量；达到上限后最旧快照会被移除。

自动备份用于降低意外退出造成的损失，不能替代有明确文件名和保存位置的手动保存。

<GuideImage src="/images/projects/recent-restore-autosave.png" alt="首选项中的自动备份设置" />

### 从快照恢复时的原则

1. 先把当前 `.lcp` 手动保存为副本，避免覆盖仍有价值的版本。
2. 在缓存目录的 `LineCut Auto-Save` 中识别最接近需要时点的 `.lcp` 快照。
3. 通过 **文件 → 打开项目…** 打开该快照，检查媒体是否仍能定位。
4. 确认内容正确后，用**另存为**将其保存到正式项目位置；不要把缓存快照当成唯一长期存档。

> [!WARNING]
> 更改缓存路径、清理缓存盘或把“最多保留自动备份快照”设得很低，都可能让旧快照消失。关键工作节点仍应使用“保存”或“保存副本”。

### “还原”与自动备份不是一回事

**文件 → 还原**仅回到当前项目最近一次手动保存的状态；它不会让你在自动备份列表中选择版本。需要恢复意外退出前状态时，按本页的快照流程打开并另存为。

继续阅读[首选项](/projects/preferences)了解如何调整间隔、上限和缓存路径。

## 项目文件与素材位置

### `.lcp` 项目文件保存什么

项目文件保存的是 LineCut 的工作数据，包括：

- 媒体箱中的视频、音频、字幕条目和文件夹结构；
- 活动视频、活动字幕轨、绑定关系和预览代理关联；
- 字幕的星级、旗标、色标与自定义标签；
- 分镜检测结果、堆叠、标题、星级、旗标、色标和关键字；
- 项目的保存身份与导出相关的持久状态。

### `.lcp` 不保存什么

- 原始视频、音频、外部字幕和代理媒体本身；
- 字幕面板的临时勾选、搜索文本和过滤条件；
- 仅在当前界面会话中存在的临时选择。

因此，复制一个 `.lcp` 文件不等于复制项目素材。项目依赖的媒体仍在其原始路径上。

### 移交或迁移项目

1. 在原电脑执行**保存**，必要时再执行**保存副本**作为备份。
2. 收集 `.lcp` 文件以及所有原始视频、音频、外部字幕；如果希望另一台电脑继续使用代理，也一并复制代理文件。
3. 在新电脑保持尽可能相同的目录结构，或先打开项目再逐个重新链接脱机媒体。
4. 检查绑定的音频和字幕是否仍归属正确视频，检查代理预览是否指向可用文件。
5. 在新电脑保存一次项目，使新的有效媒体路径写入项目。

<GuideImage src="/images/projects/project-files-media.png" alt="可交付项目包的文件结构" />

### 项目版本兼容性

LineCut 可以迁移旧版本项目到当前内容模型；旧项目一旦由新版本保存，就可能无法再由较早版本打开。升级前，请保留原始 `.lcp` 的副本，并在团队协作中统一应用版本。

如果打开后发现路径问题，继续[脱机、替换和重新链接](/media/offline-proxies)。

## 历史记录、撤销与分支

### 撤销与重做

| 操作 | 快捷键                                            | 作用                       |
| ---- | ------------------------------------------------- | -------------------------- |
| 撤销 | <kbd>Ctrl</kbd> + <kbd>Z</kbd>                    | 回退一项项目操作           |
| 重做 | <kbd>Ctrl</kbd> + <kbd>Shift</kbd> + <kbd>Z</kbd> | 恢复刚撤销的下一项项目操作 |

撤销和重做作用于当前项目操作。输入框内编辑文字时，应用会优先让输入控件处理常规文本编辑，避免把文字编辑意外变成项目回退。

### 打开历史记录面板

选择 **窗口 → 历史记录**。面板从顶部到下方显示项目的基础状态和随后发生的操作，例如导入、重命名、标记、绑定、分镜检测、代理和导出相关操作。

1. 点击非当前状态的历史条目。
2. LineCut 跳转到该条目代表的项目状态。
3. 当前状态以下的条目会以“未来”状态显示；你可以重做回去，或从当前位置继续编辑。

<GuideImage src="/images/projects/history.png" alt="历史记录面板" />

### 从历史位置继续编辑

在旧状态上做出新的项目更改后，原来的“未来”分支不会继续作为独立分支保存。若你想保留两种方案，应先**保存副本**，再在各自项目文件中继续修改。

### 删除当前事件及后续历史

历史面板底部的删除按钮会将项目回到当前条目的上一个事件状态，并永久删除该条目及其后的历史记录。该动作无法撤销。

在删除前：

- 先检查是否只是需要普通撤销或跳转；
- 若可能还会比较这条分支，先保存项目副本；
- 不要把历史记录当作长期版本管理工具，重要阶段应保存单独 `.lcp` 文件。

项目的手动保存与自动备份见[最近项目、还原与自动备份](/projects/projects)。
