# 首选项

选择**编辑 → 首选项…**，在左侧选择**常规、自动保存、媒体缓存**或**媒体工具**。调整后单击**确定**生效；单击**取消**、关闭窗口或按 **Esc** 放弃本次修改。

路径可直接输入，也可单击**浏览…**选择。数值不符合允许范围时，请按提示修正后保存。

## 常规

**启动时显示主页**默认开启。关闭后仍可通过顶部主页按钮打开项目首页。

## 自动保存

| 设置                     | 用途                                           |
| ------------------------ | ---------------------------------------------- |
| 自动保存项目             | 开启或关闭定时自动保存，默认开启               |
| 自动保存时间间隔         | 1–1440 分钟，默认 5 分钟                       |
| 最大项目版本             | 每个项目保留 1–1000 个自动保存文件，默认 20 个 |
| 自动保存也会保存当前项目 | 同时保存已有正式路径的当前项目，默认开启       |
| 自动保存位置             | 选择自动保存文件所在目录                       |

项目内容有变化时才生成新的自动保存文件。达到上限后，删除该项目最旧的自动保存文件。未命名项目也可生成恢复文件，但需手动保存一次后，才能自动写回正式项目路径。

默认自动保存位置是缓存目录下的 **Locution Pro Auto-Save**。该位置独立设置，随后更改媒体缓存位置不会连带改变它。清空自动保存位置并确认，可重新采用当前缓存目录下的默认位置。

更改位置不会迁移或删除旧文件。请选择稳定、可写且空间充足的目录。恢复步骤见[自动保存与恢复](/projects/projects#自动保存与恢复)。

## 媒体缓存

缓存用于日常浏览和检索准备，应放在空间充足、连接稳定的磁盘上。

1. 选择**媒体缓存**。
2. 输入缓存路径，或单击**浏览…**选择文件夹；留空采用默认位置。
3. 单击**确定**。

新生成的缓存使用新位置，旧文件不会自动迁移。缓存位置与项目、原始素材及自动保存位置分别管理。

## 媒体工具

通常使用安装程序提供的内置媒体工具即可。如果使用自己的工具，分别填写 **FFmpeg** 与 **ffprobe** 的可执行文件路径，建议来自同一套发行包。

单击**重置工具路径**会恢复这两项的默认命令名称，仍需单击**确定**才生效。如果系统中没有对应工具，重置后也可能无法处理媒体；可重新运行安装程序选择内置方案。

工具问题见[故障排查](/troubleshooting/troubleshooting#媒体工具不可用)。

## 使用键盘操作

使用 **Tab / Shift + Tab** 移动焦点。焦点位于左侧分类时，使用上下方向键切换，**Home / End** 跳到首项或末项。
