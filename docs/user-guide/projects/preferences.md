# 首选项

> 适用版本：Locution Pro 0.3.3。

在 **编辑 → 首选项…** 打开“首选项”对话框。左侧分为**常规**、**自动保存**、**媒体缓存**和**媒体工具**，右侧显示对应的分组设置。切换分类会保留当前草稿，更改只会在点击**确定**后统一写入应用首选项。

点击**取消**、右上角关闭按钮或按 **Esc** 会关闭窗口并放弃当前草稿。点击窗口外部不会关闭首选项。路径既可直接键入，也可用右侧**浏览…**按钮选择；数值框显示有效范围，留空、非整数或超出范围时会显示提示，并禁用**确定**。

可用 **Tab / Shift+Tab** 在窗口内切换焦点；焦点位于左侧分类时，用 **↑ / ↓** 切换分类，**Home / End** 跳到第一个或最后一个分类。

## 设置说明

| 设置                     | 可填内容                   | 用途                                                             |
| ------------------------ | -------------------------- | ---------------------------------------------------------------- |
| 启动时显示主页           | 开启或关闭                 | 下次启动时显示主页；默认开启，可随时通过顶部主页按钮打开         |
| 自动保存项目             | 开启或关闭                 | 定时检查项目变化并生成自动保存文件；默认开启                     |
| 自动保存时间间隔         | 1–1440 分钟                | 自动保存的检查间隔；默认 5 分钟                                  |
| 最大项目版本             | 1–1000                     | 每个项目保留的自动保存版本上限；默认 20                          |
| 自动保存也会保存当前项目 | 开启或关闭                 | 生成自动保存文件后，也直接保存已有路径的当前项目；默认开启       |
| 自动保存位置             | 本地目录                   | 独立于媒体缓存设置，默认使用缓存下的 Locution Pro Auto-Save 目录 |
| 缓存路径                 | 本地目录                   | 存放媒体缓存；应选择空间充足且稳定的磁盘                         |
| FFmpeg                   | `ffmpeg.exe` 路径或命令名  | 用于媒体处理、代理和导出                                         |
| ffprobe                  | `ffprobe.exe` 路径或命令名 | 用于读取媒体流、时长、编码等信息                                 |

## 更改缓存路径

1. 选择左侧**媒体缓存**，点击“缓存路径”右侧的**浏览…**，选择目录；也可直接输入完整路径。留空使用应用默认缓存目录。
2. 确认目标盘有足够空间，并尽量避免会被系统自动清理的临时目录。
3. 点击**确定**。
4. 以后新生成的媒体缓存使用新位置；旧缓存不会因为更改设置自动迁移。已配置的自动保存位置保持不变。

## 更改媒体工具路径

如果安装程序未安装内置 FFmpeg，或你希望使用自己的版本：

1. 选择左侧**媒体工具**，分别为 `FFmpeg` 与 `ffprobe` 点击浏览并选择对应 `.exe`；也可直接输入路径或命令名。
2. 保持两者来自同一套发行版，减少版本不匹配。
3. 点击**确定**后，重新尝试导入、代理或导出。

窗口左下角的**重置工具路径**只会将 FFmpeg 和 ffprobe 恢复为默认命令名；缓存路径和自动保存设置的当前草稿保持不变。

重置只是修改当前对话框草稿，仍需点击**确定**才会生效；关闭对话框会放弃这次重置。

## 自动保存

在**自动保存 → 本地项目**中勾选或取消**自动保存项目**，点击**确定**后生效。关闭后停止后续定时检查，不会删除已有文件，也不会撤销已经开始的写入。重新开启后，按保留的间隔继续检查。

自动保存按设置的间隔检查项目内容，有变化时生成可独立打开的 `.lcp` 文件。**最大项目版本**按项目分别计算，达到上限后删除该项目最旧的自动保存版本，不占用其他项目的版本额度。

勾选**自动保存也会保存当前项目**后，每次自动保存先生成恢复文件，再直接写回当前项目原有的 `.lcp` 路径。成功后更新已保存状态；写入期间产生的新编辑仍标为未保存。未命名项目会生成自动保存文件，但不会弹出路径选择窗口；请先手动保存一次，之后才能自动写回当前项目。

在**自动保存位置**分组中，可直接编辑**位置**或点击**浏览…**选择目录。初始默认位置为当前缓存目录下的 `Locution Pro Auto-Save`；此后独立保存配置，修改媒体缓存位置不会改变它。清空位置并点击**确定**，会重新采用当前缓存下的默认目录。更改位置不会迁移或删除旧目录中的文件。

请选择稳定、可写且空间充足的目录，避免使用会被自动清理或经常脱机的位置。自动保存用于辅助恢复项目，仍建议手动保存重要更改并保留项目副本。

常见错误见[FFmpeg、ffprobe 与工具路径](/troubleshooting/troubleshooting)及[性能、缓存与代理](/troubleshooting/troubleshooting)。

## 0.3.3 缓存和面板配置的区别

缓存路径控制新生成的媒体缓存位置，自动保存使用独立的位置配置。它不等于 `.lcp` 项目位置，也不负责携带来源工作区到另一台电脑。更改缓存后旧文件不会自动迁移；在线素材缺失封面时可以自动重新分析，字幕和分镜缩略图也会按需重建。

更改 FFmpeg/ffprobe 后，请在新任务中验证。分镜检测的 Windows 提取阶段会请求 D3D11VA，使用自定义 FFmpeg 时其构建与源编码应兼容；“重置工具路径”只恢复默认命令名，不保证当前系统路径里的工具一定满足媒体要求。
