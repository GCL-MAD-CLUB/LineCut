# 项目文件与素材位置

## `.lcp` 项目文件保存什么

项目文件保存的是 LineCut 的工作数据，包括：

- 媒体箱中的视频、音频、字幕条目和文件夹结构；
- 活动视频、活动字幕轨、绑定关系和预览代理关联；
- 字幕的星级、旗标、色标与自定义标签；
- 分镜检测结果、堆叠、标题、星级、旗标、色标和关键字；
- 项目的保存身份与导出相关的持久状态。

## `.lcp` 不保存什么

- 原始视频、音频、外部字幕和代理媒体本身；
- 字幕面板的临时勾选、搜索文本和过滤条件；
- 仅在当前界面会话中存在的临时选择。

因此，复制一个 `.lcp` 文件不等于复制项目素材。项目依赖的媒体仍在其原始路径上。

## 移交或迁移项目

1. 在原电脑执行**保存**，必要时再执行**保存副本**作为备份。
2. 收集 `.lcp` 文件以及所有原始视频、音频、外部字幕；如果希望另一台电脑继续使用代理，也一并复制代理文件。
3. 在新电脑保持尽可能相同的目录结构，或先打开项目再逐个重新链接脱机媒体。
4. 检查绑定的音频和字幕是否仍归属正确视频，检查代理预览是否指向可用文件。
5. 在新电脑保存一次项目，使新的有效媒体路径写入项目。

## 项目版本兼容性

LineCut 可以迁移旧版本项目到当前内容模型；旧项目一旦由新版本保存，就可能无法再由较早版本打开。升级前，请保留原始 `.lcp` 的副本，并在团队协作中统一应用版本。

如果打开后发现路径问题，继续[脱机、替换和重新链接](/media/offline-relink)。
