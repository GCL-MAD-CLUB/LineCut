# 分镜 CSES 选帧

本次实现只完成分镜选帧。分镜面板选择「语义」并输入非空文字后，沿用字幕语义检索的
350 ms 防抖、全局任务排队、同范围任务共享、取消、进度、最新查询读取和排序流程。
完成后帧痕图以红色竖线显示选中帧。匹配度列、阈值控件、排序和缺失模型时的模式回退
与字幕面板一致。检索函数目前仅验证所有分镜已完成选帧，并返回全部分镜、分数 1.0。

选帧位置仅保留在 Rust 进程和前端内存中，不写项目文件、缓存目录或索引。
完整分镜的结果可供后续范围复用；取消中的分镜不会发布半成品。分镜边界、媒体指纹、
流、帧率、路径或文件元数据变化会使后端内存结果失效。退出应用后重新选帧。

## 论文对应关系

依据用户提供的 `2608.00714v1.pdf`（Coverage-Driven Adaptive Keyframe Selection
for Video Understanding），实现位于 `src-tauri/src/backend/storyboard_semantic/cses.rs`。

1. 均匀采样获得 O₀，包含首尾帧，先编码全部探测帧。每个探测帧使用 leave-one-out
   平均非负余弦相似度的补数 vᵢ。后续帧始终相对最初 O₀ 计算 vᵢ；不扩大参考集。
2. 按公式 1、4 计算 logP、u、ℓ。公式 6 的高斯回归用 vᵢ 代替 rᵢ；公式 7 的
   vis 使用左右相邻探测帧。候选网格在未编码的离散帧序列上均匀取点。
3. 按算法 1 第 7–18 行，每次规划后更新虚拟覆盖率，并重新计算 σ 和 W。
   饱和判断和增益求和始终覆盖整个候选网格（包括已规划点），只有 argmax 排除已规划点。
   达到 95% 加权覆盖率、预算上限、候选耗尽或没有正增益时停止。
4. 规划全部完成后才批量编码 P。按公式 9 仅更新峰值，保留 O₀ 的中位数和 MAD，
   再计算最终带宽。没有在采集循环内更新 logP 或带宽。
5. 按公式 2、3、5 和附录算法 2，构建非负余弦 × 高斯时间核，强制 Kᵢᵢ = 1。
   以 vᵢ + κ 加权，贪心选择；同增益时优先选择与已选集合最大核相似度最小的帧。
   同样相似时按时间先后确定结果。输出按时间排序。

高斯回归采用减去最大对数权重的等价计算，避免长分镜中所有权重同时下溢。
余弦计算使用 L2 归一化 DINOv3 CLS 特征；不再次对 vᵢ 做 min-max 归一化。

## 参数选择

设 N 为当前分镜包含首尾的帧数，T = N / fps（秒）。时长只使用该分镜，不使用整部视频。

| 参数       | 本实现                         | 原因                                                   |
| ---------- | ------------------------------ | ------------------------------------------------------ |
| n₁         | min(N, clamp(ceil(2T), 4, 64)) | 短分镜避免固定编码 64 帧，仍保留至少四个探测点（若有） |
| Rmax       | min(N, 2n₁, 128)               | 为主动采集预留至多与探测相同的预算                     |
| G          | min(512, N − n₁)               | 保留论文上限，短分镜只使用剩余离散帧                   |
| Kmax       | min(N, clamp(ceil(2T), 1, 32)) | 输出上限随分镜时长增加，保留论文最大值                 |
| ℓmax       | clamp(T / 4, 1, 38) 秒         | 保留公式规定的一秒下限，避免短分镜一开始就全被宽核覆盖 |
| Kmin       | 1                              | 附录给出该参数但未指定实验值，至少返回一帧             |
| τ、κ、ϵ、δ | 2、0.005、0.05、10⁻⁶           | 保留论文常量                                           |

不足 n₁ 的范围只取实际可用帧，不重复帧。单帧分镜直接返回唯一帧；这是
O₀ 去掉自身后为空、用户给定公式未定义时的退化处理。非法或空区间报错。
当全部 vᵢ 为零时，最终选择仍保留 κ 加权覆盖，不额外退回均匀选帧。

## 模型与运行入口

执行 `npm run prepare:transnetv2` 和 `npm run prepare:storyboard-semantic` 准备共享运行库
和 DINOv3；不需要字幕的 Jina 模型才能使用分镜选帧。DINOv3 的版本、输入和输出见
[MODEL.md](../src-tauri/resources/storyboard-semantic/MODEL.md)。

后端命令为 `storyboard_semantic_search_available`、`select_storyboard_frames` 和
`search_storyboards_semantic`。未来实际检索只需替换 `search_completed_shots` 的得分逻辑。
当前不包含 SigLIP2、索引构建、缓存持久化或文字向量化。
