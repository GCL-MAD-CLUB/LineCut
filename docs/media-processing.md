# 媒体处理维护契约

本文面向维护者，以 Locution Pro 0.4.0 为基线，记录媒体分析、镜头检测和检索的所有权与恢复要求。用户操作只在用户指南中描述。

## 登记与分析

导入先登记媒体，自动绑定与后续分析由应用媒体层协调。分析队列不依赖导入页面挂载，必须检查项目与素材身份，再合并封面、轨道和内嵌文字字幕。已有可复用轨道与字幕应保留身份。

在线媒体缺失封面或内嵌文字字幕数据时可延迟补分析；读取封面本身不能顺带启动另一套分析任务。视频无需字幕即可参与检测、检索和导出。字幕读取统一经过[派生预处理](system-architecture.md#多来源与派生读取)。

## 缩略图与静帧

封面、分镜和时间线缩略图分别按用途请求，遵守媒体与帧范围。缩略图服务需要限制并发、内存及临时输出；隐藏面板应停止不必要请求。缓存不属于项目权威数据，失败可按需重建。

当前帧导出由 `application/media/stillExportTask.ts` 协调，读取原媒体与原始分辨率。代理预览不能改变静帧来源，完成后导入需验证原项目仍有效；不覆盖已有同名图片。

## 镜头检测

TransNetV2 检测提供基础切点，前端负责选择合并或覆盖。主动重识别已有结果前确认处理方式；期间编辑变化需在提交前再次确认。合并补充切点，覆盖重建镜头并清除旧整理内容。

后端共享推理会话，通过有界读取队列重叠取帧与推理，空闲后退役。Windows 解码请求与推理提供者是不同兼容性条件，不能互相推断成功。

事件决策只接收逐帧概率，参数位于 `resources/transnetv2/storyboard-event-model.json`。当前系数标记为 `bootstrap_uncalibrated`，不能宣称为已拟合或全面校准的模型。

## ONNX 运行与恢复

统一运行入口为 `backend/onnx.rs` 的 `OnnxModel`。会话成功创建不代表真实推理成功，必须处理运行阶段失败。

支持 GPU 的模型在失败时按共享策略尝试 CPU，成功恢复后继续复用 CPU；取消在重建和重试边界检查。CPU 重试也失败时保留两段诊断。错误代码由调用方提供，不能在通用恢复层按文本分类。

SigLIP2 文本编码显式使用 CPU，以保持与图像检索的数值配对。模型身份、输入归一化、校准与资源准备细节见各资源目录的 MODEL 文档。

## 分镜选帧与语义检索

DINOv3 与 CSES 为镜头选帧，SigLIP2 编码所选画面及文本查询。镜头分数使用最高得分帧，并将其绝对帧位置传到搜索结果和缩略图。分数不按当前结果集合重新缩放，不能将显示的小数精度用于排序与过滤。

冷构建按媒体合并连续未缓存范围，复用 256 × 256 RGB。DINOv3 使用相应缩放，SigLIP2 复用所选帧；完整缓存不重新解码或推理，修复语义记录只补齐缺失画面。

编码器可按实测吞吐在 2、4、8、16、32 帧形状间调整批量。尾批、预热和等待时间不能充当可比较吞吐样本。批量失败先缩批，必要时进入共享 CPU 恢复；切换批量不应重启解码或改变帧顺序。

Windows 硬件缩放仅在首轮实际解码成功后使用。失败路径按程序、媒体与视频流记忆；尚未输出像素时可顺序尝试兼容路径，部分输出后不得重放前缀。

## 媒体缓存存储

选帧和语义记录共用 `backend/storyboard_semantic/storage.rs`，分别位于缓存根的 `Storyboard Keyframe` 和 `Storyboard Semantic Search`。同一媒体按方案与媒体版本聚合，文件名使用顺序号和 UUID，单卷达到 256 MiB 后才按大小分卷。元数据在记录内，不以镜头数量创建目录。

身份包含模型与算法、媒体大小、原始纳秒修改时间、视频流、帧率和绝对帧区间。原始纳秒不能截断；复用导入时媒体指纹，不额外扫描文件计算 hash。

记录采用头校验、载荷校验及提交标记。读取可越过损坏中段恢复后续已提交记录，追加仅截断最后有效末端后的不完整后缀。可解码且身份匹配的部分记录保留有效向量，只补缺失内容。

批量追加对每个涉及分卷同步一次，再同步目录并检查一次维护条件。压缩必须验证各键最新记录，失败则保留所有旧卷；成功发布新卷后才能删除旧卷。首次新版本记录成功提交后才清理同媒体的旧版本。维护留在后端，不产生无关前台警告。

锁协议协调当前进程中的读写，不承诺多个应用进程共写缓存。Windows 文件内容同步与崩溃恢复不等于突然断电下所有目录操作都持久。缓存不能作为素材或项目备份。

## 任务、进度与取消

任务槽由 `TaskSystem` 管理；底层完成或取消清理后才释放。检测失败隔离到该任务，旧项目或已替换媒体的结果不能提交。取消排队项不启动媒体工具，取消全部期间不补位。

首次分镜语义初始化使用共享等待，并在完成、失败时清理状态。索引进度将选帧计为 75%、图像编码计为 25%，按累计量汇总。字幕语义检索使用独立的文字索引，不因画面检索而改写字幕。

导出使用提交时快照，取消不回滚已经成功写出的文件。相关范围契约见[系统维护契约](system-architecture.md#任务与导出)。

## 验证范围

纯匹配、边界、记录恢复、任务顺序与取消逻辑使用确定性测试。真实 FFmpeg 编码、模型推理和 GPU 兼容验证保持手动或忽略测试，不加入普通 CI，也不以一次机器的结果承诺普遍性能。
