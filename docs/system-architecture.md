# 系统维护契约

本文面向维护者，以 Locution Pro 0.4.0 为基线。产品介绍位于根 README，使用说明位于用户指南；本页的技术契约不得移入这两类文档。

## 产品与数据边界

应用支持独立的媒体管理、画面检索、分镜整理和导出。字幕是可选来源，不应成为视频导入、检测、分镜检索或导出的前置条件。

应用标识为 `com.locutionpro.desktop`，项目扩展名为 `.lcp`，默认 Windows 数据目录为 `%LOCALAPPDATA%\Locution Pro`，浏览器键使用 `locution-pro:` 前缀。与 LineCut 的安装、卸载、快捷方式和可写数据隔离，项目读取兼容由项目文件层维护。

## 组件通信

组件拥有本地交互状态；项目事实由 `ProjectSystem` 聚合，长任务生命周期由 `TaskSystem` 管理。视觉组件直接使用类型化项目端口、私有状态与运行时能力，不增加 `use...System` 组合层。

| 边界         | 契约                                                      |
| ------------ | --------------------------------------------------------- |
| EventHub     | 广播请求与事实，不指定接收实例，不消费事件                |
| StateHub     | 发布最小只读投影，以 key 与 owner 标识，revision 单调递增 |
| 项目端口     | 外部按需声明查询与命令，不直接导入 ProjectState           |
| 面板私有状态 | 不跨面板导入，不把完整 store 发布为共享状态               |

事件信封与投影不可变。发布方不持有接收者引用；某订阅失败不阻断其他订阅，错误进入统一诊断。编辑与播放仲裁由各接收方根据活动页签、焦点和稳定身份执行，不能用目标面板字段取代广播。

运行时契约位于 `src/runtime/events`、`src/runtime/state` 与 `src/runtime/systems`。公共组件位于 `src/components/common`，业务面板位于 `src/components/panels`。

## 多来源与派生读取

来源上下文只组织视图和编辑分发，不将多个视频变为共享媒体。显示行可以包装来源身份，但持久化条目保留原身份。合并镜头、删除与堆叠在各视频内执行；关键字目录按项目协调。

字幕自动整理集中在 `core/editor/subtitlePreprocessing.ts`。同轨、纯文本完全相同且相接或重叠的连续 cue 可合并为缓存读取视图，原始 cue 不变。所有显示、计数、搜索、预览和导出使用该视图；删除等显式编辑通过来源 cue 映射作用于原数据。位图轨不参与文本预处理。

## 面板来源与播放

`application/media/panelMediaSources.ts` 组织来源，`panelMediaPersistence.ts` 与 `projectPanelPersistence.ts` 负责本机恢复和顺序写入。

来源工作区保存来源集合、活动源、字幕轨、播放位置和有界来源历史。相同媒体与轨道集合只保留一个工作区；项目与面板实例共同限定本机配置。来源锁分别属于字幕与分镜面板，阻止手动及自动来源变化，仍允许切换既有工作区。

播放模式通过最小投影共享，源监视器不得导入媒体面板私有状态。只有可见且满足活动规则的面板可接管播放。恢复配置完成前不启用目标配置写入，避免跨项目污染。

## 搜索与大列表

共享搜索控件位于 `components/common/PanelSearch`，纯文本规则位于 `core/editor/textSearch.ts`。查询实时更新，最近搜索只在退出输入时记录最终非空值。分镜与字幕各自维护历史和默认阈值。

分镜语义结果携带最高得分帧位置；列表补充只读预览，图标视图使用命中帧并保留缩略图操作。排序和过滤使用原始分数，显示精度不能改变结果。

图标网格按可见行渲染，键盘导航按网格坐标处理未挂载项。隐藏面板暂停缩略图与观察工作，不能因标签保留而持续处理大列表。

## 任务与导出

任务提交时登记 queued，获得执行资格后才启动底层工作。最多三项分镜检测并行，其余任务独占，后续检测不越过队列中的普通任务。取消运行任务后，由所有者等待清理完成再释放；取消全部时暂停补位。

导出来源与参数在提交时捕获。分镜、字幕和媒体箱的临时范围由 `ExportSystem/exportWorkspaceState.ts` 管理，独立撤销，不修改原项目切点和字幕时间。刷新来源按仍有效的片段与路径保留范围，切换项目清空。任务期间的新编辑不改变已提交输出。

## 首次安装迁移

迁移由当前用户安装器执行，正常运行不扫描或复制 LineCut 数据。既有 Locution Pro 安装记录、用户数据或浏览器配置阻止重新迁移；机器级安装不迁移用户数据。中断的首次迁移只在归属可验证时继续。

复制使用暂存、同步、完整性校验和提交，源数据保留。缓存与自动保存位置改为自身副本，浏览器配置整体提交，不合并既有数据库。安装器媒体工具选择优先于导入的旧设置，正常保存后的用户设置继续优先。

取消后等待有限清理，失败不自动跳过。图形界面允许重试或显式跳过；跳过保留原数据与已复制副本，并阻止后续自动续传。卸载与清理只操作自身记录和已确认归属路径。

## 验证

运行 `npm run check:architecture`、`npm run check:errors` 和 `npm test`。涉及媒体资源的真实验证按贡献指南手动执行，普通 CI 保持确定性。
