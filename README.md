Locution Pro 是面向视频创作者、剪辑师和素材管理者的桌面工作软件，集媒体管理、画面检索、镜头整理和片段导出于一体。将分散的素材汇集到项目中，按画面内容寻找所需镜头，完成筛选、分类与交付。

无论是没有对白的风景空镜、活动现场，还是包含大量访谈的长视频，都可以直接开始工作。字幕是查找对白的可选辅助；浏览画面、检测镜头、整理素材和导出均可独立完成。

## 以画面寻找素材

自动识别视频中的镜头切点，将长视频展开为清晰的分镜列表或缩略图网格。用画面快速回顾拍摄内容，找到值得保留的瞬间。

安装语义检索组件后，可以用自然语言描述所需画面，例如“夜晚街道上的行人”或“海边日落”，从多个视频中查找相关镜头。结合命中画面预览和匹配度，快速确认候选素材。

## 建立有条理的素材库

在同一项目中管理视频、音频、图像和字幕，用多级媒体箱安排素材。为镜头设置标题、星级、留用旗标和色标，用层级关键字描述人物、地点、动作与场景。

跨视频集中审核镜头，按关键字和标记组合筛选，将相关镜头组成可展开的堆叠。需要查找对白时，也可以使用字幕文字搜索或语义搜索。

## 精确审看，专注选择

在源监视器中逐帧定位、检查镜头衔接、调整切点。高分辨率或高码率素材可配合代理预览，让长时间审片更流畅。

随时将当前画面导出为原始分辨率静帧，用于选图、参考或后续制作。面板支持停靠与拆分，可按自己的审片习惯安排工作区。

## 从候选镜头到交付文件

将所选镜头、媒体或对白片段逐项输出，或合并为一个文件。在导出预览中微调每段的入点和出点，再设置画面、音频、文件名与输出位置。

支持 H.264、HEVC、Apple ProRes、VP9，以及 MP3 和 AAC 音频输出，适用于独立片段交付、素材挑选和后期交换。

## 开始创作

1. 下载并安装 Locution Pro，首次安装建议保留内置媒体工具和语义检索组件。
2. 新建项目，导入视频或其他素材；无需先准备字幕。
3. 在分镜面板浏览镜头，搜索画面、添加标记并选出所需片段。
4. 进入导出工作区，确认范围和输出设置，生成交付文件。

详细步骤见[创建第一个项目](docs/user-guide/getting-started/first-project.md)。

## 本地工作，持续保存

媒体分析、镜头检测、语义检索、预览和导出均在本机完成，日常素材处理无需上传文件。

用 `.lcp` 项目保存素材组织与镜头标注，配合自动保存和项目副本继续工作。项目文件不包含原始媒体；移交项目时，请一并提供素材。

## 运行环境

- Windows 10 或 Windows 11，64 位。
- 可用窗口至少为 1080 × 700，建议使用 1920 × 1080 或更高分辨率显示器。
- 为原始素材、媒体缓存、可选语义检索组件、代理和导出文件预留充足磁盘空间。

更多信息见[系统要求](docs/user-guide/getting-started/system-requirements.md)与[格式兼容性](docs/user-guide/reference/supported-formats.md)。
